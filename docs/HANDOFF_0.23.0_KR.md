## 남은 환경 검증과 한계

이번 환경에는 Burp 본체와 Docker 실행 환경이 없어 실제 Burp 로드/GUI, 브라우저 DOM, Docker/Oracle/Nginx, Pro Collaborator, 외부 BApp 및 현재 네이티브 TLS/HTTP2는 미실행입니다. 과거 환경의 해당 검증과 구분합니다. PDF는 실제 Burp 화면 촬영이 아닌 운영 Swing UI 미리보기입니다.

단일 증거 ZIP은 브라우저 이미지 한 장이며 서로 다른 이미지는 별도 묶음을 사용합니다. 원본 연결은 128KiB/보관 한도가 있고 일반 HTML·바이너리 파일 원문 첨부는 제공하지 않습니다. 자동 `/me` 신원 검증, 수동 정책 태그별 대표 URL, 장시간 수집은 후속 후보입니다. 마커는 흐름별로 고유하게 사용하며 같은 마커의 새 쓰기는 이전 조회/수동 근거를 무효화합니다.
