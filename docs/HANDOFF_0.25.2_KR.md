# 0.25.2 인수인계

사용자 요청: 실제 Burp도 확인하고 HTTP history처럼 250건·128KiB 제한 제거.

출발점은 PR #12의 `ea3514610e479629cf3dfe3fa0e95417519ab976`입니다. 새 작업 브랜치로 전달하며 main 및 별도 0.26.0 SCOPE 작업 브랜치를 변경하지 않습니다. 이전 로컬 0.26.0의 DiskTrafficStore 초안을 검토해 재사용했으며 SCOPE/ON/OFF 통합 기능은 섞지 않았습니다.

변경: 행 자동 제거와 크기 제외, 유한 수집 큐 제거. 원본 임시 디스크 저장, 선택 시 복원, 목록 비우기/언로드 정리. 기존 0.25.1 예외 격리 유지. 내보내기는 원본을 반복 로드하지 않고 메타데이터를 사용합니다.

실제 Burp Community 2026.3.3 / Java 21 / headless / loopback 전용 검증은 audit/0.25.2에 보존합니다. 601건과 2MiB 바이너리 요청·응답, 무누락, 원본 일치, clear/unload 정리를 확인했습니다. 사용자 프로필/브라우저/프록시 설정은 수정하지 않았습니다. GUI 동작, 장시간 대용량 스트레스, 디스크 고갈 상황은 실제 Burp 검증 범위 밖입니다.

기존 기능 검사는 dev.py release 결과 및 CI를 기준으로 확인합니다. 상세 변경과 설치는 RELEASE_0.25.2_KR.md를 참고합니다.
