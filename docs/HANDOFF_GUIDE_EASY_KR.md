# 쉬운 한국어 가이드 개정 기록

작성일: 2026-10-11 / 담당: 계정 A / 확장 0.25.0용 문서 개정판.

## 사용자 피드백과 수정

가이드북의 한국어가 번역투처럼 읽히고, 낯선 표현 때문에 사용 방법을 이해하기 어렵다는 피드백을 받았습니다. 영어 원문을 번역한 문서는 아니지만 개발 용어와 명사 위주의 압축된 설명이 많았습니다.

24쪽 전체를 사용 목적, 누를 버튼, 확인할 결과 순서로 다시 썼습니다. 예를 들어 ‘관측 요청’은 ‘목록에서 요청 선택하기’, ‘기준·검사·대조 응답’은 ‘원래 응답과 검사값을 넣은 응답 비교하기’처럼 풀었습니다. SCOPE·API·세션·마커·JWT·OAST 등 필요한 용어는 첫 설명에 뜻을 덧붙였습니다.

실제 버튼명도 대조해 ‘AST 분석’을 현재 화면의 ‘수동 분석’으로 바로잡았습니다. 업무 등록 전에 계정을 등록하고 `/api/auth/me` 요청을 연결하는 순서를 보완했습니다. Cookie에서 복사할 범위, JSON 변수 추출 위치, 전체 검사 경로와 Bob의 응답에서 OWNER_ID를 확인하는 점도 명확하게 적었습니다.

## 검토와 확인

원고 전체를 읽고 자연스러운 한국어와 필요한 사용 순서를 확인했습니다. 실제 Java 버튼명, 계정 ID, 로그인 처리, 실습 경로와 응답 조건을 대조했습니다. PDF를 Poppler로 110 DPI PNG 24장으로 렌더링하여 전 페이지를 시각 검토했습니다. 제목·본문·표·그림의 잘림과 페이지 넘침이 없었습니다. 책갈피 24개와 그림 17개(화면 15개, 유스케이스 다이어그램 2개)를 유지했습니다.

`python tools/package_downloads.py --verify`로 기존 배포 파일과 소스 지문이 그대로 일치하는지 확인했습니다. 문서만 수정했으므로 로컬에서 확장 기능 검사를 새로 반복하지 않았습니다. 기존 기능 검사 수를 이번 문서 검증 수로 합산하지 않습니다. PR의 자동 검사는 별도로 기록합니다.

그림은 확장 화면에 예제 데이터를 넣어 만든 것입니다. 이번 작업에서 네이티브 Burp, 브라우저, Docker 또는 외부 서비스 실행은 수행하지 않았습니다.
