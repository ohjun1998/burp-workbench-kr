# 0.24.0 변경 안내

확장 **0.24.0**의 화면 배치와 버튼 동작을 개선했습니다. 커뮤니티 실습 사이트와 Docker 패키지는 **3.5.0**을 사용합니다. 0.23.0의 원본 증거 연결·저장/조회 단계·수동 실행 확인·가림 미리보기와 이전 버전의 계정·업무 점검 기능을 유지합니다.

[다운로드](../downloads/README.md) · [그림 가이드](../downloads/guides/README.md) · [화면 비교](UI_0.24.0_KR.md) · [모의 진단 절차](TEST_WORKFLOW_KR.md)

## 버튼을 찾는 순서

계정별 점검은 계정을 선택한 다음 API와 입력을 선택합니다. API가 없으면 URL 완료·완료 해제를, 입력이 없으면 입력 완료·해제를 실행할 수 없습니다. 입력 완료 후 선택을 유지해 같은 항목의 완료를 바로 해제할 수 있습니다.

업무별 현황에서는 업무를 선택해 설정·완료·해제를 실행합니다. API를 연결하거나 제외하려면 하단의 **요구 계정 × API** 상세 표에서 대상을 선택합니다. 파일 확인은 **증거 파일 ▾ → 파일 상태 확인 / 증거 ZIP 재연결 / 모든 증거 재검증**에서 실행합니다.

JS 추출의 **선택 URL → Repeater**와 **동적 값 확정**은 **URL · API** 탭의 항목을 선택했을 때 활성화됩니다. **원본 위치**는 URL·API 또는 토큰·API 키 후보를 선택했을 때 활성화됩니다. Repeater 기능은 요청 초안을 준비하며 자동 전송하지 않습니다.

데이터 비교는 양쪽 카드에서 트래픽을 가져오고 **비교 실행**을 누릅니다. 입력 편집으로 돌아가거나 새 원본을 가져오면 이전 차이 탐색을 비활성화하므로 다시 비교합니다. **원본 → 증거**는 양쪽 실제 원본이 연결되었을 때 활성화됩니다. 입력값을 직접 편집하면 해당 원본 연결이 해제됩니다.

저장/조회 연결의 **브라우저 실행 확인**은 HTML 조회가 관측된 흐름을 선택했을 때 사용할 수 있습니다. 실제 브라우저에서 실행을 직접 확인하고 가린 PNG/JPEG를 연결하는 절차를 유지합니다. **실행 근거 해제**는 연결한 근거가 있을 때 활성화됩니다. 버튼의 활성화 자체는 취약점 확정이나 브라우저 실행 증명이 아닙니다.

## 검증 방법과 결과

`python dev.py release`가 종료 코드 0으로 완료되었습니다. **기능 검사 1,629개와 패키징 검사 4개가 통과**했습니다. 현재 실행의 수치·로그·파일 해시는 [검증 JSON](VERIFICATION_0.24.0.json)에 기록했습니다. 과거 버전이나 중간 실행의 통과 수는 합산하지 않았습니다.

| 검사 | 결과 |
|---|---|
| 회귀·API·헤드리스 Swing | 1,136개, 38묶음; 신규·확장 검사 84개 포함 |
| 페이로드 HTTP fixture | 127개 |
| 전체 기능 HTTP | 100개, 실제 요청 199건 |
| 커뮤니티 모의 진단 | 266개, 실제 요청 259건 |
| 패키징 | 4개; 다운로드·소스 지문 검증 통과 |

```sh
python dev.py release
python tools/render_ui_layout.py --out tmp/ui-layout --check
```

화면 검사는 **확장 작업 영역** 1024×720, 1280×800, 1440×920과 밝은/어두운 테마에서 JS 대체 배치를 포함해 각 16개 화면, 총 96개 화면을 렌더링하도록 구성했습니다. 운영 Swing 구성 요소에 합성 데이터와 테스트 API 어댑터를 사용합니다. 버튼 경계뿐 아니라 JS 원문, 업무 흐름 입력·상세, 증거 영향·재현 입력의 실제 보이는 영역을 측정하고 PNG를 확인합니다. GitHub CI에도 같은 화면 배치 게이트를 추가했습니다.

최종 로컬 검사에서 **96개 화면·918개 컨트롤의 잘림 0건, 24px 미만 컨트롤 0건, 핵심 본문 영역 기준 미달 0건**을 확인했습니다. 1024×720에서 JS 원문은 기본·대체 배치 모두 실제 노출 높이 99px, 업무 흐름 상세는 214px입니다. [화면 측정 결과](ui/0.24.0/after/layout-report.json)와 [전후 비교](UI_0.24.0_KR.md)를 확인하세요. PDF는 최신 화면 15개를 포함한 23쪽이며 전체 페이지를 렌더링해 검토했습니다. GitHub CI 상태는 작업 브랜치 PR에서 별도로 확인합니다.

이 검사는 실제 Burp에 JAR를 로드하거나 GUI를 조작한 검증이 아닙니다. 운영체제별 글꼴·DPI, 실제 Burp의 키보드 포커스·팝업·분할 막대, 장시간 수집은 별도 확인이 필요합니다. 브라우저 DOM, 전체 Docker/Oracle/Nginx, Pro Collaborator와 외부 BApp의 현재 실행 실적도 이 렌더링 결과에 포함되지 않습니다.

## 배포와 협업 상태

JAR·소스 ZIP과 PDF는 `downloads/extensions/0.24.0/`, `downloads/guides/0.24.0/`에 구분합니다. 0.23.0을 포함한 기존 버전 파일과 검증 기록은 보존합니다. 사이트 소스와 Docker 3.5.0은 이번 UI 변경으로 새 버전을 만들지 않습니다.
