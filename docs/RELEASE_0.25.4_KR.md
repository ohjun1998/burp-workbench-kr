## Scope 사용법과 버전별 차이

1. 기존 확장을 해제하고 `downloads/extensions/0.25.4/`의 JAR를 로드합니다.
2. Burp HTTP history에서 대상 요청을 우클릭하고 기본 **Add to scope**를 누릅니다.
3. Workbench **SCOPE 목록**에서 체크 상태를 확인한 뒤 수집 모드를 **SCOPE**로 바꿉니다.
4. 필요하면 URL 추가·체크 해제·선택 삭제·일괄 삭제를 사용합니다.

대상 목록을 JSON으로 내보내는 Burp는 기존 규칙을 그대로 읽습니다. 일부 Burp에서는 실제 Scope 판정이 참이어도 해당 설정을 내보내지 않습니다. 이 경우 History·Site Map·선택 요청과 이후 관측하는 요청에서 HTTP(S) 주소와 상위 경로를 확인해 범위를 만듭니다. 이 조회는 추가 HTTP 요청을 보내지 않으며, 수집 시에는 Burp의 실제 Scope와 제외 규칙을 다시 확인합니다.

목록 내보내기를 지원하지 않는 버전에서는 **아직 방문하거나 선택하지 않은 URL 및 고급 정규식 규칙 전체를 원래 형태로 나열할 수 없습니다.** 필요한 주소가 안 보이면 URL 추가로 직접 등록하세요. 복원한 행은 관측한 URL에서 확인한 범위이며 원래 Burp 규칙 전체를 내보낸 결과는 아닙니다. 쿼리 값·인증정보는 범위 후보에 저장하지 않습니다.

ON은 모든 새 트래픽을 수집하고, OFF는 신규 수집을 중지합니다. 모드 변경 전 이미 대기 중인 패킷은 반영될 수 있습니다. 체크·삭제는 Workbench 목록에 적용되며 Burp Target Scope를 변경하지 않습니다. 트래픽 원본은 확장 실행 중 임시 보관이고 영구 프로젝트 저장 기능은 아닙니다.
