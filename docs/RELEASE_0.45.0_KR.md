# Workbench 0.45.0 변경 안내

**독립 메뉴 10개와 화면 배치를 유지하고, Juice Shop 테스트에서 놓쳤던 판정·분석·흐름 연결을 개선했습니다.** 계정 권한 비교 외의 도구도 같은 실제 Burp 실행에서 다시 확인했습니다.

## 사용하면서 달라지는 점

| 기능 | 이전에 관측한 문제 | 개선한 동작 |
|---|---|---|
| 계정 권한 비교 | 비로그인 `200 {"user":{}}`를 우회 의심으로 표시 | 빈 사용자·자료는 **확인 필요**. 실제 데이터가 없다는 이유만으로 정상 차단을 확정하지 않음 |
| 응답 차단 규칙 | 대상의 명시적인 거부 메시지가 있는 400도 계속 보류 | 사용자가 지정한 규칙과 맞는 400·422를 분류. JSON 자료·소유자·중요 필드가 함께 있으면 충돌로 보류 |
| JS에서 API 찾기 | Angular 호출·템플릿 문자열·대형 번들의 뒤쪽 API를 놓침 | `http`·`httpClient` 호출과 메서드를 보조 복구. 잘못된 URL 조각은 개별 제외하고, 이력 처리 실패 시 발견 후보 보존 |
| 응답 보안 분석·입력값 보안 검사 | `SQLITE_ERROR`를 놓침 | SQLite·Sequelize DB 오류 패턴을 공유. 기존 기준 응답에도 있던 오류는 새 SQL 주입 근거로 사용하지 않음 |
| 기본 SQL 검사값 | 단순 따옴표·괄호 문맥만 검사 | LIKE·닫는 괄호 문맥의 참·거짓 쌍 4개 추가. 기존 전송 예산·중단 제어 안에서 실행 |
| 저장 후 조회 흐름 | POST 302 → GET 200의 같은 마커가 연결되지 않음 | 관측한 같은 Origin의 리다이렉트 대상과 후속 조회를 후보로 연결. 쓰기 2xx 미관측·브라우저 실행 미검증을 계속 구분 |

JS에서 확정하지 못한 호스트·경로 값·본문은 편집기의 미확정 표시와 전송 차단을 유지합니다. 리다이렉트 분석은 관측한 패킷을 연결하며 HTTP 요청을 새로 보내지 않습니다. 외부 Origin, 다른 후속 경로, URL 자체의 마커 반사는 리다이렉트 저장 근거로 연결하지 않습니다.

## 테스트 결과

| 구분 | 이전 0.44.0 | 개선 0.45.0 |
|---|---:|---:|
| 실제 Burp 기능 조건 | 28/33 충족 | 33/33 충족 |
| 실제 Chromium 흐름 | 5/5 통과 | 5/5 통과 |
| 기본 규칙 18칸 | TP6·FP1·TN9·FN0·보류2 | TP6·FP0·TN9·FN0·보류3 |
| 대상 규칙 6칸 재검사 | TN4·보류2 | TN6·보류0 |
| 별도 회귀·HTTP | 2,890개 통과 | 2,942개 통과(새 회귀 52개 포함) |

기존 실패 AU-08·JS-02·RE-02·RE-03·PL-01을 해소했습니다. AU-07의 빈 사용자 판정과 JS-03의 보관 버전 전체 분석 실패 제외 조건도 강화했습니다. 기본 규칙의 보류가 1건 늘어난 것은 빈 200 응답의 오탐을 보류로 바꿨기 때문입니다. 대상 차단 규칙을 지정한 별도 재검사에서는 이 응답과 400 거부 응답을 정상 분류합니다. 기준 계정과 보류는 TP/FP/TN/FN에 중복 집계하지 않습니다.

배포 파일 해시·소스 지문과 패키징 6개를 확인했습니다. 메뉴·배치 소스 5개가 기준과 같고, 헤드리스 Swing 150개 화면·2,640개 컨트롤/탭·제목 측정에서 잘림과 핵심 영역 붕괴가 없었습니다. 이번 재개는 중단 전 완료된 최종 실행 원본의 복구·재집계·문서화이며 실제 Burp를 새로 실행했다고 표현하지 않습니다.

## 설치와 확인

[0.45.0 JAR·소스](../downloads/README.md)를 받고 이전 Workbench를 해제한 뒤 **Extensions → Add → Java**로 설치합니다. 메뉴와 기존 설정 동선은 같습니다. 빈 200 응답을 서비스의 확정 거부로 분류하려면 기존 **비교 설정 → 응답 차단 규칙**에 그 서비스의 정확한 거부 조건을 지정합니다. 일반 오류를 일괄 차단 규칙으로 넣으면 판단을 흐릴 수 있습니다.

이번 검증은 개인용 로컬 Juice Shop 20.3.0과 headless Burp Community·실제 Chromium을 사용합니다. Burp 패널은 하네스가 컨트롤러를 호출했으며 수동 GUI 클릭은 검사하지 않았습니다. crAPI·실제 Oracle·Windows DPI/IME·외부 OAST/BApps/아카이브는 이번 실행 범위 밖입니다. JS의 전체 최신 문법 해석, SQL 주입 확정, 서버 영구 저장과 브라우저 실행은 별도 근거가 필요합니다.
