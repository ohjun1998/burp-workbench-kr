# Workbench 0.46.1 변경 안내

Vuln Bank 점검에서 드러난 세 가지 판정 공백을 보완했습니다. 독립 메뉴와 주요 화면 배치는 그대로입니다.

| 기능 | 이전 | 변경 후 |
|---|---|---|
| 계정 권한 비교 | GraphQL POST query도 쓰기로 처리, HTTP 400 권한 거부 보류 | 단일 JSON query를 조회로 처리하고 기준 응답 재검증. `data`와 `errors`를 구분해 명시적 거부·부분 데이터·일반 오류를 분리 |
| 입력값 보안 검사 | 참 200 / 거짓 404를 하나의 조건 후보로 연결하지 못함 | 순차 모드는 거짓 상태·본문을 반복 확인. 적응형은 역순 참/거짓과 기준 재확인까지 통과해야 후보 표시 |
| 쓰기 전후 조회 | 변화 유무만 확인, 업무 숫자 경계 미지원 | 숫자 증가 상한 초과 / 감소 하한 미달 모드. 전후 값·변화량·경계를 실제 판정 근거에 표시 |

## 사용하는 방법

- **GraphQL:** `/graphql` 또는 그 경로로 끝나는 JSON POST의 단일 query만 자동 조회로 인식합니다. operationName은 선택한 단일 연산과 같아야 합니다. mutation·subscription·배치·다중 연산·fragment·불명확한 문서는 기존 쓰기 허용 설정을 유지합니다. 다른 경로의 GraphQL은 자동 분류하지 않습니다. 200이라도 오류/부분 데이터가 있으면 보류하며 일반 오류를 권한 거부로 확정하지 않습니다.
- **SQL:** 입력값 보안 검사에서 SQL Injection을 선택합니다. 순차 모드의 참/거짓 두 값만 검사할 때 상태 차이 반복까지 최소 5회 예산이 필요합니다. 적응형은 더 많은 대조 요청이 필요하며 예산·중지·401/403/429/503 제어를 지킵니다. 후보는 SQLi 확정이 아닙니다.
- **업무 규칙:** 계정 권한 비교의 기존 비교 설정 → 쓰기 전후 조회에서 대상 POST 경로, 같은 Origin의 조회 GET URL, 숫자 JSON 경로를 지정합니다. 예를 들어 송금자의 잔액이 늘면 안 되는 조건은 `숫자 증가 상한 초과`, 경계 `0`으로 설정합니다. 전후 차이가 0보다 클 때 후보입니다. 기준 요청 인증으로 같은 조회 항목을 관측하므로 계정별 대상과 실제 업무 규칙을 맞춰야 합니다. 기준 계정은 교차 비교에서 제외되므로 별도의 비교 계정을 지정해 해당 계정의 상태를 관측합니다. 단일 계정의 독립 업무 검사는 이번 추가 범위가 아닙니다. 쓰기를 재시도하거나 롤백하지 않습니다.

## 최종 검증 수치

- `python dev.py release`: 회귀 2,496 + 페이로드 HTTP136 + 전체 기능 HTTP102 + 모의 진단266 = **3,000개 통과**. 새 회귀54개와 적응형 SQL 대조4개를 포함합니다.
- 실제 Burp: 기능 조건 **32개 통과**, 보조 확장 연동 **1개 미실행**. 실제 Chromium **5/5 통과**.
- 이전 버전과 같은 로컬 DB 환경의 계정 대조15개: **TP5/TN8/보류2 → TP5/TN10/보류0**, 두 실행 FP0/FN0. 기준5칸 제외.
- 권한 패널의 light/dark·3개 크기: 컨트롤1,104개/제목·탭468개 측정, 잘림0·핵심 영역 붕괴0. 이 검사는 합성 데이터 레이아웃 검사이며 보고서의 실제 결과 화면과 구분합니다.

## 검증 범위와 제한

실제 Burp Community에서 새 JAR를 로드하고 Workbench 기능 조건, 별도 Feature Mapper, 실제 Chromium 흐름을 점검합니다. 증빙 화면은 해당 실행 결과를 담은 실제 Swing 패널의 헤드리스 렌더링이며 수동 데스크톱 클릭 검증이 아닙니다.

Vuln Bank 대상 소스는 변경하지 않았습니다. 이 환경은 일반 PostgreSQL을 비관리자 프로세스로 시작할 수 없어 PGlite 0.5.10(PostgreSQL 18.6) TCP 서버와 순차 Flask를 사용했습니다. 공식 Compose/PostgreSQL 13 환경과 다르며 동시성·성능 검증으로 해석하지 않습니다. 브라우저 보조 확장 클릭 연동은 이전 환경 제약으로 이번 실행에서 제외했습니다. 외부 BApps·OAST·실제 AI 서비스는 범위 밖입니다.
