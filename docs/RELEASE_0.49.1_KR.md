# Workbench 0.49.1 · 계정 비교 전 설정·판정 한계 안내

비교를 실행하기 전에 **어떤 요청·계정에 권한 설정과 쓰기 조회가 적용되는지**, 설정이 빠지면 **무엇을 확정할 수 없는지** 확인할 수 있습니다. 내장 Mapper는 0.3.3, 실습 사이트는 3.10.0입니다.

## 사용 순서

1. 기존처럼 계정을 지정하고 요청을 선택한 뒤 **선택 요청 비교**를 누릅니다. 트래픽 우클릭의 **선택 요청 계정 비교 실행**도 같은 안내를 엽니다.
2. **비교 전 설정 확인**에서 요청·계정별 적용 권한, 쓰기 결과 조회, 판정 한계, 다음 설정을 읽습니다. 표의 행을 선택하면 긴 설명을 아래에서 줄바꿈하여 읽을 수 있습니다.
3. **권한표 설정**은 세션·권한 매트릭스로, **쓰기 조회 설정**은 비교 설정의 처리 결과 확인으로 이동합니다. 설정을 수정한 뒤 다시 비교하면 새 설정으로 준비 상태를 계산합니다.
4. 설정이 부족한 경우 **제한 확인 후 비교**, 설정 항목이 준비된 경우 **비교 시작**을 눌러 실제 비교를 시작합니다. 취소하거나 설정 창으로 이동하면 비교 요청을 보내지 않습니다.
5. 실행 후 상세 창의 **판정 근거 → 비교 전 설정** 탭에서 당시 설정 적용 범위를 다시 볼 수 있습니다. 현재 설정을 바꿔도 과거 실행의 안내는 바뀌지 않습니다.

## 안내하는 내용

| 상황 | 실행 전 표시 |
|---|---|
| 이 메서드·경로에 적용되는 권한표나 경로 정책 없음 | 공개·공유 허용과 권한 위반을 확정하기 어려움 |
| 요청에 맞는 권한표가 있으나 특정 계정이 미지정 | 해당 계정의 기대 권한 미지정 |
| 공개/공유 정책 또는 소유자 전용 정책 사용 | 적용 정책 표시. 소유 JSON 경로·계정 소유값이 빠지면 보완 항목 표시 |
| 쓰기 전후 조회 꺼짐 | 응답 코드만으로 저장·삭제·권한 변경 성공 여부를 확정할 수 없음 |
| 조회가 켜졌으나 메서드·경로 불일치 | 조회 규칙 미적용. 현재 요청을 연결하도록 안내 |
| 조회 규칙 적용 | 관측 방식·최대 조회 횟수 표시. 실제 조회 성공·지연·동시 변경은 실행 후 확인 |
| Scope·기준 응답·쓰기 전송 조건 불충족 또는 조회 URL이 Scope 밖 | 사유 표시, 이 준비 화면에서 비교 시작 선택지 제공 안 함 |

자동 비교 ON도 먼저 준비 화면을 표시합니다. 앞으로 들어올 URL이 정해지지 않았으므로 계정별 규칙 개수만으로 전체 요청을 검증했다고 표시하지 않습니다. 정확한 적용 범위는 선택 요청에서 확인하고, 자동 실행의 각 기록에는 실제 요청에 대한 설정 안내를 보관합니다.

준비 화면은 저장된 설정을 읽어 계산하며 HTTP를 전송하지 않습니다. 화면에 설정 항목이 준비됐다고 나와도 실제 신원·권한 정책·서버 처리 결과를 검증했다는 의미는 아닙니다. 차단 규칙·비교 제외 필드의 개수도 함께 표시하며 서비스별 규칙의 적절성은 사용자가 확인합니다.

## 빌드·검사 범위

사용자의 앞선 로컬·원격 검사 중단 요청을 유지합니다. 이번 버전은 **테스트 옵션 없는 컴파일·패키징만 수행**하며 회귀·HTTP·GUI·브라우저·원격 CI를 실행하지 않습니다. 기존 UI 회귀의 탭 구성 기대값은 새 구성에 맞게 갱신했지만 실행하지 않았습니다.

이전 392건 정탐·미탐과 보류91건은 기존 0.49.0 실습 자료입니다. 이번 안내 기능의 새 탐지 성능 측정치로 사용하지 않습니다. 기존 0.49.0 및 Mapper0.3.3의 검증 한계와 알려진 브라우저 도우미/fixture 문제도 이전 기록에 남아 있습니다.
