# Workbench Next 0.52.1 안정화

0.52.0에서 확인된 검색 예약 경합, 응답 초기화 예약 누수, 브라우저 본문 관측 범위의 잘못된 가정을 정리한 후속 버전입니다. 8개 주요 메뉴와 사용 순서는 유지합니다. 내장 Feature Mapper와 선택 설치하는 브라우저 도우미는 0.3.5입니다. 기존 0.52.0 파일은 보존합니다.

## 바뀐 동작

| 문제 | 0.52.0에서 확인한 현상 | 0.52.1 동작 |
|---|---|---|
| 검색 완료 시점 | Swing 타이머는 종료됐지만 화면 스레드의 검색 시작이 아직 대기 중인 구간을 완료로 오인 | 예약 상태를 검색 시작·취소·초기화·종료까지 추적. 그룹 펼치기와 중요 표시 변경의 갱신을 기다림 |
| 응답 관찰 초기화 | 취소 스냅샷 직후 들어온 분석 작업을 큐에서 직접 지우면서 입력 메모리 예약이 남을 수 있음 | 단일 취소 경로에서 큐 제거와 예약 반환을 처리. 실행 중 작업은 종료 시 반환 |
| 브라우저 본문 근거 | 실제 브라우저 검사에서 PATCH에도 raw 본문 SHA-256을 요구. 일부 무해시 연결이 선행 ID 관계로 높은 확신이 될 수 있음 | POST/PUT의 관측 가능한 raw 본문은 해시 대조 유지. PATCH 등 본문 미관측 사유를 표시하고 무해시 연결은 중간 확신으로 제한. 모호하면 연결 보류 |

브라우저 도우미는 페이지의 fetch/XHR를 가로채거나 새 권한을 요구하지 않습니다. Chrome webRequest가 제공하지 않는 본문을 복원·추측하지 않습니다. [Chrome 공식 API](https://developer.chrome.com/docs/extensions/reference/api/webRequest#event-onBeforeRequest)의 requestBody.raw 제공 범위는 POST/PUT입니다. 폼 데이터만 제공되거나 512KiB 한도를 넘으면 본문 해시를 확인한 것으로 표시하지 않습니다.

## 설치

1. 기존 JAR와 필요한 Next 설정·프로젝트를 보관합니다.
2. Burp Extensions에서 기존 Workbench/Next 로드를 해제하고 [0.52.1 JAR](../downloads/extensions/0.52.1/burp-workbench-kr-0.52.1.jar)를 로드합니다.
3. 브라우저 도우미를 사용한다면 [0.3.5 배포](../downloads/feature-mapper/0.3.5/)로 교체하고 사이트 연결을 확인합니다. 해당 도우미는 선택 사항입니다.
4. 검색의 묶음 펼치기·중요 표시, 응답 관찰 초기화 후 새 결과, Mapper의 본문 관측 사유를 확인합니다.

Next 0.52.0과 같은 Next 설정·기록 계열을 사용합니다. 사용법은 [0.52.0 상세 안내](RELEASE_0.52.0_NEXT_KR.md)를 참고할 수 있습니다. 과거 가이드의 버전 배지는 해당 배포 당시 화면입니다.

## 어디까지 확인하면 마무리하나

개선 아이디어가 더 이상 나오지 않는 것을 종료조건으로 삼지 않습니다. 이번 버전의 종료조건은 아래 다섯 가지입니다.

| 종료조건 | 확인할 근거 |
|---|---|
| 이번에 재현한 예약·취소 결함이 해결됨 | 수정 전 실패·수정 후 통과, 초기화 후 대기 상태와 입력/작업 예약 0 복귀 |
| 최종 소스의 기본·Windows 검사가 통과 | 전체 회귀·격리 HTTP 및 Windows 검색·저장·수집 검사 |
| 기존 실제 브라우저 실패가 해소됨 | POST raw SHA-256 대조 유지, PATCH 본문 미관측·중간 확신·유일 상관관계 검증 |
| 기존 핵심 자료 흐름이 유지됨 | Scope·원본·JS 보존/후반 위치·실행 취소·정책 revision·증거 ZIP 연결 회귀 |
| 배포물과 검증 소스가 같음 | JAR·소스 ZIP 지문, 0.52.0 및 이전 배포 보존 확인 |

필수 조건이 충족되면 이번 안정화를 마무리합니다. 추가 화면·새 탐지 기능·취향에 따른 배치는 다음 버전의 선택 개선으로 관리합니다. 기능 범위를 넓힌 뒤 같은 버전의 종료조건도 계속 늘리는 방식은 피합니다.

## 검증 결과와 남은 범위

로컬 최종 `dev.py release`는 95개 Java 그룹 3,222개 + HTTP 504개 = **3,726개**를 통과했습니다. Mapper는 Java **136개**, Node 도우미 **9개**를 통과했습니다. Workbench 화면 **342개**(두 테마·세 크기)의 잘림·축소·필수 영역 붕괴는 0개이고, 상태 시나리오 **78개**가 통과했습니다. Mapper 화면 **30개**도 통과했습니다. 배포 지문 검사와 이전 버전 보존 확인은 통과했습니다.

로컬 Chrome 154.0.8037.57은 실행 호스트의 소켓 생성 제한으로 시작 전에 중단됐습니다. 실제 브라우저 검사와 Windows 원격 검사는 아직 대기 중이며, 모든 종료조건이 충족됐다고 판정하지 않습니다. 원격 결과를 같은 소스 커밋에 연결해 후속 기록합니다.

[최종 검증 기록](VERIFICATION_0.52.1.json)에서 실제 실행한 환경과 미실행 항목을 구분합니다. 원격 CI 결과는 로컬 검사와 별개입니다. 실제 Burp GUI, Windows DPI/IME, Edge 수동 조작과 외부 운영 사이트 검증을 자동 회귀 통과로 대신하지 않습니다.
