## 검증 원칙

기능별 회귀와 전체 `python dev.py check`, 기존 화면 배치 검사, 새 통합 사용 흐름을 실행했습니다. 재시작·프로젝트 전환·대량 수집·작은 창·키보드·취소/오래된 결과 경합을 자동 검사했습니다. 기존 배치 기준을 낮추지 않았습니다.

검증 결과와 실제 실행 범위는 아래 및 [검증 JSON](VERIFICATION_0.53.4.json)에 기록합니다. 자동 Swing/API/격리 HTTP 검사와 실제 Burp GUI 조작을 구분합니다. 실제 Burp GUI·Windows DPI/IME·브라우저 수동 조작·Docker·외부 AI/OAST/BApp 서비스는 이번 검증에서 실행하지 않았습니다.

## 사용하기

1. **재현·증거 정리 → 증거 묶음**에서 제목·영향·재현 절차를 작성합니다. 현재 프로젝트에 자동 저장되며 아래 저장 상태를 확인합니다. **더 보기 → 작성 도움·저장 초안**에서 저장본 다시 불러오기·초기화·저장된 항목 메모를 확인합니다. 저장 실패나 손상 기록은 안내하며 자동으로 덮어쓰지 않습니다. 다시 시작하면 작성한 글이 복원되지만 HTTP 원본은 자동 연결되지 않습니다. 저장된 메모를 확인해 필요한 원본에 직접 연결하세요.
2. 증거의 제거·순서 변경·설명 편집·비우기는 **실행 취소 / 다시 실행**으로 최대 20단계 복구합니다. 다음 복구 작업명을 표시합니다. 새로운 원본 추가는 이전 편집 이력을 마무리하며, 프로젝트 변경·종료·재시작에는 원본을 가진 편집 이력을 넘기지 않습니다.
3. **요청·응답 목록 → 목록 고정**은 화면만 고정합니다. SCOPE·수집 설정과 원본 저장을 유지하며, **새 요청 N건**으로 반영하면 선택한 원본·스크롤을 보존합니다. 고정 상태에서 검색 조건을 바꾸면 고정된 원본 범위에서 검색합니다.
4. 요청을 여러 개 선택한 뒤 행 메뉴의 **모두 중요 표시 / 모두 중요 해제**를 사용합니다. 선택 수를 확인하고 **중요 변경 취소**로 최근 20회의 상태를 복구합니다. 메모는 유지하며 한 번에 최대 4,096건을 변경합니다.
5. 상단 **설정**에서 글자 크기 **100/125/150%**, 목록 간격과 배치 방향을 선택합니다. 열 순서·너비와 분할 비율은 현재 프로젝트에 저장합니다. **배치 초기화 / 화면 설정 초기화**로 복원합니다. 좁은 패킷 창은 Pretty/Raw/Hex/Render를 **패킷 표시 방식** 선택상자로, 대소문자·정규식 검색은 **검색 옵션** 메뉴로 제공합니다.
6. 트래픽 표에 포커스가 있으면 **Shift+F10 / 메뉴 키**로 행 메뉴, **Alt+I / Alt+Shift+I**로 중요 표시/해제, **Alt+M**으로 메모, **Alt+G**로 묶음 펼치기·접기, **Alt+Z**로 중요 변경을 취소합니다. 입력 편집기의 일반 단축키는 유지합니다.
7. **변환·비교 → 응답·데이터 비교**에서 비교하면 백그라운드로 계산합니다. **중지**는 비교만 중지하고 이전 성공 결과를 유지합니다. 입력·원본·프로젝트가 바뀌면 이전 계산이 새 결과를 덮어쓰지 않습니다. **비교 기준**으로 전체 비교 범위와 제한을 읽습니다. 작업 현황은 변경된 내용만 갱신하며 화면을 숨기거나 작업이 모두 끝나면 경과 갱신을 멈춥니다.
8. 증거를 선택해 **항목 설명**에서 이름·관찰 메모를 적고 적용합니다. 편집 중 메모도 초안에 보관하지만 보고서 반영은 적용 이후입니다. **더 보기 → 작성 도움·저장 초안 → 작성 양식 넣기**로 기존 글을 유지하며 사전 조건·재현 단계·관측 결과 양식을 넣고, 영향 입력란까지 정리합니다. 작성 확인은 누락 항목을 안내하며 **가림 미리보기 → ZIP 저장**으로 제출본을 만듭니다. 증거별 설명은 report.md·report.html·evidence.json에 반영합니다.
