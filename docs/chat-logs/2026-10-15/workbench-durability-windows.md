# Workbench 잔여 검증: 수집 내구성·실제 디스크 고갈·Windows

- 날짜: 2026-10-15 (Asia/Seoul)
- 작업: workbench-durability-windows

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 02. 도우미 · 원문

중단된 지점과 GitHub의 현재 상태를 확인한 뒤, 이어서 처리할 수 있는 작업부터 진행하겠습니다. 이전 작업 맥락은 Personal Context 스킬로 확인하고, 이번 변경도 날짜별 대화 기록과 함께 남기겠습니다.

## 03. 도우미 · 요약

확인해 보니 0.25.4는 이미 main에 병합됐고, 병합 후 자동 검사도 통과했습니다. JS 검사 오류, Mapper 통합, PDF와 Docker 수정은 완료된 상태입니다. 이번에는 남아 있는 수집 내구성·디스크 고갈·Windows 검증을 이어서 진행하겠습니다.

## 04. 도우미 · 요약

작은 임시 파일시스템의 실제 용량 부족, 기존 패킷 보존·공간 확보 후 재개를 확인할 하네스와 Windows Java 회귀·수집 검사를 준비. Windows PowerShell 확인과 Docker Desktop 전체 구동은 구분해 기록하기로 함.

## 05. 도우미 · 요약

새 수집 하네스의 로컬 사전 확인에서 524건을 모두 보관하고 저장 실패·처리 오류 0, 처음·중간·마지막 원본 바이트 복원과 unload 정리를 확인. PR #18에서 Windows와 실제 디스크 고갈 검사를 실행 중.

## 06. 사용자 · 원문

현재 수행하고 있는 작업 완료 후애 전체 소스코드 확인해보고 최적화 및 고도화가 필요한 부분 설명해줘

## 07. 도우미 · 요약

지금 진행 중인 검증과 main 반영을 먼저 마무리한 뒤, Workbench 전체 소스를 검토하겠습니다. 실제 코드에서 확인한 문제와 개선 후보를 구분하고, 최적화·고도화가 필요한 이유와 우선순위를 정리해 드리겠습니다.

## 08. 도우미 · 요약

Linux에서 실제 16 MiB tmpfs ENOSPC 13개와 180초 3,626건 수집 8개를 통과. Windows에서 기존 ExtenderTest의 worker 종료와 UI 행 게시 사이 대기 경쟁을 발견해 원본 assertion을 유지하는 테스트 복사본의 bounded EDT wait로 보완. 별도로 Windows PowerShell 5.1이 BOM 없는 한글 start.ps1을 파싱하지 못하는 문제를 확인하여 UTF-8 BOM과 실습 3.5.2 새 배포로 수정.

## 09. 도우미 · 요약

Windows 시작 스크립트 UTF-8 BOM 수정과 실습 3.5.2 새 Docker ZIP을 PR #18의 c3298fd에 반영. 기존 0.25.4 및 3.5.1 다운로드 보존. 수정본의 전체 release·Windows 검사를 다시 실행하고 통과 결과를 기록한 뒤 병합하기로 함.

## 10. 도우미 · 요약

Windows payload UI assertion이 bounded UI wait 뒤에도 한 실행에서 실패하여 대기 순서만으로 원인을 확정하지 않음. 일부 동일 커밋 실행은 통과. 기존 assertion을 유지한 채 callback 수·행 수·Scope 판정 수·상태를 출력하는 진단을 추가하여 확인하기로 함.

## 11. 도우미 · 요약

원인을 재현: Legacy FutureTask 결과가 반환된 뒤 busy를 해제하는 경쟁으로 완료된 요청 이후에도 다음 요청이 사용 중으로 거절됨. 수정 전 재현에서 성공 459건·잘못된 거절 5건. Workbench 0.25.5에서 콜백 반환/실패 전에 task별 1회 해제하도록 수정하고 5,000회 순차 전송 등 회귀 5개 추가. 임시 UI 테스트 복사본 방식은 제거하고 원본 Windows 전체 검사로 돌아감. CI 전체 release 통과 후 새 JAR·소스 ZIP을 같은 작업 브랜치에 기록하도록 준비.

## 12. 도우미 · 요약

수정 후 독립 재현에서 100,000회 순차 전송의 잘못된 busy 거절 0건을 확인. 자동 승인 검토가 쓰기 권한 CI의 자동 커밋을 거절해 해당 workflow와 스크립트를 제외하고 직접 소스·배포 파일 커밋으로 전환. 해시 검증된 Maven 런타임 의존성만 담은 로컬 임시 WAR로 현재 실습 소스를 컴파일하여 0.25.5 전체 release를 실행 중. 임시 WAR는 업로드하지 않음.

## 13. 도우미 · 요약

0.25.5 전체 release 1,796개와 배포 해시·소스 대응 검사를 통과. JAR·소스 ZIP을 직접 업로드. Windows PowerShell 6개 assertion은 이미 통과했으나 의도적으로 만든 실패 코드 17이 shell 종료 코드로 남는 하네스를 보완. 이전 배포 파일과 임시 런타임 WAR는 변경·업로드하지 않음.

## 14. 도우미 · 요약

자동 승인 검토가 저장소 소유권 확인 후에도 최종 소스·배포 파일 게시를 거절했습니다. 미승인 코드 업로드 사유로 최종 커밋과 병합은 진행되지 않았습니다.
