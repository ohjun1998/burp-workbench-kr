# Workbench 전체 P1·P2 최적화 및 0.26.0 업데이트

- 날짜: 2026-10-15 (Asia/Seoul)
- 작업: workbench-optimization-0260

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 도우미 · 요약

이전 작업에서 Workbench0.25.5·실습3.5.2를 PR18로 main에 병합했습니다. 전체 소스 검토에서 수집·화면·분석 분리, Mapper 인덱스·저장 잠금, 큰 증거 메모리, JS 캐시 총량, 화면 증분 갱신, 구조·버전 관리의 P1·P2 우선순위를 제안했습니다.

## 02. 사용자 · 원문

## 03. 도우미 · 원문

## 04. 도우미 · 요약

기존 main65d1976의 빌드·수집 내구성·Docker 검사가 모두 통과한 것을 확인했습니다. 새 account-a/optimization-0260-20261015 작업 브랜치에서 전체 P1·P2를 구현하고 Workbench0.26.0·Mapper0.2.0을 준비합니다. 원본 무제한 보관과 기존 다운로드를 유지합니다.

## 05. 도우미 · 요약

수집은 디스크 색인·배치 행 갱신·백그라운드 관찰, Mapper는 후보 인덱스·일관된 스냅샷 저장, 증거는 원본 디스크 참조·스트리밍 ZIP, JS는24MiB 추정 캐시·16MiB 작업 스냅샷 예산을 구현했습니다. Activity·Assessment는 증분 갱신·캐시 무효화를 적용하고 버전 기준을 BuildInfo로 통합했습니다.

## 06. 도우미 · 요약

각 영역 회귀 검사와 성능 비교를 실행했습니다. 교차 검토에서 초기화 전 결과의 늦은 반영, 소스 선택 변경 후 패킷 미리보기 덮어쓰기, 목록 이벤트 예외 후 복구를 보완하고 전체 릴리스·화면·패키징 검증을 준비합니다. 성능 측정은 API 어댑터이며 실제 Burp GUI/다시간 결과로 주장하지 않습니다.

## 07. 도우미 · 요약

전체 Java 회귀 1,445개와 페이로드 HTTP132개가 통과했습니다. 화면 검사에서 최소 창 크기의 JS 미리보기 높이76px 문제를 확인하고 상태 표시를 간결하게 조정해97px로 복구했습니다. 기준80px를 유지한 채 별도 검증을 통과했으며 전체release와156화면 검증을 진행합니다. 수집3,900건 원본 누락·오류0, 화면 배출과 Mapper 조회 개선을 확인했고 인덱스 디스크·입력 비용도 함께 기록합니다.

## 08. 도우미 · 요약

최종 통합 검사를 완료했습니다. Workbench Java1,445·페이로드132·전체기능HTTP100·모의진단266으로1,943개, Mapper Java75·Node7, Swing108화면·안내48화면 모두 통과했습니다. 버전별 JAR·소스 ZIP 생성과 해시/소스 지문 검증을 마쳤습니다. 기존 다운로드를 보존하고 날짜별 기록과 함께 PR을 만든 뒤 원격 CI를 확인합니다.
