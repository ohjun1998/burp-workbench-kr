# Workbench 남은 단계 진행 · 0.25.4

- 날짜: 2026-10-15 (Asia/Seoul)
- 작업: workbench-remaining

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 요약

기존 요청: 0.21.0 대신 account-a/0.25.2-unlimited-traffic 계보에서 수정하고 main까지 반영. GitHub에 올리는 모든 작업에는 관련 대화를 한국 날짜별로 함께 기록.

## 02. 사용자 · 원문

github에 workbench 현재 업데이트 사항 알려주고, 남아있는 사항 알려줘

## 03. 사용자 · 원문

남은 단계 업데이트 해줘

## 04. 도우미 · 요약

현재 main과 미병합 작업을 확인하고 0.25.4에서 JS 검사 대기 순서, 실제 Burp Scope 설정 내보내기 생략 호환성, Feature Mapper 통합, 읽기 쉬운 PDF와 검증·인수인계를 진행. 기존 버전의 다운로드와 다른 계정의 브랜치는 보존.

## 05. 도우미 · 요약

실제 Burp Community 2026.3.3의 공개 Scope API와 loopback HTTP를 확인. Scope 목록을 내보내지 않는 경우 관측 URL에 기반한 보완 경로를 구현하고, 체크 해제·삭제한 부모 및 native 제외 규칙이 계속 적용되도록 검사. 아직 관측하지 않은 URL과 고급 규칙 전체의 원형 열거 한계는 문서에 명시.

## 06. 도우미 · 요약

로컬 릴리스 검사 1,791개, 패키징 검사 4개, Swing 기본·안내 156화면, JS 검사 20회 반복을 통과. 실제 Burp 15개 검사와 300초 수집에서 최종 3,555행, drop·write error 0, unload 임시 보관 정리를 확인. Mapper Java 48개·Node 7개·실제 Burp 12개도 확인. 26쪽 PDF 전체를 렌더링해 검토.

## 07. 도우미 · 요약

업로드 중 원본 내부 테스트 로그에 대한 자동 승인 검토가 거절되어 해당 원본을 제외. 연결 계정과 비공개 저장소 소유권·권한을 확인하고, 요청된 소스·배포 자료와 민감한 원본이 없는 숫자 중심 검증 요약만 게시하는 방식으로 진행.

## 08. 사용자 · 원문

남은 단계 다시 진행해줘

## 09. 도우미 · 요약

검증한 0.25.4 결과의 업로드 상태를 복구해 이어서 진행. JAR·소스 ZIP·PDF와 예시 이미지의 blob 업로드를 완료했으며, main에는 아직 반영하지 않았음을 알림.

## 10. 사용자 · 원문

남은 단계 다시 진행해줘

## 11. 도우미 · 원문

검증을 마친 0.25.4 작업을 이어서 진행하겠습니다. 업로드 상태를 확인한 뒤 변경 사항과 날짜별 작업 기록을 커밋하고, GitHub 검사와 main 반영까지 마무리하겠습니다.

## 12. 도우미 · 원문

JAR·소스 ZIP·PDF 업로드는 완료되어 있고, main에는 아직 변경이 없습니다. 로컬에서는 1,791개 기능 검사와 실제 Burp의 5분 수집 검사를 통과했습니다. 이제 대화 기록과 검증 요약을 함께 커밋하고, Docker 전체 구성과 브라우저 검사를 GitHub에서 확인하겠습니다.

## 13. 도우미 · 요약

PR #17을 생성. 기존 760개 파일을 보존하고 15개 수정·68개 추가, 날짜별 대화 기록을 포함. 실제 Chromium 보조 확장 및 production Mapper/Bridge fixture 13개와 배포 바이트 비교를 통과했으며 Workbench 원격 전체 검사도 통과.

## 14. 도우미 · 요약

첫 Docker 검사에서 컨테이너는 정상이나 호스트 8088 접속이 실패. 초기에는 준비 시점 문제를 의심했으나 추가 로그에서 published ports가 비어 있음을 확인. 실습 3.5.1로 웹·프로토콜의 접속용 bridge와 Nginx healthcheck를 추가하고, DB·WAS 내부망 및 127.0.0.1 제한을 유지하여 다시 검증하기로 함.

## 15. 사용자 · 원문

남은 단계 다시 진행해줘

## 16. 도우미 · 요약

Docker 3.5.1의 네트워크 수정과 새 ZIP, 실제 호스트 포트·TLS·HTTP/2 검사를 PR #17에 반영. 기존 Docker 3.5.0·확장 0.25.4 파일을 덮어쓰지 않고 새 버전으로 추가. 수정본 전체 검사를 다시 실행 중이며, Mapper 실제 Chromium 검사는 통과.

## 17. 도우미 · 원문

수정본의 GitHub 검사를 모두 통과했습니다. Oracle HTTP 54개, Nginx, 네 포트의 127.0.0.1 게시 상태, TLS·HTTP/2와 Mapper의 실제 브라우저 동작까지 확인했습니다. 결과를 검증 문서와 대화 기록에 반영한 뒤 main에 병합하겠습니다.
