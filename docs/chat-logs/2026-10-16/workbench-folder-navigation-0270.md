# Workbench 0.27.0 · 왼쪽 폴더 메뉴와 폭 조절·숨기기

- 날짜: 2026-10-16 (Asia/Seoul)
- 작업: workbench-folder-navigation-0270

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

개발중인 extension 들이 무분별하게 나열되어있는데, extenison의 성격에 맞게 폴더 형태로 분류해서 제시해줄래?

## 02. 도우미 · 요약

처음에는 Workbench 내부 기능과 별도 개발 프로젝트를 함께 분류했고, 요청·응답 목록 내부 기능인 SCOPE 관리를 별도 항목처럼 제시했다.

## 03. 사용자 · 원문

extension 목록은 이게 다인데, SCOPE 관리는 어디서 나온겨...

## 04. 도우미 · 요약

첨부 화면에서 실제 상단 메뉴 10개를 확인했다. SCOPE 관리를 잘못 분리한 것을 정정하고, 트래픽 / 탐색·정보 수집 / 보안 분석·검증 / 데이터 도구 / 점검 관리·증거의 5개 폴더로 다시 분류했다. 왼쪽 폴더에서 선택하면 오른쪽에 해당 기능을 표시하는 방식을 제안했다.

## 05. 사용자 · 요약

왼쪽 폴더 목록에서 펼쳐 선택하고 오른쪽에 해당 기능이 표시되는 구성을 이미지로 요청했다.

## 06. 도우미 · 요약

첨부한 어두운 상단 메뉴 화면을 참고해, 정확히 기존 10개 메뉴만 5개 폴더로 묶은 UI 시안 이미지를 생성해 제시했다. 구현 완료 화면이라고 표현하지 않았다.

## 07. 사용자 · 원문

현재 목록들은 상위에 배치되어있는데, 왼쪽으로 놓는 것도 괜찮을려나?

## 08. 도우미 · 요약

긴 이름의 메뉴 10개를 찾기 쉽게 묶을 수 있다고 설명했다. 가로 작업 공간을 확보하도록 기본 약 220px의 메뉴 폭 조절, 메뉴 숨기기·다시 보기, 기능 이동 전후 입력값·결과·선택 상태 유지를 추천했다.

## 09. 사용자 · 원문

폭을 조절하고 숨길 수 있는 왼쪽 폴더 메뉴로 구성해서 업데이트 해줘

## 10. 도우미 · 원문

기존 10개 기능을 왼쪽 폴더 메뉴로 옮기고, 메뉴 폭 조절과 숨기기·다시 보기를 추가하겠습니다. 현재 코드와 GitHub 상태를 확인한 뒤 새 버전 배포 파일과 날짜별 대화 기록까지 업데이트하겠습니다.

## 11. 도우미 · 요약

현재 main af2936e351055638e1a7c27e96fdff3ffe4cec75에서 새 account-a/0.27.0-folder-navigation 브랜치를 만들었다. 기존 페이지 인스턴스와 전환 경로를 유지하며 폴더 메뉴를 추가했다. 우클릭·기능 안내 이동과 폴더 선택을 동기화하고, 메뉴 폭·숨김 상태를 Burp 환경설정에 저장한다.

## 12. 도우미 · 요약

10개 기능 이동·숨기기·폭 복원·입력값 및 선택 상태 유지의 초기 검사를 통과했다. 1024px 화면에서 JS 입력 영역이 좁아지는 것을 발견해 최근 분석 선택기의 폭을 줄여 도구 영역을 확보했다. 작은 화면 재검사 통과 후 정식 0.27.0 release 및 전체 화면 검사를 진행한다고 안내했다.

## 13. 도우미 · 요약

0.27.0 로컬 정식 release의 Workbench 1,988개, 별도 Mapper Java75·Node7, 운영 Swing126화면·안내48화면과 패키징4개·소스 지문 검사가 통과했다. 새 메뉴 회귀40개는 Workbench Java 합계에 포함한다. 실제 운영 Swing 화면 두 장과 변경 안내·검증 기록을 추가했다. GitHub PR 및 원격 검사 확인 후 main 반영을 진행한다.
