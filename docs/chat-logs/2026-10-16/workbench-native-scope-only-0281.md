# OFF/SCOPE 전용 수집과 이미지 전용 레이아웃 시안

- 날짜: 2026-10-16 (Asia/Seoul)
- 작업: workbench-native-scope-only-0281

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

이미지 처럼 extension 좀 이쁘고 가독성 있게 디자인 해줄 수 있어?

- 폴더 모양 아이콘
- 선택하면 색깔 들어가는 것

## 02. 사용자 · 원문

테마나 글꼴, 크기, 레이아웃 구조, ON / OFF / SCOPE 불 들어오는 것 기타 등
똑같이는 구현해내기 힘든가? 폴더 색깔도 적용된 거는 아무런 색이 없는데

## 03. 사용자 · 원문

우리 이거 OFF > SCOPE 기능만 살리기로 했던걸로 기억하는데, 해당 프롬프트 찾아볼래?

## 04. 도우미 · 요약

앞선 작업에서 0.28.0 전체 테마와 3개 수집 모드를 배포했습니다. 이후 과거 2개 모드 합의 프롬프트를 찾아보았으나 확인 가능한 검색 결과에서는 찾지 못했습니다.

## 05. 사용자 · 원문

그렇구만... 그럼 OFF / SCOPE 만 남기고, OFF는 트래픽 수집 금지, SCOPE는 HTTP history에서 add to scope 한 URL들만 수집하도록 설정해줘

그리고 현재 레이아웃 배치는 요청, 응답 목록 글자 크게 되어있는거 삭제시키고 검색 INPUT을 위에 올려서 밑에 트래픽/요청/응답패킷을 위로 늘려줘, 검색 텍스트도 없애고, 레이아웃 배치는 소스코드에 적용하지말고 이미지로만 보여줘

## 06. 도우미 · 원문

수집 모드는 코드에서 **OFF ↔ SCOPE** 두 가지만 남기고, SCOPE는 Burp의 **HTTP history → Add to scope**로 지정한 대상만 수집하도록 바꾸겠습니다. 레이아웃은 코드에 적용하지 않고, 큰 제목과 ‘검색’ 글자를 없애 검색 입력창과 패킷 영역을 위로 올린 이미지로만 보여드리겠습니다.

## 07. 도우미 · 요약

현재 수동 Workbench URL 규칙이 수집을 허용하는 경로를 확인하고 네이티브 Scope로 제한하며 시작 상태를 OFF로 정했습니다. 실시간·History 가져오기·수동 분석 관찰 경로를 검사했습니다.

## 08. 도우미 · 요약

이미지 생성 스킬로 현재 어두운 화면을 편집한 시안 1장을 제시했습니다. 큰 페이지 제목·중복 경로·독립 검색 라벨을 제거하고 검색 입력·SCOPE 버튼을 상단에 정렬했으며 트래픽과 요청/응답 편집 영역을 위로 확장했습니다. 이 배치는 소스에 적용하지 않았습니다.

## 09. 도우미 · 요약

OFF의 디스크 저장·수동 가져오기 차단, SCOPE의 네이티브 범위·제외·체크·삭제·조회 실패 제한과 Workbench 수동 URL 우회 차단을 검사했습니다. 새 배포물 패키징과 원격 검증을 진행합니다.

## 10. 도우미 · 원문

전체 배포 검사 **2,016개**를 통과했고 0.28.1 JAR·소스 파일을 생성했습니다. 이제 GitHub PR에서 원격 검사를 진행합니다. 레이아웃 변경은 이미지 시안에만 남겨 두었습니다.
