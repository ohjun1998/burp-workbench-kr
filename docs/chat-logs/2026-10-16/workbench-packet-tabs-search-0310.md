# 승인 시안 적용 · Pretty·Raw·Hex·Search 0.31.0

- 날짜: 2026-10-16 (Asia/Seoul)
- 작업: workbench-packet-tabs-search-0310

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

첨부한 이미지처럼 Pretty, Raw, Hex 만들고 Search 기능도 만들어서 이미지만 먼저 뽑아줘

## 02. 도우미 · 원문

첨부 이미지를 확인해 Pretty·Raw·Hex 탭과 Search가 있는 요청·응답 패널 시안을 만들겠습니다. 소스코드는 바꾸지 않고 이미지로만 보여드리겠습니다.

## 03. 도우미 · 원문

이미지 생성 스킬로 기존 Workbench 화면에 맞춘 시안을 만들겠습니다. 양쪽 패킷 창에 Pretty·Raw·Hex 탭을 두고, 아래에는 검색창·이전/다음 결과·일치 개수를 배치하겠습니다.

## 04. 도우미 · 원문

이미지 시안입니다. 양쪽 패킷 창에 Pretty·Raw·Hex 탭과 하단 Search를 배치했습니다.

검색 결과 강조, 이전·다음 이동, 일치 개수, 대소문자·정규식 옵션을 포함했으며 소스코드는 변경하지 않았습니다.

## 05. 사용자 · 원문

좋다 이렇게 소스코드 적용해줘

## 06. 도우미 · 원문

확정한 시안을 소스코드에 적용하겠습니다. 요청·응답 각각에 Pretty·Raw·Hex 탭과 검색창을 연결하고, 검색 결과 강조·이전/다음 이동·일치 개수·대소문자·정규식 옵션까지 동작하도록 구현하겠습니다.

## 07. 도우미 · 원문

시안과 같은 위치에 탭과 검색바가 고정되도록 전용 패킷 뷰를 구성하고 있습니다. Pretty는 읽기 좋게 정렬하고 Raw·Hex는 원본 바이트를 기준으로 표시하겠습니다. 검색은 백그라운드에서 처리해 긴 응답이나 복잡한 정규식 때문에 화면이 멈추지 않도록 하겠습니다.

## 08. 도우미 · 원문

탭과 검색 동작을 연결했습니다. 보기 방식을 바꿔도 원본 패킷은 그대로 유지하고, 검색어는 선택한 Pretty·Raw·Hex 화면에서 다시 찾도록 했습니다. 기존 Burp 기본 편집기도 ⋯ 버튼으로 열 수 있게 유지하겠습니다.

## 09. 도우미 · 원문

패킷 보기·검색 전용 회귀 검사 35개가 통과했습니다. Raw의 줄바꿈 보존, Hex의 실제 바이트 표시, 검색 이동과 순환, 잘못된 정규식 처리, 패킷을 바꾼 뒤 오래된 검색 결과가 섞이지 않는 동작을 확인했습니다. 현재 전체 기능 검사와 작은 화면의 배치를 확인하고 있습니다.

## 10. 도우미 · 요약

첨부 이미지는 배치·스타일 참고로만 사용했습니다. 실제 사이트·쿠키·패킷 값은 복제하지 않고 합성 example.test 데이터로 시안과 운영 화면을 검증했습니다. 코드 변경은 승인 이후 시작했습니다.

## 11. 도우미 · 원문

작은 화면에서도 탭과 검색창이 잘리지 않는 것을 확인했습니다. 화살표·줄바꿈·더 보기 아이콘은 글꼴에 따라 깨지지 않도록 직접 그리게 했고, Hex는 바이트 열을 고정해 가로로 스크롤하도록 정리했습니다. 이 최종 코드로 배포 검사를 다시 진행하고 있습니다.

## 12. 도우미 · 원문

최종 배포 검사 2,118개가 통과했습니다. 새 패킷 보기·검색 검사 39개도 포함됐습니다. 지금은 구현 코드로 만든 Pretty·Raw·Hex 화면을 마지막으로 확인하고 있으며, 이어서 배포 파일과 작업 기록을 GitHub에 반영하겠습니다.
