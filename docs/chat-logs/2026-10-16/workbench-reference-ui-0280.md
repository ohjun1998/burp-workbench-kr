# Workbench 0.28.0 전체 화면·수집 상태등·호스트 스타일 복원 작업 대화

- 날짜: 2026-10-16 (Asia/Seoul)
- 작업: workbench-reference-ui-0280

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 요약

이전 0.27.1은 왼쪽 메뉴 아이콘·선택 강조 중심으로 반영됐지만, 사용자가 올린 실제 화면에는 회색 폴더·기본 글꼴·목록 왼쪽 배치·평범한 ON 버튼이 보였다. 별도 시안은 어두운 테마, 주황색 폴더, 큰 제목, 목록 위/요청·응답 아래, 색상 상태등을 보여준다.

## 02. 사용자 · 원문

테마나 글꼴, 크기, 레이아웃 구조, ON / OFF / SCOPE 불 들어오는 것 기타 등
똑같이는 구현해내기 힘든가? 폴더 색깔도 적용된 거는 아무런 색이 없는데

## 03. 도우미 · 원문

시안에 훨씬 가깝게 구현할 수 있습니다. 앞선 변경은 왼쪽 메뉴에만 집중해서 전체 테마·글꼴·배치와 수집 상태 표시까지 맞추지 못했습니다. 첨부하신 두 화면을 비교하고, 폴더 색상이 실제 Burp에서 보이지 않는 원인도 확인해 함께 수정하겠습니다.

## 04. 도우미 · 원문

첨부 화면에서는 시안과 달리 기본 회색 아이콘과 좁은 메뉴 간격이 보입니다. Burp가 화면 스타일을 다시 적용해도 아이콘·글꼴이 유지되도록 보완하고, 트래픽 화면은 목록 위·요청/응답 아래, 수집 버튼은 ON 초록·OFF 빨강·SCOPE 주황으로 맞추겠습니다.

## 05. 도우미 · 원문

전체 화면의 배경·카드·버튼·표 스타일과 수집 상태 표시를 적용 중입니다. 글꼴은 Burp 기본 글꼴의 영향을 줄이도록 확장에 포함된 고딕체로 통일하고 있습니다. 폴더 색상 문제는 호스트가 메뉴 렌더러를 교체하는 상황을 재현해 복원 여부까지 검사하겠습니다.

## 06. 도우미 · 원문

트래픽 목록을 위로 옮기고 요청·응답을 아래에 나란히 배치한 화면을 확인했습니다. ON·OFF·SCOPE는 각각 색이 다른 상태등으로 표시됩니다. 스타일 재적용 시험에서는 폴더 색상 복원을 확인했고, 함께 발견된 탭 갱신 오류도 보완하고 있습니다.

## 07. 도우미 · 원문

1024px 화면에서도 새 배치가 정상적으로 보이는 것을 확인했습니다. 권한 비교 화면에서 요청·응답 영역이 눌리던 부분도 조정했습니다. 이제 코드를 고정하고 전체 검사와 밝은·어두운 테마 화면 검증을 진행하겠습니다.

## 08. 도우미 · 원문

최종 밝은·어두운 테마 화면 144개와 안내창 48개가 모두 통과했습니다. 호스트가 메뉴·버튼 스타일을 교체한 뒤에도 색상과 글꼴이 복원됐고, 탭 갱신 오류도 해결했습니다. 배포용 전체 회귀 검사를 마무리하고 있습니다.

## 09. 도우미 · 원문

전체 회귀 검사 2,008개가 통과했습니다. 새로 추가한 20개 검사는 상태등 색상, 호스트 스타일 변경 후 폴더·글꼴 복원, 입력값 유지와 화면 오류 0건을 확인합니다. 0.28.0 JAR·소스와 변경 화면을 GitHub에 올리겠습니다.
