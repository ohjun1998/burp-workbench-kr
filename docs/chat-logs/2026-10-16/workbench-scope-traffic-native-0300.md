# SCOPE 편집·조밀한 트래픽·Burp 패킷 보기 0.30.0

- 날짜: 2026-10-16 (Asia/Seoul)
- 작업: workbench-scope-traffic-native-0300

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

요청,응답 목록 내 SCOPE 목록에서 URL 추가하니까 트래픽 SCOPE에 반영이 안되는데 확인해 볼래?
그리고 추가한 URL 수정도 가능하게 해줘

## 02. 도우미 · 원문

SCOPE 목록의 ‘URL 추가’가 수집 조건에 어떻게 연결되는지 확인하겠습니다. 수동 추가 URL이 트래픽 수집에 반영되도록 수정하고, 등록한 URL을 편집하는 기능도 함께 넣겠습니다.

## 03. 도우미 · 원문

원인을 확인했습니다. 현재 버전은 수동 URL을 저장해도 트래픽 수집에서는 Burp에 등록된 범위만 확인하고 있습니다. 수동으로 추가한 URL도 SCOPE 모드에서 즉시 적용되도록 연결하고, 목록에서 URL을 선택해 수정할 수 있게 바꾸겠습니다. OFF의 수집 중지는 유지합니다.

## 04. 도우미 · 원문

수동 URL을 수집 조건에 연결했고, `URL 수정` 버튼을 추가했습니다. 수정할 때 체크 상태를 유지하고, URL을 바꾸면 이전 주소는 범위에서 빠지도록 처리했습니다. 이제 실제 수집 콜백으로 추가·수정·체크 해제 동작을 검사하고 있습니다.

## 05. 도우미 · 원문

추가·수정·체크 해제·기존 History 가져오기 회귀 검사가 통과했습니다. 작은 창에서는 수정 입력칸이 목록을 많이 가리는 부분이 있어 배치도 줄였습니다. 새 배포본으로 전체 검사와 밝은/어두운 테마 화면을 확인하고 있습니다.

## 06. 사용자 · 원문

요청, 응답 목록에 트래픽의 간격을 좀 더 촘촘하게 해서 더 많은 목록을 볼 수 있게 하고 고딕체로 변경해줘, 그리고 요청/응답 패킷의 텍스처를 가독성 좋게 burp suite에서 제공하는 스타일도 적용해줘

## 07. 사용자 · 요약

트래픽 목록의 넓은 행, Burp HTTP history의 조밀한 행, Burp Pretty 요청·응답 편집기 화면을 참고 이미지로 제공했습니다. 이미지의 실제 사이트·패킷·인증정보는 이 작업 기록이나 배포 자료에 복제하지 않습니다.

## 08. 도우미 · 원문

진행 중인 SCOPE 수정에 이어 화면 변경도 함께 반영하겠습니다. 트래픽 행 간격을 줄이고 고딕 글꼴을 적용하며, 요청·응답 패킷 영역은 Burp가 제공하는 메시지 편집기를 사용할 수 있는지 확인하겠습니다.

## 09. 도우미 · 원문

첨부 화면을 확인했습니다. 트래픽은 24px 행 높이와 13px 나눔고딕으로 조밀하게 표시하겠습니다. 패킷 영역은 현재 Burp 편집기를 생성만 하고 자체 미리보기를 표시하고 있어, Burp의 기본 요청·응답 편집기를 실제 화면에 연결하겠습니다. 그러면 Burp의 Pretty·Raw·Hex 보기와 구문 강조를 사용할 수 있습니다.

## 10. 도우미 · 원문

트래픽 행을 줄여 같은 높이에 약 50% 더 많은 항목이 보이도록 적용했습니다. 요청·응답에는 원본 패킷을 Burp 기본 편집기로 전달하며, 편집기 내부의 색상과 글꼴은 Burp 설정을 따르게 했습니다. SCOPE 추가·수정 기능까지 묶어 통합 검증을 진행 중입니다.

## 11. 도우미 · 원문

통합 배포 검사 2,078개와 화면 202개의 배치 검사가 통과했습니다. 수동 URL의 SCOPE 수집·수정, 조밀한 고딕 목록, Burp 기본 패킷 편집기 연결을 0.30.0으로 묶었습니다. 이제 배포 파일과 GitHub 자동 검사를 확인하겠습니다.
