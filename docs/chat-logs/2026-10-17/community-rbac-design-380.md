# 커뮤니티 3.8.0 — 공통 권한 정책과 화면 고도화

- 날짜: 2026-10-17 (Asia/Seoul)
- 작업: community-rbac-design-380

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

국내에서 보편적으로 많이 적용하는 권한 체크 방법은 어떻게 돼?

## 02. 도우미 · 요약

전자정부 표준프레임워크의 사용자·역할·보호 자원 관리와 OWASP의 매 요청·객체별 서버 인가 검사 기준을 설명했습니다. 역할 기반 권한과 기능·데이터 소유권·담당 게시판·업무 상태 검사를 결합하고, 화면의 메뉴 표시는 서버 권한 검사와 함께 적용하는 구성을 제안했습니다.

## 03. 사용자 · 원문

권한 체크 부분 적용시켜주고, 전체적으로 사이트 디자인이나 레이아웃들도 고도화 시켜줘

## 04. 도우미 · 요약

공통 권한 정책과 API별 권한 선언을 적용하고 작성자·담당 게시판 범위를 같은 정책으로 정리했습니다. 정상 API의 권한 선언 누락은 기본 거부하며, 기존 취약점 실습은 명시된 취약 경로에서 비교 기능을 유지합니다. 관리자 권한표·최근 접근 기록·게시판 운영자의 담당 목록과 권한 기반 메뉴를 추가했습니다.

## 05. 도우미 · 요약

왼쪽 탐색과 넓은 본문, 카드형 게시글·강의, 정돈된 관리 표, 작은 화면의 메뉴 서랍을 구현했습니다. 로그인 화면도 새 레이아웃과 실습 계정 선택·비밀번호 표시로 개선했습니다. 새 권한 경계를 포함한 실제 H2 HTTP 검사 384개와 기존 JS 분석 호환 63개, 로그인 스크립트 4개가 통과했습니다. 실제 Chromium의 화면·흐름 검사를 준비 중입니다.

## 06. 도우미 · 요약

실제 Chromium 검사 66개와 화면 18장을 확인했습니다. 최초 브라우저 검사는 댓글 저장 후 화면 갱신을 기다리지 않아 실패했고, 확인된 화면에 댓글이 저장되어 있어 대기 조건을 보완했습니다. 확장한 내 권한 검사에서는 공통 권한의 예상 개수(8개)를 바로잡은 뒤 전부 통과했습니다. 작은 화면의 표는 내부 가로 스크롤을 제공하고, 글자 크기를 보완했습니다. 작업 중 main에 반영된 Workbench 0.37.4 소스와 배포를 보존하고 전체 release 검사 및 3.8.0 실행 ZIP을 준비하고 있습니다.

## 07. 도우미 · 요약

사이트 3.8.0을 PR #51로 전달했습니다. 정상 API의 공통 RBAC·기능·객체 권한 검사, 내 권한·관리자 권한표·최근 접근 기록, 커뮤니티·로그인·관리·모바일 화면을 적용했습니다. 실제 H2 HTTP 384개, 로그인 JS 4개, 분석기 호환 63개, 실제 Chromium 66개와 화면 18장, 패키징 6개 및 전체 release 2,478개(Java 1,978·HTTP 132+102+266)를 통과했습니다. 최종 코드 b7747b74b5e6fb838a06d657c2355e9a3c889dc9의 원격 Build·Linux/Windows·Docker/Oracle/Nginx·Chromium 검사도 모두 성공했습니다. 최종 기록은 세 문서만 갱신하여 검증한 소스·ZIP·화면을 유지하고 main에 반영합니다. 최신 확장 0.37.4·Mapper 0.3.1과 이전 배포를 보존했습니다.
