# 커뮤니티 3.7.1 — 단독 로그인과 권한별 연결

- 날짜: 2026-10-17 (Asia/Seoul)
- 작업: community-standalone-login-371

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

단독 로그인 페이지에서 관리자/일반 사용자로 로그인 시 구분해서 커뮤니티 사이트에 연결되게 소스코드 수정해줘

## 02. 도우미 · 원문

로그인 화면을 별도 페이지로 분리하고, 로그인한 계정의 실제 권한에 따라 커뮤니티 메뉴가 표시되도록 수정하겠습니다. 먼저 최신 소스의 로그인 흐름을 확인하겠습니다.

## 03. 도우미 · 요약

기존 커뮤니티 상단 로그인을 /login 단독 화면으로 옮기고 관리자/일반 사용자 유형을 선택하게 구현했습니다. 실제 서버 권한을 검사한 뒤 관리자는 사용자 관리, 일반 사용자는 게시글 목록으로 연결합니다. 기존 /admin/login, /user/login 별칭도 연결했습니다.

## 04. 도우미 · 요약

현재 소스 HTTP 검사 307개·로그인 스크립트 흐름 4개·기존 Workbench 분석기 호환 63개를 통과했습니다. 전체 release 검사와 3.7.1 실행 ZIP 생성을 진행하고 있습니다. 실제 브라우저 화면이나 Burp GUI를 실행한 결과로 표현하지 않습니다.
