# 커뮤니티 통합 및 취약점 실습 3.7.0

- 날짜: 2026-10-17 (Asia/Seoul)
- 작업: community-unified-lab-370

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

현재 커뮤니티 테스트 사이트에 관리자, 사용자, 커뮤니티 페이지가 나누어져 있는데, 관리자로 로그인하면 커뮤니티 사이트에서 관리자 권한으로 사용할 수 있는 기능(사용자 관리, 게시글 삭제, 신고 확인, 강의 수락/거절 등 여러가지)들과 일반 사용자 권한으로 사용할 수 있는 기능(게시글 작성, 댓글, 신고, 강의 신청 등)들을 커뮤니티 사이트에서 사용할 수 있도록 합쳐줄래?

소스코드에 적용하지는 말고 계획만 알려줘

## 02. 도우미 · 요약

관리자와 일반 사용자가 같은 커뮤니티에 로그인하고 역할에 따라 메뉴를 표시하는 통합 계획을 제시했다. 관리자는 공통 기능도 사용하며, 사용자·게시글·댓글·신고·강의·수강 신청·본인 정보와 서버 권한 검사, admin/alice/bob 계정 비교를 포함했다. 이때 코드 적용은 보류했다.

## 03. 사용자 · 원문

이대로 소스코드에 적용해주는데, 메뉴 하나 추가해서 일부로 취약하게 만들어서 취약점 진단 테스트할 때 용이하게 사용할 수 있게 해줘

## 04. 도우미 · 원문

커뮤니티 안에서 관리자·사용자 기능을 함께 사용할 수 있도록 통합하겠습니다. 추가 메뉴는 취약점 진단 실습용으로 구성하고, 먼저 현재 소스와 실행 구조를 확인하겠습니다.

## 05. 도우미 · 요약

현재 사이트 3.6.0과 최신 main b072bc2를 확인했다. 기존 기능을 재사용하고 신고·강의·사용자 관리와 취약점 실습 메뉴를 추가하기로 했다. 정상 화면은 수정 API를 사용하고 실습 메뉴에서 취약·수정 동작을 비교하도록 안내했다.

## 06. 도우미 · 요약

통합 화면과 API 구현 후 실제 HTTP 세션 검사 237개가 통과했다. 기존 Workbench 회귀에서 새 JavaScript의 분석기 호환 문제가 발견되어 지원 구문과 요청 래퍼를 조정했다. 관련 회귀 63개 통과 및 POST 로그인·댓글 경로 추출을 확인하고 전체 release 검증을 진행했다.

## 07. 도우미 · 요약

회원 이메일 수정까지 포함한 통합 HTTP 검사 242개가 통과했다. 검사 도중 소스를 보완하여 첫 release 감사의 소스 불변성 확인이 실패했고, 최종 소스를 고정한 뒤 전체 release를 다시 실행했다. 브라우저·Docker가 없는 환경이므로 화면·XSS 실행·Docker 기동을 HTTP 검증과 구분해 기록하기로 안내했다.

## 08. 도우미 · 요약

기존 회귀·HTTP 검사 2,442개, 통합 기능·권한 검사 242개, 패키징 회귀 6개가 통과했다. 기존 버그바운티 manifest를 3.7.0으로 맞춘 뒤 해당 단계를 재실행했다. 새 실행 ZIP의 해시·소스 지문을 확인하고 소스·문서·대화 기록을 GitHub에 반영하겠다고 안내했다.

## 09. 도우미 · 요약

PR #45에 업로드한 26개 파일과 기존 파일 보존을 확인했다. 원격 Build and verify·Linux/Windows 내구성·Docker/Oracle/Nginx 검사가 모두 성공했다. 병합 직전 다른 작업의 Workbench 0.37.2가 main에 들어와 공통 문서 충돌이 발생했으며, 새 버전과 사이트 변경을 모두 보존하도록 병합한다고 안내했다. 공통 문서 여섯 개를 정리하고 사이트 소스와 실행 ZIP을 보존한 상태에서 0.37.2 JAR 호환 63개·통합 HTTP 242개 및 다운로드 지문을 재확인했다.
