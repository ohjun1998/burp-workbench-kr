# 계정 권한 비교 레이아웃 보정 · 0.39.1

날짜: 2026-10-17 (Asia/Seoul). 사용자에게 보이는 요청·답변만 기록하며 내부 추론·원시 도구 출력·실제 인증값은 포함하지 않습니다.

## 사용자 요청 원문

> 레이아웃 안 맞는데 확인해서 고도화 좀 시켜줘

실제 어두운 테마 화면과 이전 승인 시안 이미지 두 장을 첨부했습니다. 자동 이미지 접근 오류 문구가 있었으나 이 작업에서는 제공된 두 파일을 모두 열어 확인했습니다. 이미지를 덮어쓰지 않고 운영 소스를 수정합니다.

## 진행 안내 원문

“첨부 화면과 현재 레이아웃을 비교해 버튼·표·상세 창의 배치가 어긋나는 부분을 확인하고 수정하겠습니다. 이미지 파일 접근이 안 되면 현재 화면을 직접 렌더링해 확인하겠습니다.”

“이미지 두 장을 모두 확인했습니다. 시안과 달리 상단 버튼이 너무 많고, 표 열이 화면 너비를 채우지 않으며, 계정 상세 입력도 한 열로 길게 배치되어 있습니다. 시안처럼 주요 버튼을 줄이고, 기록 비우기는 비교 기록 영역으로 옮기고, 표와 상세 창이 화면 크기에 맞게 배치되도록 수정하겠습니다.”

“상단을 시안처럼 주요 버튼 6개로 정리하고, 세션 검사·권한 매트릭스는 더보기로 옮겼습니다. 비교 기록에는 메서드 열을 추가했고, 표는 넓은 화면을 채우되 좁아지면 열 너비를 유지하며 스크롤하도록 바꿨습니다. 사이드 메뉴가 열린 전체 화면과 데이터가 없는 초기 화면도 검증에 추가했습니다.”

## 작업 요약

버튼·표·폼의 배치를 보정하고 사용자 매핑·재전송·Ctrl+Space와 응답 분류는 유지합니다. 시안의 예시 데이터는 실제 계정이나 기록으로 삽입하지 않습니다. 검증 범위와 산출물은 RELEASE_0.39.1_KR.md, VERIFICATION_0.39.1.json에 기록합니다. 실제 Burp GUI·Windows DPI/IME 검증 여부와 자동 어댑터·합성 Swing 렌더링을 구분합니다.

검증 완료: 정식 release 2,630개, 레이아웃 회귀 98개, 두 테마·세 해상도와 최소/기본 상세 창을 포함한 화면 54개·컨트롤 786개 검증 및 패키징 회귀 4개를 통과했습니다. 네이티브 Burp GUI·Windows DPI/IME 검증은 미수행입니다. 0.39.1 JAR·전체 소스 ZIP과 실제 Swing 렌더링을 제공하며 이전 배포는 보존합니다.
