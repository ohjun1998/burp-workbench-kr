# 계정 권한 비교 화면 개편 · 0.39.0

기록 날짜: 2026-10-17 (Asia/Seoul). 이 문서는 이 작업에서 확인 가능한 사용자 요청과 사용자에게 보낸 답변을 기록합니다. 내부 추론·원시 도구 출력·실제 인증값은 포함하지 않습니다.

## 사용자 요청 원문 — 화면 디자인

> 계정 권한 비교 extension에서 기능이나 레이아웃들 수정할게
>
> 1. 요청, 응답 목록에서 OFF / SCOPE 유무 상관없이, 인증 탐지 버튼 만들어서 ON이면 인증 정보 탐지하고 OFF면 인증 정보 탐지 금지해줘
> 2. 새 요청 자동 비교 버튼은 요청 비교 ON / OFF로 만들어줘
> 3. 인증 정보 수집하면 Origin, 인증 헤더/값만 확인이 되는데, 여기에 추가적으로 사용자 계정 정보도 같이 매핑 시켜주고 더블 클릭 누르면 창모드로 상세 정보 확인 가능하게 해줘(일반 텍스트 나열이 아닌 가독성 챙겨서)
> 4. 비교 기록에 계정1, 계정2, 계정3 이런식으로 표현되는데, 이거 매핑되어있는 사용자 계정 정보로 표시해주면 안 헷갈릴거 같아
> 5. 현재 레이아웃에 있는 요청/응답 패킷, 판정 근거는 삭제하고 비교 기록에서 더블 클릭하면 창 모드로 요청/응답 패킷, 판정 근거를 확인할 수 있게 지정해줘
> 6. 레이아웃이나 버튼 테마는 이전에 요청/응답 목록, JS에서 API 찾기 테마를 적용 시켜줘
>
> 아직 소스코드는 적용하지 말고, 이미지로 디자인만 보여줘

답변 요약: 메인 화면·사용자 계정 카드·비교 기록 상세를 담은 디자인 이미지를 제시했습니다. 이 단계에서는 소스 적용하지 않았습니다.

## 사용자 요청 원문 — 구현 승인과 단축키 변경

> 3. 비교 기록 상세에 현재 패킷 -> Repeater 는 제거하고 ctrl + spacebar 단축키로 자동으로 Repeater로 넘어가게 해주고 전체 소스코드에 적용해줘

첨부 이미지 경로를 읽을 수 없다는 오류가 함께 제공되었습니다. 지정 이미지 파일이 존재하지 않아 해당 파일의 이미지 편집은 수행하지 않았습니다. 앞서 제시한 화면 설계와 이번 구현 요청에 따라 소스 작업을 진행했습니다.

## 사용자에게 전달한 진행 안내

- 승인한 화면 설계와 Ctrl+Space를 구현하며, 이미지 수정은 누락된 원본의 재첨부가 필요하다고 알렸습니다. 소스 구현은 계속 진행한다고 안내했습니다. (이전 안내 요약)
- 인증 탐지 독립 동작·수동 계정 매핑·JS와 동일한 별도 Repeater 창·길게 누르기 방지를 설명했습니다. (이전 안내 요약)
- 원문: “비교 상세 창에서 Repeater 버튼을 제거하고, 선택한 계정의 패킷을 `Ctrl + Space`로 Repeater에 여는 동작을 적용하고 있습니다. 단축키를 길게 눌러도 요청이 의도치 않게 전송되지 않는지 함께 확인하겠습니다.”
- 원문: “인증 탐지와 요청 비교를 각각 ON/OFF로 분리했고, 계정 정보 매핑과 더블클릭 상세 창도 연결했습니다. 현재 회귀 검사에서 Scope 밖의 인증 탐지, 계정 변경 시 이전 정보 초기화, 선택한 계정 패킷의 Repeater 전달을 확인하고 있습니다.”
- 원문: “새 동작에 대한 20개 회귀 검사를 통과했습니다. `Ctrl + Space`는 선택한 계정의 요청·응답을 별도 Repeater 창으로 열며, 창을 여는 것만으로 요청을 보내지는 않습니다. 밝은 테마와 어두운 테마의 화면도 확인했고, 전체 배포 검증을 진행 중입니다.”

현재 검증 범위와 산출물은 RELEASE_0.39.0_KR.md 및 VERIFICATION_0.39.0.json에 기록합니다. 실제 Burp GUI·브라우저·사용자 환경에서의 검증과 자동 어댑터 검증은 구분합니다.

## 검증 완료 기록

전체 release 2,532개, 새 흐름 21개, 별도 Mapper·패키징 회귀 4개와 Swing 20개 화면 검증을 통과했습니다. 기존 응답 수집 연계 테스트는 독립 요청 인증 탐지로 변경했으며 수동 History 가져오기는 인증 탐지를 하지 않는 것으로 검증했습니다. JAR·전체 소스 ZIP과 버전별 사용법·검증 기록을 PR로 제공합니다.
