# Repeater 미확정 메서드 기본 GET — 0.37.4

- 날짜: 2026-10-17 (Asia/Seoul)
- 작업: workbench-default-get-0374

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

미확정이면 GET을 디폴트 값으로 놓고 JS 분석해서 적절한 결과가 나오면 해당 메소드를 사용하게 하는건 어때?

## 02. 도우미 · 원문

그 방식이면 미확정 항목도 바로 확인하기 편해집니다. **GET을 기본값으로 두고, 분석 근거가 있으면 해당 메서드로 선택**하는 방향을 권합니다.

| 우선순위 | 선택 기준 | 표시 예시 |
|---|---|---|
| 1 | JS에서 확인한 메서드 | `POST · JS 분석` |
| 2 | JS는 미확정이지만 관찰된 메서드가 하나 | `PUT · 관찰 기록` |
| 3 | 근거가 없거나 관찰 결과가 충돌 | `GET · 기본값` |

기본 GET은 서버에서 확인된 메서드와 구분해 표시하면 됩니다. 수동 변경은 계속 가능하게 두고, **자동 선택만 수행하며 전송은 Send 또는 Ctrl+Space로 실행**하는 구성이 적절합니다.

## 04. 도우미 · 원문

미확정 메서드는 GET을 기본값으로 사용하고, JS 분석 결과나 단일 관찰 메서드가 있으면 우선 적용하도록 수정하겠습니다. 선택 근거 표시와 수동 변경을 유지하고, 검증 후 GitHub main까지 반영하겠습니다.

## 05. 도우미 · 진행 요약

최신 main의 0.37.3에서 작업을 분리하고 0.37.4로 버전을 올렸습니다. 근거 없음·관찰 충돌·불완전한 기록은 GET 기본값으로 준비하며, 분석·관찰 근거와 구분합니다. 직접 편집한 요청을 후속 분석으로 덮어쓰지 않고, 미확정 경로·값과 SCOPE 검사는 유지합니다. 제목 표시줄의 기본 창 버튼과 Send/Ctrl+Space 경로도 유지합니다.

기존 수동 메서드 선택을 전제로 한 응답 워크플로 테스트를 새 기준으로 갱신했습니다. 기본 GET·관찰 메서드·수동 변경의 실제 loopback 응답 검사를 포함합니다. 새 화면 검사에서 기본 GET 두 크기의 측정 기준을 추가하고 두 테마 화면을 검토합니다. 전체 HTTP 검사에서는 저장본과 실시간 갱신 중인 목록의 시간차 비교가 가능했던 기존 검사를 보완했습니다. 저장 데이터와 기대 개수를 같은 시점에 고정하고 쿠키 제외 검사도 분리했으며 운영 활동 추적 코드는 바꾸지 않았습니다. 최초 실패와 전체 재실행은 버전별 검증 기록에 구분합니다.

## 06. 도우미 · 검증·배포 안내 요약

실제 실행한 수치와 제한은 [0.37.4 검증 기록](../../VERIFICATION_0.37.4.json), 사용법과 화면은 [변경 안내](../../RELEASE_0.37.4_KR.md), 원격 결과와 병합 여부는 이 작업 PR의 Checks를 기준으로 확인합니다. 작업 중 추가된 main의 사이트 3.7.1을 반영하고 기존 버전·커뮤니티 사이트·Mapper 배포는 보존하며 새 JAR·소스 ZIP과 이 대화를 함께 업로드합니다. 실제 Burp GUI·물리 키/IME·사용자 환경의 실행을 자동 회귀 결과로 대신 주장하지 않습니다.
