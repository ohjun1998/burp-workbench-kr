> 고도화 내용 전부 업데이트 해줄래? 고도화 해도 기존 레이아웃이 변경되는건 없지?

## 이전 답변 요약

최신 main 0.35.1 소스를 검토했습니다. API 주소와 실행 페이지의 구분, Axios 인스턴스·래퍼 추적, 큰 JS 분석 누락 감소, Brotli, 소스맵의 위치·초안 연결, 디스크 이력, 실제 요청 대조를 제안했습니다. 추가로 검토 우선순위·GraphQL 작업별 분석·중복 통합과 출처 보존을 제안했습니다. 첫 검토에서는 코드 수정이나 실제 Burp 실행을 수행하지 않았다고 설명했습니다.

쉽게 설명한 답변에서는 분리된 API 주소 결합, 메서드·데이터 찾기, 큰 파일 뒤쪽 분석, 원본 코드 이동, 이전 결과 유지, JS에서만 발견하고 아직 호출하지 않은 API 구분을 설명했습니다.

## 구현 시작 답변 원문

> 기존 레이아웃은 유지하겠습니다. 버튼·탭·영역 배치와 연속 스크롤을 그대로 두고, 제안한 개선을 분석 로직과 기존 상세 화면·메뉴에 반영하겠습니다. 최신 소스와 작업 규칙부터 확인하겠습니다.

## 진행 답변 요약

- GitHub 연결로 최신 main을 확인했으며 터미널 Git 인증이 없어 연결 도구로 소스와 빌드 의존성을 복원한다고 안내했습니다.
- 새 버튼·탭 없이 기존 표, 상세 창, 메뉴에서 검토 근거·관찰 패킷·출처를 확인하도록 구현한다고 안내했습니다.
- 원본 수집과 분석용 메모리 예산을 구분하고 오래된 분석 결과를 디스크에서 다시 확인하도록 진행한다고 안내했습니다.
- Axios·래퍼, Brotli·복합 압축, 큰 파일 분석, 디스크 이력, GraphQL, 기존 해결 상태·관찰된 API 패킷 메뉴 연결을 구현했다고 안내했습니다.
- 자동 전송을 늘리지 않고 Scope 확인과 수동 Send를 유지한다고 안내했습니다.
- 새 회귀 검사와 기존 흐름의 집중 검사를 통과한 뒤 전체 릴리스 검사 및 이전 버전과 화면 배치 수치 비교를 진행한다고 안내했습니다.
- 새 버전은 0.36.0으로 생성하고 이전 배포 파일은 보존한다고 안내했습니다.
