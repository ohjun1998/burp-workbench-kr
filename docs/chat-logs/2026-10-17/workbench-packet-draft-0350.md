# Workbench 분석 상세·전체 집계·패킷·요청 매핑 0.35.0

- 날짜: 2026-10-17 (Asia/Seoul)
- 작업: workbench-packet-draft-0350

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

JS에서 API 찾기 extension의 다음 사항을 수정해줘

1. 분석 원문에도 burp suite 스타일 적용하고 왼쪽 끝에 줄번호 표시해줘(모든 extension에 패킷 부분은 burp suite 스타일 적용해줘)
2. repeater 모드에서 ctrl +space 누르면 자동으로 send 보내게 해줘
3. repeater 모드에서 REPLACE_METHOD, REPLACE_PARAMETER가 자동으로 매핑되어서 send하면 정확한 응답 패킷을 안 주는 거 같은데 확인해보고 수정해줘

## 02. 도우미 · 요약

분석 원문과 전체 패킷 영역에 구문 강조·줄 번호를 적용하고 Repeater Ctrl+Space를 추가한다고 안내했다. 전송 경로 확인 결과 0.33.0은 미확정 메서드·경로는 차단하지만 쿼리·본문의 REPLACE_ME는 전송할 수 있었다. 상수·중첩 JSON 값은 반영하고 미확정 표시는 전송을 막으며 편집 시 이전 응답을 비우는 수정과 실제 수신 서버 검증을 진행한다고 안내했다.

## 03. 사용자 · 원문

추가로 분석 상세 탭을 분석 목록 버튼 오른쪽에 배치하고 분석 상세 누르면 창 모드로 분석 상세 내용이 뜨게 해줘, 그런데 지금은 상세 내용이 텍스쳐로만 되어있는데, 보기 이쁘게 가독성 챙겨서 작성해줘,

## 04. 도우미 · 요약

분석 목록 오른쪽의 분석 상세 버튼으로 별도 창을 열고 요약 카드·항목별 목록으로 구성하며 진행 중 검증에 변경을 포함한다고 안내했다.

## 05. 사용자 · 원문

그리고 분석 ON / OFF 버튼이 위치한 상단의 젤 오른쪽 끝에 분석 대상 전체를 대상으로 URL/API, 토큰/API 키후보, 도메인, 클라우드 URL 개수를 표시해줘, 표시하는 구간의 스킨은 첨부한 이미지 참고해서 불빛 느낌으로 작성해줘

## 06. 도우미 · 요약

첨부 이미지를 확인했다. 같은 초록 불빛·테두리의 상단 오른쪽 집계를 적용하고 여러 파일의 중복 항목은 한 번씩 세며, 좁은 화면에서는 두 줄로 배치한다고 안내했다. 분석 상세는 요약 카드·항목별 표로 구현했다고 설명했다.

## 07. 도우미 · 요약

분석 상세 창과 전체 집계의 기능·작은 화면 검증을 통과했다고 안내했다. 최종 로컬 전체 검사 2,348개, Mapper Java 94·Node 7, 두 테마 화면 288개와 패키징 4개를 통과했으며 최신 JAR·소스를 준비하고 GitHub 자동 검사와 main 반영을 마무리한다고 설명했다.
