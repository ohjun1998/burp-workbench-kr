# 인증 조합별 로그인·계정 권한 비교와 보고서 3.9.0

- 날짜: 2026-10-18 (Asia/Seoul)
- 작업: authentication-combinations-lab-390

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

계정 권한 비교 확장자로 테스트해서 보고서로 뽑아줘
1. 커뮤니티 사이트에 사이드 메뉴 만들어서 세션, 토큰, JWT 등 다양한 조합으로 로그인을 할  수 있도록 여러 페이지를 세팅해줘
2. 로그인 후 다양한 조합으로 이루어진 세션으로   URL 요청을 통해 권한 검증이 재대로 이루어지고 있는지 판단해줘

## 02. 도우미 · 원문

커뮤니티 사이트에 인증 방식별 로그인 테스트 메뉴를 만들고, 관리자·일반 사용자·비로그인 요청을 계정 권한 비교 기능으로 검사하겠습니다. 인증 조합별 권한 검증 결과와 요청·응답 근거를 보고서로 정리하겠습니다.

## 03. 도우미 · 요약

세션·불투명 토큰·JWT와 네 가지 복합 조합을 일곱 로그인 페이지로 구성한다고 안내했습니다. 정상 URL, 의도된 취약 대조 URL, 누락·혼합·변조·만료·폐기와 쓰기 전후 상태를 검사합니다. PDF 작성 스킬로 보고서를 만들고 실제 실행 범위를 구분한다고 설명했습니다.

## 04. 도우미 · 요약

별도 임시 프로필의 실제 Burp Community 2026.3.3에서 기존 0.43.0 JAR를 로드했습니다. 운영 컨트롤러의 권한 비교 42건(기준 제외 계정 대조 126건), 사용자 신원 21건·만료 기준 보호 1건이 통과했습니다. 정상 대조 28건은 기대 정책과 일치했고 의도된 두 결함 유형의 14건은 우회 의심으로 구분됐습니다.

## 05. 도우미 · 요약

최종 독립 HTTP 420개와 브라우저 104개, 기존 커뮤니티 권한 HTTP 384개·브라우저 66개, 배포용 인증 대조 197개(H2)를 통과했습니다. 실제 native/브라우저 화면과 가린 요청·응답을 보고서 근거로 정리합니다. Burp 헤드리스 호스트 UI 경고는 실제 GUI 조작 검증과 구분하고, 원격 Oracle·Nginx 검사도 별도로 기록합니다.

## 06. 도우미 · 원문

보고서에 정상·취약 URL의 계정별 응답, 의도된 인가 누락 두 유형, 쓰기 전후 데이터 근거를 넣고 있습니다. 배포 환경에서도 로그인 Origin 검사가 맞도록 Nginx가 외부 Host의 포트를 보존하게 수정했습니다. 현재 전체 회귀 검사와 3.9.0 실행 ZIP 생성을 진행 중입니다.

## 07. 도우미 · 요약

API·로그인 화면에 남아 있던 3.8.0 버전 표기를 3.9.0으로 정리했습니다. PDF 초안 8쪽의 표와 화면 배치를 확인했으며 정상 차단·실제 우회·만료 기준 보호와 가린 요청·응답 근거를 넣었습니다. 배포 패키지와 원격 검증을 진행합니다.

## 08. 도우미 · 요약

자동 검사 대체 전송에서도 HTTP 420개·비교 42건을 통과했습니다. 기존 트래픽 검색 비동기 회귀가 한 차례 실패했으나 즉시 분리 실행한 23개 검사는 통과했고, 배포 전체 검사를 다시 수행합니다. 복합 인증 누락·혼합, JWT 변조, 로그아웃·만료 재사용은 차단되었으며 정상·취약 메모 쓰기의 저장 상태도 확인했습니다.

## 09. 도우미 · 원문

정식 배포 검사 2,851개와 별도 Mapper 검사가 통과했고, 사이트 3.9.0 실행 ZIP도 생성됐습니다. 이제 원격 Oracle·Nginx 및 브라우저 검사 결과를 확인해 보고서에 반영하겠습니다.

## 10. 도우미 · 요약

PR #67에 코드·보고서·실행 ZIP을 올렸고 새 화면을 제시했습니다. 원격 브라우저 검사가 통과했습니다. 검사 도구의 3.8.0 고정 기대값도 현재 POM/서버 버전으로 바꾸고 로컬 HTTP 384개와 브라우저 66개를 다시 통과해 3.9.0 결과로 기록했습니다.

## 11. 도우미 · 요약

실제 Docker·Oracle·Nginx의 인증 경계 197개·기존 HTTP 54개와 외부 포트 Origin 검사가 통과했습니다. 8쪽 PDF를 먼저 제공했습니다. 최종 소스 브라우저 66개·인증 UI 104개 재검사도 통과했고, 동일 런타임의 Windows/Linux 안정성 CI가 성공했습니다. 373개 확장·사이트·Mapper·내구성/네이티브 하네스 입력 파일을 앞서 성공한 커밋과 바이트 대조하여 변경이 없음을 확인하고 최종 근거를 정리합니다.

## 12. 도우미 · 원문

최종 Build 검사도 성공했습니다. 실제 Oracle·Nginx, 최종 브라우저, 검증 입력이 동일한 Windows·Linux CI 결과를 보고서에 반영하고 있습니다. 실행 ZIP의 소스 90개와 압축 무결성도 확인했습니다.

## 13. 사용자 · 원문

남은 단계 계속 진행해줘

## 14. 도우미 · 원문

보고서와 실행 ZIP 검증까지 끝났습니다. 남은 최종 파일 업로드와 저장소 병합을 계속 진행하겠습니다. 완료 후 보고서·요청/응답 근거·실행 ZIP을 한 번에 안내해드리겠습니다.
