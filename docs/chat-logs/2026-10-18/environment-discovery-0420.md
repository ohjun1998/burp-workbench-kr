# 서버·경로 탐색 여섯 기능 고도화 · 0.42.0

- 날짜: 2026-10-18 (Asia/Seoul)
- 작업: environment-discovery-0420

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

서버 경로 탐색 extension 고도화 방안 제시해줘

## 02. 도우미 · 요약

현재 0.41.0 소스를 검토하고 계정별 결과 분리, 가짜 200 구분, 노출 내용 판별, 후속 탐색, 세션 확인, Repeater 연계, 요청 제어, 결과 저장·변경 추적을 제안했다. 소스는 수정하지 않았다고 안내했다.

## 03. 사용자 · 원문

좀만 더 쉽게 설명해줘

## 04. 도우미 · 요약

숨겨진 경로 후보를 찾는 기능에서 실제 응답 내용과 계정별 접근 조건, 다음 확인을 알려주는 기능으로 개선하는 방향이라고 설명했다.

## 05. 사용자 · 원문

노출 내용 판별, 가짜 200 응답 구분 강화, 탐색 결과의 재활용, 세션 유효성 확인, 요청 제어 일시정지 재개, 결과 저장 번경 추적 적용해서 고도화 시켜줘

## 06. 도우미 · 원문

요청한 여섯 항목을 기존 화면 구조 안에 적용하겠습니다. 먼저 최신 main과 검사 구조를 확인하고, 응답 판별·후속 탐색·세션 확인·일시정지와 재개·결과 저장을 구현한 뒤 테스트와 GitHub 반영까지 진행하겠습니다.

## 07. 도우미 · 원문

여섯 기능을 연결할 구조를 확인했습니다. 검사한 응답을 다음 경로 후보로 재활용하고, 로그인 계정은 기존 세션 검사 조건으로 확인하도록 연결하겠습니다. 저장 파일에는 인증값과 응답 본문을 넣지 않고 판정·변경 이력·남은 경로를 담겠습니다.

## 08. 도우미 · 원문

응답 내용에서 API 명세·설정 파일·Git 참조·디렉터리 목록 등을 구분하는 판별기를 추가했습니다. 없는 경로와 비슷한 화면은 ‘공통 화면 의심’으로 표시하고, 요청 예산과 탐색 깊이를 제한하는 실행기도 추가했습니다. 이제 기존 화면에 제어 버튼과 저장 기능을 연결하겠습니다.

## 09. 도우미 · 원문

기존 화면에 일시정지·재개 버튼을 연결했고, 더보기 메뉴에 결과 저장·불러오기·변경 기록을 추가했습니다. 중지하거나 요청 한도에 도달하면 남은 경로를 보존합니다. 현재는 격리된 로컬 서버로 후속 탐색, 만료 세션 차단, 429 응답 후 재개, 저장 파일 복원을 검사하고 있습니다.

## 10. 도우미 · 원문

경계 상황을 검사하면서 짧은 경로가 HTML 태그 일부까지 치환될 수 있던 기존 비교 로직을 발견해 보완했습니다. 로그인 계정은 실행 전·재개 시·일정 요청 간격마다 신원을 확인하고, 확인에 실패하면 다음 경로 요청을 보내지 않도록 구성했습니다.

## 11. 도우미 · 원문

신규 고도화 검사 66개와 기존 경로 탐색·세션 검사까지 통과했습니다. 만료된 세션에서 탐색 요청이 차단되는 것, 429 응답 후 자동 전송이 멈추는 것, 저장 파일을 불러와도 요청이 나가지 않는 것을 확인했습니다. 이어서 전체 회귀 검사와 화면 배치를 확인하겠습니다.

## 12. 도우미 · 원문

밝은·어두운 테마의 새 화면을 생성했고, 화면 검사 도구가 숨겨진 탭을 측정하지 못하던 부분을 보완했습니다. 전체 회귀 검사는 진행 중입니다. 판정 근거와 변경 기록 창도 함께 확인해 버튼과 패킷 영역이 잘리지 않는지 검증하겠습니다.

## 13. 도우미 · 원문

새 화면 20개와 전체 도구·기능 안내 화면의 배치 검사가 통과했습니다. 직접 화면을 보면서 후보 수 선택값과 변경 기록 열을 더 읽기 쉽게 조정할 부분을 확인했습니다. 작은 창에서도 주요 값이 보이도록 마지막으로 보정하겠습니다.

## 14. 도우미 · 원문

기능 검증은 2,803개까지 통과했습니다. 설정 값과 변경 기록의 표시를 보정한 최종 빌드를 다시 확인하고 있으며, 설정·근거·이력 창은 기본 크기와 최소 크기에서도 검사하겠습니다. 검증 기록과 설치용 JAR를 함께 GitHub에 올리겠습니다.

## 15. 도우미 · 원문

시작 버튼 직후 곧바로 중지하는 경우에도 대기 중인 작업에 중지 신호가 전달되도록 보완하고 회귀 검사를 추가했습니다. 이 변경을 포함한 최종 소스로 배포 검사를 마친 뒤 PR의 Windows·Linux 검증을 확인하겠습니다.

## 16. 도우미 · 요약

최종 python dev.py release 2,805개(신규 경로 탐색 회귀 72개 포함), 패키징 6개와 JAR·소스 ZIP 해시/CRC/소스 지문 검증을 통과했다. 해당 최종 JAR로 Swing 화면 180개·컨트롤 2,136개·탭/제목 1,800개를 확인했다. 실제 Burp GUI·Windows DPI/IME와 구분하고 0.42.0 배포 파일·검증·날짜별 대화를 PR에 올린 뒤 원격 검사를 확인하겠다고 안내했다.
