# 독립 메뉴를 유지한 Juice Shop 테스트 기반 로직 고도화

- 날짜: 2026-10-18 (Asia/Seoul)
- 작업: juice-logic-upgrade

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

테스트를 기반으로 고도화 제시방안

## 02. 도우미 · 요약

앞선 Juice Shop 테스트에서 확인한 빈 사용자 200 응답 오탐, 400 거부 응답 보류, Angular·대형 JS API 누락, SQLite 오류 누락과 302 저장 흐름 미연결을 개선 대상으로 정리했다. 최초 테스트 근거와 제약은 oss-workbench-testing.md와 audit/oss-lab/results/2026-10-18/에 보존한다.

## 03. 사용자 · 원문

독립 메뉴는 냅두고 나머지 로직 고도화 해줘

## 04. 도우미 · 원문

독립 메뉴와 레이아웃은 유지하고, 계정 판정·JS/API 분석·SQL 검사·저장 흐름 연결 로직을 개선하겠습니다. 수정 후 같은 Juice Shop 사례로 재검증해 전후 결과를 확인하겠습니다.

## 05. 도우미 · 요약

빈 사용자 응답과 실제 자료를 구분하고, 명시적인 대상 차단 규칙을 400·422에도 적용하되 자료 충돌은 보류하도록 구현했다. Angular·대형 번들 HTTP 호출 복구, 분석 후보 보존, SQLite·ORM 오류 공통 패턴, SQL 조건 쌍과 관측된 리다이렉트 뒤 조회 연결을 추가했다.

## 06. 도우미 · 원문

Juice Shop에서 다시 테스트한 결과, 기존에 실패했던 5개 항목이 모두 통과했습니다. 빈 사용자 응답은 확인 필요로 바뀌었고, 로그인·장바구니·검색 API 발견, SQLite 오류 탐지, 저장 후 조회 연결도 확인했습니다. 기존 기능의 회귀 검사와 배포 파일 검증을 마무리하겠습니다.

## 07. 도우미 · 원문

대형 JS를 페이지 주소 없이 분석할 때, URL이 아닌 문자열 조각 하나 때문에 결과 전체가 실패하는 경우도 찾았습니다. 해당 조각만 제외하고 다른 API 후보는 보존하도록 수정한 뒤 다시 확인하겠습니다.

## 08. 도우미 · 원문

추가한 예외 처리로 OpenAPI의 `/items/{id}` 경로까지 제외되는 회귀가 잡혀 수정했습니다. 미확정 경로는 유지하고 잘못된 문자열만 건너뜁니다. 메뉴·배치 관련 소스 5개도 이전 버전과 동일함을 확인했습니다.

## 09. 도우미 · 요약

추가 회귀 검사에서 OpenAPI 경로 보존을 수정했고, 기존 비동기 검색 테스트가 타이머 종료와 결과 적용 사이에 완료를 잘못 감지하는 대기 조건도 보완했다. 운영 검색 로직과 메뉴·배치는 변경하지 않았다. 검색 검사 23개를 3회 연속 확인한 뒤 최종 release 전체 검사를 다시 실행했다.

## 10. 사용자 · 원문

고도화 남은 거 계속 진행해줘

## 11. 도우미 · 요약

이전 작업 기록과 최신 main을 대조해 독립 메뉴·레이아웃 유지 조건, 0.45.0 전체 회귀 2,942개와 실제 Burp의 Juice Shop 33개 조건 통과 기록을 확인했다. 같은 작업의 최종 실행 원본을 복구했으며 새 Burp 실행으로 표현하지 않았다.

## 12. 도우미 · 요약

배포 소스·해시와 패키징 6개를 다시 확인했다. 기본 규칙의 빈 user 응답 오탐 1건은 보류로 바뀌었고, 대상 전용 규칙의 재검사 6칸은 TN 6·보류 0이었다. 정탐·오탐·미탐·보류 사유 CSV, 5쪽 전후 비교 PDF와 인증값을 가린 근거 ZIP을 작성했다. GitHub 업로드와 원격 검증을 이어간다.

## 13. 사용자 · 원문

고도화 남은 거 계속 진행해줘

## 14. 도우미 · 요약

소스·설치 파일·보고서 준비 후 GitHub 업로드 중 중단된 작업을 재개했다. 업로드한 Git 객체의 SHA를 확인하고, PR 생성과 원격 검증을 이어간다.

## 15. 도우미 · 요약

PR #74를 생성하고 업로드한 전체 파일 트리가 로컬 검증본과 같음을 확인했다. 원격 Build와 Windows/Linux 검사가 모두 통과했다. 회귀·HTTP 2,942개, 패키징 6개, 50개 기능의 계정 비교, 화면 배치·소스 지문을 검증했다. Windows/Linux 3분 수집은 3,634/3,623건 모두 누락·처리 오류 0이었다. 원격 계정 비교는 API adapter 검사이며 실제 Burp 실행으로 표현하지 않는다.

원격 계정 비교 완료 후 사용자에게 main 병합과 완료 기록을 진행한다고 안내했다. PR #74와 선행 #73이 main에 병합됐고, 병합 소스 트리가 검사한 트리와 같음을 확인했다. 성공한 PR의 동일 소스 병합 CI는 중복 실행하지 않았으며, 후속 상태·검증·변경 안내·대화 기록만 갱신한다. 설치 JAR·소스 ZIP·보고서·가림 근거는 보존한다.
