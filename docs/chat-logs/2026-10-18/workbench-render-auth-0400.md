# Workbench 0.40.0 — 굴림·Render·인증 비교 사용성

- 날짜: 2026-10-18 (Asia/Seoul)
- 작업: workbench-render-auth-0400

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

1. 글씨체 굴림체로 바꿔줘
2. 모든 repeater에 Pretty, Raw, Hex만 있는데 render 기능도 넣어줘
3. 판전 근거 좀 가독성 있고 직관적이게 작성해줘, 텍스쳐만 긁어오니까 눈에 안들어와
4. 인증 정보 후보, 비교 기록에서 우클릭시 삭제 기능도 넣어줘
5. 인증 헤더 / 값 가림 처리 되어있는거 해제해줘
6. 인증 정보 후보에서 우클릭 시 관리자, 일반, 후보1, 비로그인, 해제만 보이게 변경해줘(굳이 하위로 하나 더 들어갈 필요 없이 상위에서 한번에 처리)

## 02. 도우미 · 요약

첨부 화면과 최신 main에서 여섯 항목을 확인하고 적용 중임을 안내했습니다. 공통 패킷 뷰어에 정적 Render를 추가하고, 판정 근거를 종합 요약·계정별 근거·필드 차이로 나누기로 했습니다. 비로그인은 세 번째 비교 위치, 해제는 선택 후보의 모든 지정 해제이며 후보 삭제 시 과거 기록을 유지한다고 설명했습니다. 굴림 미설치 환경은 한글 대체 글꼴을 사용하며 회귀 검사를 진행 중임을 안내했습니다.

## 03. 도우미 · 요약

Render 전환 시 요청 바이트 보존, 정렬된 행 삭제와 인증값 표시·과거 기록 보존 검사가 통과했다고 안내했습니다. 최소 크기 상세 창의 패킷 높이 저하를 화면 검사에서 발견해 보정하고, 판정 근거의 크게 보기와 좁은 화면 탭 너비를 추가로 조정했습니다. 최종 소스의 전체 검사와 두 테마 화면 검증을 진행한다고 안내했습니다.

## 04. 도우미 · 요약

최종 소스의 정식 release 2,684개 검사와 패키징 회귀 4개, 다운로드 해시·소스 지문 검사를 통과했습니다. 전체·인증·패킷·JS·안내 창의 두 테마 화면 272개에서 컨트롤 잘림·필수 영역 붕괴·선택 탭/제목 잘림이 없음을 확인했습니다. 실제 Burp GUI·Windows DPI/IME는 수행하지 않았고 Render는 정적 HTML임을 구분합니다. 새 JAR와 소스를 PR로 전달합니다.

## 05. 도우미 · 요약

화면 272개에서 컨트롤 잘림과 필수 영역 붕괴가 없었으며 Render·최소 크기 상세·JSON 값 비교 표를 직접 확인했다고 안내했습니다. 배포 파일과 검증 기록을 GitHub에 올리고 PR 자동 검사 후 main에 반영하겠다고 설명했습니다.
