# Workbench 전체 고도화·재검증 요청과 진행 기록

- 날짜: 2026-10-20 (Asia/Seoul)
- 작업: full-hardening

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

## 02. 도우미 · 요약

첨부한 최신 0.48.0 보고서 기준으로 Mapper 실제 브라우저 연결, 대형 JS 문맥 복원, 401 원인 분리, 대형 응답 분석 범위, 실사용 환경 검증과 대상 확대를 남은 범위로 설명했다. 기존 XSS4·JSON2 보강은 완료 항목으로 구분했다.

## 04. 도우미 · 원문

최신 소스와 검증 환경을 확인한 뒤, 남은 고도화를 반영하고 전체 재검증을 진행하겠습니다. 결과에는 개선된 항목, 여전히 미흡한 항목, 환경 제약으로 검증하지 못한 항목을 구분해 남기겠습니다.

## 05. 도우미 · 요약

main의 0.48.0 병합을 확인하고 새 작업 브랜치를 만들었다. Mapper 이벤트 중복과 worker 초기화, JS 정적 문맥, 신원 대조, 대형 본문 분석, 증거 가림, 수집/URL 출처 표시를 보강했다. 실제 Chrome은 socket 생성 제한으로 시작하지 못했다. 초기 통합 검사에서 증거 저장 중 동시 종료 회귀를 발견하고 기존 테스트를 완화하지 않은 채 수정했다.

## 06. 도우미 · 원문

추가 실습 사이트의 취약점 재현 작업 일부는 실행 환경의 보안 검사로 중단됐습니다. 해당 항목은 완료로 표시하지 않고, 이미 확보한 로그를 확인하겠습니다. 코드 회귀 검사와 통제된 기능 검증은 계속 진행합니다.

## 07. 도우미 · 요약

독립 검토에서 JS 변이·조건부 반환·요청 객체 위치, 신원 대조 간격·불완전 응답, URL 대표군, 증거 종료 경합·JSON 가림·쿠키 속성·미리보기 성능 문제를 발견하고 회귀 사례를 추가해 수정했다. 실제 Burp 설치 확인은 임시 프로필의 라이선스 동의 안내에서 멈췄고, 동의나 기존 프로필 재사용은 하지 않았다. 최종 0.49.0 소스 전체 회귀·HTTP·화면·연속 수집 검사를 시작했다.

## 09. 도우미 · 요약

최신 보고서와 main을 확인하여 미게시 0.49.0 작업을 복구했다. 현재 소스로 전체 회귀·격리 HTTP 3,361개, Mapper Java114개·Node8개를 재실행하여 통과했다. 배포 소스 지문·JAR 해시도 확인했다. 이전 최종 JAR의 역할·인증·50개 기능 및 화면 근거를 복구하고 계정 결과를 재집계했다. 권한표·쓰기 조회 설정 전 미탐392건, 설정 후 TP392·FP0·FN0과 보류91건을 구분했다. 실제 Chrome 재시도는 소켓 권한 제한으로 시작하지 못했다. 이전 Burp 실행 시도의 JAR 해시가 최종본과 달라 최종 검증 근거에서 제외했다. 빠져 있던 검증 JSON과 HTML 보고서에 남은 고도화·실행 미확인 범위를 기록했다.

## 10. 도우미 · 원문

GitHub 업로드는 자동 승인 검토에서 차단됐습니다. 이번 요청에 해당 저장소로 코드·보고서·대화 기록을 게시한다는 명시적 승인이 없다는 사유입니다. 다른 경로로 재시도하지 않고, 검증된 변경과 보고서를 먼저 완성하겠습니다. 마지막에 정확한 게시 대상과 범위를 제시해 승인을 요청드리겠습니다.

## 11. 도우미 · 요약

## 17. 도우미 · 요약

코드·설치파일·보고서·날짜별 대화 기록의 원격 업로드와 PR #82 생성을 완료했다. 로컬과 원격 파일 트리가 일치함을 확인했다. Mapper 빌드·30개 화면 검사는 통과했으나 실제 Chromium의 연결 완료 대기가 실패했다. 원인을 단정하지 않고 브라우저 오류·팝업 상태만 기록하는 진단을 추가한다. 연결 토큰과 입력값은 출력하지 않으며 기존 성공 조건·운영 코드·설치 파일은 변경하지 않는다. 실패가 해소되고 정확한 head의 전체 원격 검증을 통과하기 전에는 main에 병합하지 않는다.

## 18. 도우미 · 원문

## 19. 도우미 · 원문

재실행에서는 연결과 클릭 전달이 통과했고, 다음 실패 원인을 찾았습니다. Chrome API가 PATCH 본문을 제공하지 않는데 검사 코드가 본문 해시 일치까지 요구하고 있었습니다. POST 해시 검증은 유지하고 PATCH는 ‘본문 미확인’을 검증하도록 바로잡겠습니다. 팝업 초기화 중 버튼이 먼저 눌릴 수 있는 문제도 보완해 새 패치 버전으로 검증하겠습니다.

## 20. 도우미 · 원문

팝업 초기화 지연과 저장소 오류를 재현하는 회귀 검사를 추가했고, 도우미 검사 10개가 모두 통과했습니다. 기존 배포물은 보존하고 Workbench 0.49.1·Mapper 0.3.4를 생성 중입니다. 이 버전으로 전체 검사와 원격 브라우저 검증을 다시 진행합니다.

## 26. 중단 및 병합 범위 · 요약

사용자가 원격 검사 통과 후 병합 조건을 변경하고 검사 중단·main 병합을 명시적으로 요청했다. 로컬 0.49.1 release 검사는 종료 코드130으로 중단됐으며 해당 패치·불완전 배포물은 원격에 게시하지 않는다. 병합 대상은 기존 PR #82의 Workbench0.49.0 / Mapper0.3.3이다. 원격 Mapper 검사는 실패이며 Build/Windows/Linux 검사 취소는 도구 부재와 브라우저 로딩 실패로 직접 완료하지 못했다. 검사 완료·통과로 표시하지 않고 사용자 지시에 따른 병합임을 기록한다. 병합·문서 커밋의 [skip ci]로 새 검사를 시작하지 않는다. 기존 워크플로와 저장소 보호 설정은 변경하지 않는다.
