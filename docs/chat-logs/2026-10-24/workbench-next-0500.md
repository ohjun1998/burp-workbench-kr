## 08. 도우미 · 요약

기존 0.49.1과 main을 보존하고 account-a/workbench-next-0500 브랜치에서 Workbench Next 0.50.0을 구현한다고 안내했다. 메뉴 통합, 선택 원본과 비교 조건 추적, 권한표·쓰기 조회 설정 보조, 보관 원본 분석 재시도, 처리 시간 관측, 검색 취소, 증거 묶음과 완료 검토를 적용했다. 설정 키와 JS 기록 저장 경로를 분리했다. 공통 콘텐츠 캐시·대상별 설정 묶음·전 도구 업무 객체 통합·실제 Burp 장시간 부하 검증은 이번 구현 범위에 포함하지 않는다.

## 09. 도우미 · 원문

최종 JAR로 화면 222개를 확인했고, 컨트롤 3,204개와 제목·탭 라벨 3,324개에서 배치 오류는 없었습니다. 기존 0.49.1 JAR도 원래 해시와 일치합니다. 새 버전에는 설치·기능별 안내와 실제 검증 기록을 함께 넣겠습니다.

## 10. 도우미 · 원문

새 버전의 빌드와 자동 검증 3,490개가 모두 통과했습니다. 이제 최종 JAR·소스 ZIP과 검증 기록을 별도 브랜치에 업로드하고, 기존 0.49.1과 바로 구분되는 다운로드 링크를 정리하겠습니다.

## 11. 도우미 · 원문

배포 파일과 소스의 무결성 확인까지 끝났습니다. 설치 안내도 새 화면 기준으로 맞추고 있습니다. 이전 PDF는 과거 버전 자료로 표시하고, Next용 안내에는 메뉴 위치와 설정·재시도·증거 저장 순서를 담았습니다.
