# Workbench Next 0.52.0 구현·검증·별도 배포

- 날짜: 2026-10-24 (Asia/Seoul)
- 작업: workbench-next-0520

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

기존 버전은 냅두고 너가 고도화 제시한 방안으로 새로운 버전(기존 버전하고 명확히 구분 가능한)으로 소스코드 수정하고 업로드 해줘

## 02. 사용자 · 원문

0.50.0 버전 최적화 고도화 방안 제시해줘

## 03. 도우미 · 요약

기존 0.49.1·Next 0.50.0을 보존하고 새 0.52.0 전용 브랜치에서 응답 큐, 증분 검색, 권한 설정 재사용, Mapper 업무 연결, 실행·증거 연결과 JS 이력 관리를 개선하며 설치 파일과 소스를 제공한다고 안내했습니다.

## 04. 사용자 · 원문

0.52.0 버전까지 업데이트 해줘

## 05. 도우미 · 요약

기능을 나누어 구현했고, 10만 개 기존 검색 결과 뒤에 새로 추가한 25개만 평가하여 전체 재검색과 같은 결과를 얻는 검사를 통과했다고 안내했습니다. 개별 기능 검사와 실제 Mapper→업무 생성 경로를 함께 확인하며 기능 ID 형식 불일치를 수정했다고 알렸습니다.

## 06. 도우미 · 원문

권한 설정 묶음, 업무별 실행 기록, 증거 ZIP 연결도 구현 단계에 들어갔습니다. 실제 Burp 실행은 새 임시 프로필에서 라이선스 동의 단계에 막혀 기능 검사까지 진행되지 않았습니다. 이 부분은 별도로 기록하고, 자동 회귀·화면·부하 검증은 계속 진행하겠습니다.

## 07. 도우미 · 원문

통합 빌드가 통과했고, 권한 설정의 별도 검사 200개도 통과했습니다. 이제 최종 회귀 검사와 새 화면 검사를 진행하고, 0.52.0 설치 파일·소스 ZIP·상세 가이드를 함께 올리겠습니다.

## 08. 사용자 · 원문

0.52.0 버전까지 업데이트 해줘

## 09. 도우미 · 원문

0.52.0 업데이트를 계속 진행하겠습니다. 핵심 기능 구현은 반영됐고, 현재 새 설정 창과 업무 연결 화면의 작은 창 배치를 마무리하고 있습니다. 이후 최종 검사와 설치 파일·소스 업로드까지 이어서 처리하겠습니다.

## 10. 도우미 · 원문

원본 요청과 실행 기록, 증거 ZIP이 정확히 연결되는 검사와 JS 기록의 페이지 이동·검색 검사가 통과했습니다. 전체 회귀 검사와 밝은/어두운 테마의 화면 검사를 진행 중이며, 기존 버전과 0.52.0의 성능 측정 결과도 비교하고 있습니다.

## 11. 도우미 · 원문

원격 저장소를 다시 확인하니 0.52.0 설치 파일·소스·가이드가 전용 브랜치와 PR #86에 올라와 있습니다. 같은 버전 파일을 중복 게시하지 않도록, 올라간 소스와 검증 기록을 대조하고 다운로드 링크를 확인하겠습니다.

## 12. 도우미 · 원문

0.52.0 배포 파일과 소스의 해시가 일치하고, 기존 0.49.1·0.50.0 파일과 main은 그대로 보존된 것을 확인했습니다. 다만 원격 CI의 Windows 검색 검사와 실제 브라우저 연동 검사가 실패한 상태라, 이 두 환경까지 검증 완료로 안내할 수는 없습니다.

## 13. 도우미 · 원문

실패한 CI 작업 두 개만 다시 실행해 재현 여부를 확인하고 있습니다. 배포된 JAR는 3,707개 회귀·HTTP 검사와 새 화면 180개 검증에 사용한 파일과 해시가 일치합니다.

## 14. 도우미 · 원문

재실행에서도 브라우저 연동의 본문 해시 검사와 Windows 검색 검사가 실패했습니다. 0.52.0 설치 파일은 보존하고, 확인된 실패 내용과 재실행 결과를 가이드에 추가하겠습니다. 배포 완료와 환경별 검증 상태를 구분해 전달하겠습니다.
