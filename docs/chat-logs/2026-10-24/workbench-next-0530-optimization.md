## 도우미 응답 · 요약
- 0.52.0 릴리스·검증 기록을 확인하고 Windows 검색, 브라우저 본문 연결, 성능 기준선·대량 데이터, 설정 영구 보관, 여러 요청 비교 준비 유지, 업무별 남은 점검을 제안했다.
- 사용자가 전체 구현을 요청했다. 구현·검증·새 JAR/소스 제공을 진행한다.
- 로컬 저장소 복제가 네트워크 권한 대기에 멈춘 뒤 GitHub 연결 도구로 소스를 복원하는 방식으로 전환했다.
- 최신 main 45d79f91f1cfd217c1e41b81b408001a8c62a04e에 0.52.0 병합이 확인되어 이 커밋을 기준으로 한다. 기존 배포물을 보존한다.
- 소스 복원을 완료하고 변경 전 스냅샷을 만들었다. 검색 완료 판단, 브라우저 연결, 설정/비교 준비, 남은 점검, JS 성능 개선을 병렬로 진행한다.

## 빌드 준비
로컬 도구의 대형 바이너리 읽기 제한으로 저장소에 이미 포함된 공개 빌드 입력을 같은 저장소의 GitHub Actions artifact로 전달한다. 새 작업 브랜치만 사용하며 main·이전 배포·접근 설정은 변경하지 않는다. 이 준비 작업을 제품 검증 통과로 집계하지 않는다.
