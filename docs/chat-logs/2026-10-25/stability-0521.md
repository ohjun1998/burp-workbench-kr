# Workbench Next 0.52.1 원격 검증 재개

## 02. 도우미 · 원문

## 03. 도우미 · 원문

[PR #88](https://github.com/ohjun1998/burp-workbench-kr/pull/88)에 0.52.1 소스·설치파일·검증 기록을 올렸습니다. 기존 버전은 보존했습니다. 지금 원격 검사가 시작됐으며, 이전에 실패했던 Windows 검색과 브라우저 본문 검사가 해소됐는지 확인하겠습니다.

## 04. 도우미 · 원문

실제 Chrome 브라우저 연동 CI가 통과했습니다. POST 본문 해시 대조와 PATCH 본문 미관측 처리가 실제 브라우저에서도 검증됐습니다. 별도 검토에서도 다운로드 링크·소스 지문·이전 버전 보존에 문제가 없었습니다. 남은 항목은 전체 기본 CI와 Windows 저장·수집 검사입니다.

## 05. 도우미 · 원문

원격 Linux 전체 회귀와 디스크 용량 부족 시 복구 검사가 통과했습니다. Windows는 전체 회귀를 실행 중이고, Linux는 3분 연속 수집을 확인 중입니다. 이 필수 검사들이 끝나면 결과를 기록하고 이번 안정화 범위를 마무리하겠습니다.

## 06. 도우미 · 원문

Windows 전체 Java 회귀도 통과해 이전 검색 실패가 해소된 것을 확인했습니다. 현재 저장·복구 검사 10회 반복과 연속 수집 검사를 진행 중입니다. 브라우저 검사는 이미 통과했으며, 지금까지 새 차단 결함은 확인되지 않았습니다.

## 07. 도우미 · 원문

Linux 연속 수집은 3분 동안 3,619건을 보존했고 유실·처리 오류 없이 통과했습니다. 디스크를 실제로 가득 채운 뒤 기존 기록 보존과 저장 재개도 확인했습니다. Windows 반복 검사와 기본 CI의 남은 화면·권한 검사가 진행 중입니다.

## 08. 도우미 · 원문

Windows 저장·복구 10회 반복과 Mapper 검사도 통과했습니다. Windows는 마지막 3분 수집 검사를 실행 중이고, 기본 CI는 50개 업무의 계정별 권한 비교를 확인 중입니다. 완료 후 검증 기록을 갱신하겠습니다.

## 09. 도우미 · 원문

기본 CI의 계정 검사는 50개 업무를 인증 조합과 설정별로 총 1,400회 비교하는 단계라 시간이 걸리고 있습니다. 이 검사가 끝나면 남은 화면 검사와 배포 지문 확인으로 마무리됩니다.

## 10. 도우미 · 원문

1,400회 계정 비교와 Windows 연속 수집 검사가 통과했습니다. 현재 마지막 화면 배치·시작 스크립트·배포 지문 검사를 확인 중입니다. 완료되면 결과를 문서와 PR에 반영하겠습니다.

## 11. 도우미 · 원문

필수 원격 검사 3개가 모두 첫 실행에서 통과했습니다. Windows 검색·저장·수집, 실제 Chrome 연동, 1,400회 계정 비교, 화면·배포 지문 검증까지 완료됐습니다. 이제 결과를 문서와 PR에 기록하고 0.52.1 안정화를 마무리하겠습니다.

## 12. 도우미 · 원문

최종 기록의 검사 수치와 한계까지 교차 확인했습니다. 검증한 코드와 설치파일은 그대로 두고 결과 문서·대화 기록만 추가합니다. 정한 종료조건을 모두 충족했으므로 이번 안정화는 마무리할 수 있습니다.
