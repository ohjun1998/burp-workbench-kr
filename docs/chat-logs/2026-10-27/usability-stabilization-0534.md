# Workbench Next 0.53.4 고정 범위 사용자 편의성 안정화·main 반영

- 날짜: 2026-10-27 (Asia/Seoul)
- 작업: usability-stabilization-0534

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

사용자 편의성 중심으로 최적화 및 고도화 제시해줘

## 02. 도우미 · 요약

현재 0.53.3 기준으로 작업 유실 방지, 읽는 위치 유지, 반복 조작 단축을 중심으로 8개를 제안했다: 작성 중 초안 자동 저장, 다단계 실행 취소·다시 실행과 비우기 복구, 수집을 유지한 목록 화면 고정, 명확한 중요 표시·해제와 복구, 글자·밀도·배치 개인화, 키보드 선택행 조작, 백그라운드 비교와 작업 현황 최소 갱신, 증거별 설명·재현 절차 작성 지원.

## 03. 사용자 · 원문

개선 사항 안 나오게 할 수 없어?

## 04. 도우미 · 요약

모든 잠재 개선점을 영구히 없앨 수 있다고 보장하지 않았다. 제시한 8개로 범위를 고정해 전체 수집→검색→비교→증거 저장과 재시작·대량 데이터·작은 창을 점검하고, 완료 기준을 통과하면 마무리하며 이후 실제 사용에서 확인된 문제를 중심으로 대응하겠다고 안내했다.

## 05. 사용자 · 원문

적용해서 main에 병합까지 해줘

## 06. 도우미 · 원문

제시한 8개 개선을 이번 범위로 고정해 구현하고, 전체 사용 흐름을 검증한 뒤 main에 병합하겠습니다. 현재 main과 저장소 지침부터 확인하고 독립적인 기능은 나눠 진행하겠습니다.

## 07. 도우미 · 원문

이번에는 초안 복원, 편집 복구, 목록 고정, 일괄 변경, 화면 개인화, 키보드 조작, 비교 반응성, 증거 작성 지원까지 8개를 적용합니다. 클라우드 환경 점검 스킬로 빌드·GitHub 연결 상태도 확인하고 있습니다.

## 08. 도우미 · 원문

현재 main은 0.53.3이며 새 작업 브랜치를 만들었습니다. 초안·증거 편집, 트래픽 목록, 화면 설정, 비동기 비교를 나눠 구현 중입니다. 새 버전은 0.53.4로 준비하고, 재시작 후 복원과 수집 중 선택 위치 유지까지 확인하겠습니다.

## 09. 도우미 · 원문

초안 저장과 다단계 편집 이력 모델의 독립 검사가 통과했습니다. 재시작 복원, 프로젝트 분리, 저장 실패·손상 기록 보존, 실행 취소·다시 실행을 확인했습니다. 지금은 이 모델을 증거 화면에 연결하고, 목록 고정 중에도 수집이 계속되는 흐름을 통합하고 있습니다.

## 10. 도우미 · 원문

목록 고정, 새 요청 수 표시, 명시적인 중요 표시·해제, 키보드 행 조작을 구현했고 관련 기존 회귀 검사도 통과했습니다. 화면 개인화와 백그라운드 비교를 연결한 뒤, 전체 빌드와 작은 창·확대 글자 검증으로 넘어가겠습니다.

## 11. 도우미 · 원문

8개 기능을 연결한 첫 생산 빌드가 통과했습니다. 검토 중에는 항목을 바꿔 편집할 때 미적용 메모가 사라질 수 있는 경로와, 새 원본 저장 실패 시 복구 이력이 지워질 수 있는 경로를 발견해 수정하고 있습니다. 이어서 실제 화면 배치와 전체 회귀 검사를 진행합니다.

## 12. 도우미 · 원문

확대 글자와 실제 패킷 본문까지 화면 설정을 연결했고, 전체 회귀 검사가 진행 중입니다. 화면 검사에서는 테스트 하네스가 네이티브 창 없이 화면 객체를 붙여 만들던 오류를 확인해 바로잡았습니다. 제품의 접근성 기능과 기존 화면 배치 기준은 유지합니다.

## 13. 도우미 · 원문

1024px 창에서 글자를 125%·150%로 확대하면 요청·응답 본문 공간이 부족해지는 문제를 확인했습니다. 툴바 줄바꿈과 검색 조작 배치를 고쳐 읽기 공간을 확보하고 있습니다. 같은 배율에서 증거 작성과 응답 비교 화면도 함께 검증하고 있습니다.

## 14. 도우미 · 원문

1024px·150% 확대 상태에서 패킷, 증거 작성, 응답 비교의 본문 공간을 확보했습니다. 이제 수정한 소스를 함께 빌드해 전체 회귀 검사와 모든 화면 모드를 다시 확인하겠습니다. 통과하면 CI 배포 파일을 생성하고 PR 검증 후 main에 병합합니다.

## 15. 도우미 · 원문

통합한 1024px 확대 화면 검사가 통과했습니다. 세 배율의 핵심 화면에서 본문 축소, 버튼 크기, 글자 잘림 기준을 모두 충족했고 41개 상태 검사도 통과했습니다. 전체 회귀 검사와 나머지 창 크기·테마 검증을 진행 중입니다.

## 16. 도우미 · 원문

전체 Java 회귀와 페이로드 HTTP 검사가 통과했고, 전체 화면·집중 화면 검사도 양 테마에서 통과했습니다. 실제 HTTP 검사의 한 하네스가 비교 결과를 즉시 읽는 이전 방식에 맞춰져 있어 비동기 완료를 기다리도록 수정 중입니다. 나머지 화면 모드와 HTTP 검증까지 마치고 게시하겠습니다.

## 17. 도우미 · 원문

로컬에서 총 4,744개 검사와 10개 화면 모드가 모두 통과했습니다. 전체 화면은 576개, 집중 화면은 414개를 검사했으며 각 검사에서 잘림·본문 축소가 없었습니다. 이제 변경 내용을 GitHub에 올려 Linux·Windows CI와 배포 파일 검증을 진행하겠습니다.

## 18. 도우미 · 요약

로컬 최종 생산 소스는 Java 회귀122그룹4240개+payload HTTP136개를 통과했다. 초기HTTP단계의동기결과가정을 고친활성하네스로 실제HTTP102개와 모의진단266개를 재실행하고 Mapper Java134/Node15도 통과했다. dev.write_check_summary의합계4744를확인했다. 전체576뷰8088컨트롤246상태와 집중414뷰4308컨트롤246상태, 나머지8UI모드가모두통과했다. 두UI검사는겹쳐합산하지않는다. 실제BurpGUI·DPI/IME수동검증을주장하지않는다.
