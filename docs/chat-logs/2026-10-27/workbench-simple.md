# Workbench Simple 1.0.0 별도 생성과 단계별 가이드

- 날짜: 2026-10-27 (Asia/Seoul)
- 작업: workbench-simple

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

workbench에서 핵심 메인 기능만 주력으로 사용 할 수 있도록 최적화 및 재구성해서 생성해줘

- 꼭 필요하지 않은 부가적인 기능들은 제거해서 메인 기능에 집중할 수 있게해줘
- UI, UX도 핵심 기능 사용에 맞추어서 고도화해줘
- 기존 파일은 냅두고 Simple 버전 이름으로 새롭게 생성해서 구분해줘
- 사용 단계별로 이미지 캡쳐해서 가이드 북 작성해줘
- 기존 extension은 유지하는데 실행 과정들만 핵심만 포함하고 부가적인 기능들은 제거해서 사용자 편의성에 맞추어줘

## 02. 도우미 · 요약

기존 파일과 extension을 유지하고 Simple 버전을 별도로 만들며 주요 기능·UI/UX·단계별 캡처 가이드를 정리하겠다고 안내했습니다. 작업 폴더가 비어 원본 위치를 질문한 뒤 연결된 GitHub에서 저장소 후보를 찾았습니다.

## 03. 사용자 · 원문

https://github.com/ohjun1998/burp-workbench-kr.git

## 04. 도우미 · 요약

기존 0.53.4 파일을 보존하고 Simple 전용 JAR·설정 공간으로 분리하기로 안내했습니다. 수집→분석→검증→증거 네 단계로 재구성하며 통합 도구 엔진·원본·비교 결과·증거 연결을 유지했습니다. 선택한 요청의 비교 준비/Repeater 준비/증거 추가를 바로 제공하고 자동 비교 토글·중복 탐색·작업 이어가기·외부 도구/OAST/순차 재현 보조 화면·시작 History 자동 순회를 메인 흐름에서 제거했습니다.

## 05. 도우미 · 요약

현재 환경의 Java 21에 ct.sym이 없어 명시적 -source 17 -target 17을 사용하며 Java 17 플랫폼 API 검증은 주장하지 않는다고 안내했습니다. 기본 빌드 --release 17은 유지합니다. 초기 샌드박스의 loopback 차단은 최종 실행에 네트워크 권한을 사용해 해결했습니다. 원래 Next 화면을 기대하는 일부 검사는 Simple 계약으로 좁게 조정하고 엔진 검사는 유지했습니다.

## 06. 도우미 · 요약

최종 Simple 회귀 122개 그룹 4,231개, payload HTTP 136개, 내장 Mapper Java 134개, 브라우저 도우미 Node 15개로 총4,516개를 통과했습니다. 밝은/어두운 테마와1024/1280 크기48화면,912컨트롤,32시나리오의 잘림/영역축소/실패0건을 확인했습니다. 합성 자료를 사용하는 실제 운영 Swing 캡처이며 실제 Burp GUI 검증은 미실행임을 안내했습니다. 11쪽 PDF와 독립 HTML 가이드를 제작했으며 기존 파일·기존 배포·main은 수정하지 않았습니다.
