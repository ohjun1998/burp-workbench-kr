# Workbench Simple 1.3.0 Katana 기반 Scope 정보 수집 고도화

- 날짜: 2026-10-28 (Asia/Seoul)
- 작업: simple-katana

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 요약

기존 Workbench와 이전 배포본을 보존하고 Simple 버전으로 구분하며, 기존 8개 extension의 핵심 기능과 사용자 편의성을 유지하고 단계별 캡처 가이드북을 제공하도록 요청했습니다.

## 02. 사용자 · 원문

지정한 scope를 대상으로 katana 사용해서 메뉴 및 기능들 접근하면서 정보(환경·경로·API·민감정보·권한 차이·변경 이력·미확인 항목 기타 등등)들 수집할 수 있게 고도화 해줘

## 03. 도우미 · 요약

Katana의 HTML·JavaScript·폼 경로 수집을 기존 Scope 통합 점검으로 연결하고 실제 요청이 Workbench의 Scope·HTTP 계정·요청 한도를 거치도록 구성한다고 안내했습니다. 동적 SPA는 기존 브라우저 탐색을 함께 유지합니다.

## 04. 도우미 · 요약

공식 Katana 1.8.0의 SHA를 고정한 외부 설치기를 추가하고 실제 다운로드·설치를 확인했습니다. HTTP/HTTPS 연결부와 실제 로컬 대상 검증을 구현했습니다. JavaScript 전용 경로 누락을 실제 실행에서 발견해 수정한 뒤 실제 Katana 102개 검사를 통과했다고 안내했습니다.

## 05. 도우미 · 요약

가이드북 확대 검수에서 실행 조건 정렬과 수집 상태 표시를 다듬고, 기존 8개 도구와 Simple 1.2.0 배포본을 유지하며 새 1.3.0의 Katana 설치·조건·결과 안내를 준비한다고 안내했습니다.

## 06. 도우미 · 요약

최종 빌드에서 자동 검사4,941개·실제 Katana HTTP/HTTPS 검증102개·화면 배치108개를 통과했습니다. 수집 시작 계정·Scope·조건별 이력 분리와 이전 배포파일16개의 해시 보존을 확인했습니다. 가이드북은34쪽·캡처27장으로 생성·확대 검수했습니다. 소스ZIP 독립 재빌드의 JAR가 배포본과 바이트 단위로 일치하며, GitHub 작업브랜치와 PR 및 원격 엄격 Java17 CI 확인을 준비합니다.
