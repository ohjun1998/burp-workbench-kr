# Simple 1.4.0 원터치 탐지 고도화 — 이어서 진행

기준 날짜: 2026-10-29 (Asia/Seoul). 작업 시작 요청과 이전 공개 안내는 [2026-10-28 기록](../2026-10-28/simple-onetouch-detection-140.md)에 보존합니다. 원문 응답·인증값·숨겨진 추론·도구 원문은 포함하지 않습니다.

## 적용 지시 원문

> 적용시켜줘

원터치 extension의 주요정보 탐지 확대·오탐 분류·실제 방문 증거·동적 API 관측 연결·계정별 확인·선택 재점검·가이드 갱신을 적용하라는 앞선 요청의 계속 작업입니다. 기존 도구 8개와 Next·이전 Simple 버전은 유지합니다.

## 공개 진행 안내 원문

> 고정한 새 JAR로 동일 응답 재분석을 마쳤습니다. 선별한 79개 항목 모두 값과 실제 원문 위치를 확인했고, 대조 표본에서 비밀값으로 잘못 승격된 항목은 없었습니다. 실제 Katana 검증 102개도 통과했습니다.
>
> 전체 회귀 검사와 새 버전의 사이트별 실행은 계속 진행 중입니다. 같은 JAR로 단계별 화면을 새로 캡처해 가이드북도 만들고 있습니다.

위 안내는 당시 고정한 후보 JAR의 검사 결과입니다. 이후 발견한 분류 오탐을 수정하여 최종 JAR 검증·캡처를 다시 진행하며 후보와 최종 결과를 합산하지 않습니다.

> 가이드 화면을 검토하다가 DB 접속 문자열의 일부가 이메일 후보로 중복 분류되는 사례를 찾았습니다. 파서에서 이를 구분하도록 수정하고 있습니다.
>
> 현재 후보의 결과와 캡처는 별도로 보존했습니다. 수정 후에는 새 JAR 기준으로 사이트 실행과 가이드 캡처를 다시 맞춰 제공하겠습니다.

> 실제 사이트 실행에서 LOOP의 기존 인증정보가 신원 확인에 401을 반환했고, extension이 정상적으로 점검을 멈춘 것을 확인했습니다. 나머지 인증 대상 4곳은 현재 신원 확인이 200입니다.
>
> LOOP는 기존 결과를 보존하고, 같은 계정으로 새로 로그인한 조건에서 이전·새 버전을 짝지어 다시 확인하겠습니다.

## 결과를 구분하는 원칙

- 실제 로컬 앱을 새로 실행한 전후 대조와 보존 응답의 오프라인 재분석을 구분합니다.
- 소스 문자열·API 템플릿·형태 일치 후보는 실제 변수 해소·권한 획득·대상 접근 성공을 뜻하지 않습니다.
- 초기 실패·후보 결과·인증 신원401·부분·중지·전송 오류를 별도로 보존합니다. 실제 수행 수와 최종 배포 지문은 해당 검증 기록과 PR 본문을 기준으로 읽습니다.
- 원문 값·로그인 인증정보·전체 HTTP 응답은 공개 Git에 올리지 않습니다. 새 설치 JAR·helper·가이드는 별도 버전으로 제공하고 이전 파일은 보존합니다.

## 이후 공개 안내와 실제 완료 결과

아래는 추가 진행 답변의 요약이며 원문 인용은 아닙니다.

- 실제 사이트에서 중지 직전 수신한 응답이 결과·보고서 목록에 빠지는 경계를 찾아, 원본을 `RESPONSE_PENDING_ANALYSIS`·`complete=false`로 보존하도록 수정하고 재검증했습니다.
- 최종 JAR의 전체 검사5,476개, 실제 Katana102개, 실제 사이트 전후28회 대조의 범위·예산·계정·원본 연결 검증을 통과했다고 안내했습니다.
- 새 캡처33개를 포함한40쪽 가이드와 배포 파일·소스 묶음을 만들고 별도 소스 재빌드를 진행한다고 안내했습니다.
- 테스트에 사용한 사이트·컨테이너는 종료하고 원본·DB 볼륨·기존 백업·실행 결과를 보존했습니다.

실제로 생성한 JAR는 `675ca941665611a540912308c8b59f8a3f683b647cc1546ed926993e856d2637`이며 소스 ZIP1,748개 지문·CRC를 검증한 별도 빌드에서도 같은 JAR가 나왔습니다. helper는0.5.0, 내장 Mapper는0.3.7입니다. 이전 배포322개 지문은 모두 유지했습니다.

새 설치 파일과 가이드는 [Simple 안내](../../../simple/README_KR.md), 실제 검사·미실행 범위는 [버전 검증 기록](../../../simple/docs/VERIFICATION_SIMPLE_1.4.0.json), 후보·실패·보존과 새 실행의 상세는 [인수인계](../../reports/2026-10-29-simple-onetouch/HANDOFF_KR.md)에 기록합니다. GitHub Actions의 실제 실행과 PR 상태는 PR 본문에 별도 연결하며 로컬 검사와 구분합니다.

## 게시 전 공개 안내

아래는 이어서 제공한 답변 원문입니다.

> 핵심 탐지 기능과 경로 수집 개선을 적용했고, 재테스트와 캡처 가이드북 작성까지 마쳤습니다. 최종 배포 파일을 확인한 뒤 변경 사항을 PR로 올리고 자동 검증 결과를 확인하겠습니다.

> 최종 파일 검증을 통과했고, 기존 배포·가이드 파일 322개의 체크섬도 그대로 유지했습니다. 새 버전은 기존 도구 8개를 유지하면서 주요정보 분류, 경로별 처리 상태와 미확인 사유, 선택 재점검을 보강합니다. 가이드북은 40쪽에 단계별 캡처 33개를 담았습니다.
