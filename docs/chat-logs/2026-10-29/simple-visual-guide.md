## 답변 원문

> 공유하신 대화와 기존 Simple 가이드를 확인해, 사용 흐름과 단계별 화면을 담은 가이드북으로 정리하겠습니다.

> 공유 대화를 확인했습니다. 원하신 형식은 화면마다 **클릭 위치를 번호·화살표·박스로 표시하고, 아래에 짧은 설명과 정상 결과를 붙이는 방식**입니다. 이 형식으로 Simple 1.4.0 가이드를 새로 만들고, 확대·검색·단계 이동이 가능한 HTML과 PDF를 함께 제공하겠습니다.

> 기존 캡처를 새 안내서에 연결하면서 버튼 이름과 클릭 위치를 확인하고 있습니다. 각 단계는 **해야 할 작업 → 번호가 표시된 화면 → 조작 설명 → 정상 결과 → 막힐 때 확인할 사항** 순서로 구성하겠습니다. 기존 가이드와 배포 파일은 그대로 보존합니다.

> 33개 화면의 조작 설명과 강조 번호 95개를 맞췄습니다. 재점검·보고서 저장처럼 조건에 따라 버튼이 비활성화되는 화면도 구분해 설명했습니다. 이제 PDF 배치와 HTML의 확대·검색·다크 모드를 확인하겠습니다.

> 번호·화살표가 들어간 40쪽 PDF 초안을 만들었습니다. 원본 화면의 픽셀은 그대로 두고 문서 위에 주석을 얹었습니다. 현재 전체 페이지의 겹침·잘림을 검토하고, 오프라인 HTML도 실제 Chromium에서 확인하고 있습니다.

> 최종 HTML의 Chromium 검사 33개가 모두 통과했습니다. 검색·확대·단계 이동·다크 모드·확인 상태 저장이 동작하고, 390·768·1440px 화면에서 가로 넘침이 없었습니다. 이 환경은 HTML 파일 직접 열기가 정책으로 차단돼, 같은 파일을 로컬 문서 서버에서 검증했으며 사용 방법도 안내서에 넣었습니다.

> 최종 가이드의 40쪽 전체 시각 검토를 마쳤습니다. 번호 겹침·확대 영역의 잘림·폰트 누락을 수정한 뒤, 최종 파일 기준으로 PDF와 HTML 검증을 통과했습니다. PDF·HTML·검증 기록을 다운로드 묶음으로 정리하고 있습니다.

## 작성·검증 결과 — 요약

공유 대화의 공개 페이지를 실제로 읽고 이미지별 번호·화살표·박스, 이미지 아래 설명, 정상 결과와 오류 해결, 확대·단계 이동 형태를 적용했습니다. 제3자 서비스의 화면을 복제하거나 사용했다고 주장하지 않습니다.

최종 PDF는 40쪽·40북마크이며 33개 원본 화면에 95개 주석을 연결했습니다. 시각 검토에서 계정 번호의 가림과 확대 영역의 불필요한 픽셀을 수정했습니다. 정적 폰트 검사에서 미지원 말줄임 문자 1개를 발견해 ‘더 보기 버튼’ 문구로 바꾸고 문서 QA를 다시 확인했습니다. 기존 후보·검토 결과를 별도 보존했고 이번 사이트 재테스트로 합산하지 않습니다.

HTML의 실제 Chromium 검사와 PDF 전 페이지 렌더링·시각 검토, 링크·좌표·원본 지문을 새 문서 검증으로 구분합니다. file://의 관리 정책 차단을 변경하지 않고 같은 HTML 바이트를 허용된 loopback 문서 서버에서 확인했으며 외부 요청은 차단했습니다. 실제 Burp GUI·native MV3 설치 검증으로 표현하지 않습니다.

결과물과 새 문서 검증 기록은 [가이드 안내](../../guides/simple-1.4.0-visual-20261029/README_KR.md)에 연결합니다. GitHub PR·자동 검사 상태는 해당 PR의 실제 기록을 기준으로 읽습니다.

공개할 최종 PDF는 SHA256 `443eda3860bf4d685d96e0611bc47be5a5a6e167bc2c1d08ab6eb0ae9492dc20`, HTML은 `f486b7401681e3ad4409c0cf94bd8ee16e4fe2a6e91630eabadb8f88d3b7d7a7`입니다. 기존 제품 입력 1,688개 지문이 모두 유지됐고 ZIP의 CRC·내장 PDF/HTML·검증 기록·체크섬도 확인했습니다. 이 숫자는 제품 검사를 새로 수행한 수가 아닌 문서 작업의 보존 확인 범위입니다.
