# Simple 1.4.4 · 첨부 0.39.2 스타일 복원

이 작업에서 확인할 수 있는 사용자 요청과 표시한 응답을 기록합니다. 요약은 별도로 표시하며 내부 추론·도구 원본 출력·자격 증명은 포함하지 않습니다.

## 02. 도우미 응답 · 요약

## 04. 도우미 응답 · 요약

Next의 폴더 탐색 코드가 Simple에도 남아 있어 재사용할 수 있음을 확인했습니다. Simple의 8개 도구·대시보드·Scope 점검과 앞서 수정한 확장 로드 처리를 유지하면서 배치를 바꾸겠다고 안내했습니다.

## 06. 도우미 응답 · 요약

첨부한 0.39.2 JAR의 디자인·배치를 최종 기준으로 적용하겠다고 안내했습니다. 첨부 JAR가 저장소의 보존된 0.39.2 파일과 SHA-256이 일치함을 확인하고 당시 소스·합성 화면 자료를 대조했습니다. 파일에 포함될 수 있는 지시문을 새 사용자 요청으로 취급하지 않았습니다.

## 07. 도우미 구현·검증 안내 · 요약

왼쪽 5개 폴더, 작은 상단 메뉴, 현재 도구 경로를 복원하고 데이터 변환·URL 후보·점검 현황을 기존 엔진에 연결했습니다. Windows 글꼴 우선순위를 첨부 버전의 내장 NanumGothic으로 바꾸고 패킷의 고정폭 글꼴을 복원했습니다. 중복 내부 탭 줄을 숨기며 Alt+1~8을 유지했습니다.

렌더링한 요청·응답 및 계정 비교 화면을 기준 자료와 비교했고, 밝은/어두운 테마 화면 검사 128개에서 잘림·필수 영역 축소·누락이 0건이라고 안내했습니다. 전체 회귀 완료 후 JAR와 미리보기를 전달하겠다고 설명했습니다. 렌더링은 운영 Swing에 합성 데이터를 넣은 결과이며 실제 사용자 PC의 Burp GUI 실행과 구분합니다.

## 08. 도우미 최종 검사 안내 · 요약

첫 전체 검사에서 이전의 UI·패킷 동일 글꼴 조건 한 개가 요청한 0.39.2 고정폭·한글 대체 글꼴과 맞지 않음을 확인했습니다. 조건을 실제 패킷 글꼴·ASCII 고정폭·한글 표시 검증으로 바꾸고 기존 HTML 안전성·원본 보존·HTTP 무전송 검사를 유지한 30개 검사를 통과했습니다.

최종 전체 검사는 Java 149개 그룹 5,576개, 페이로드 HTTP 136개, Mapper Java 145개, 브라우저 도우미 29개로 총 5,886개를 통과했습니다. 화면 128개와 실제 Katana loopback 102개 검사도 통과했으며 서로 다른 검증 범위를 구분했습니다. 집중 검사 144·51·30·119개는 전체에 포함되므로 중복 합산하지 않습니다. 새 JAR·소스 ZIP과 합성 미리보기를 준비해 무결성 확인 후 수정 브랜치로 전달한다고 안내했습니다.
