# Simple 1.4.4 · 도구별 화면 캡처

- 날짜: 2026-10-30 (Asia/Seoul)
- 작업: simple-tool-captures

사용자에게 표시된 대화만 기록합니다. 요약은 별도로 표시하며 내부 추론·도구 원본 출력·자격 증명은 포함하지 않습니다.

## 01. 사용자 요청 · 원문

extension 별로 화면 캡쳐해서 보여줘

## 02. 도우미 응답 · 요약

현재 1.4.4의 도구별 화면을 보여주겠다고 안내했습니다. 실제 Burp GUI를 실행한 캡처가 아니라 운영 Swing 컴포넌트에 합성 데이터를 넣은 미리보기라는 점을 명시했습니다.

## 03. 도우미 상태 안내 · 요약

8개 도구의 캡처를 확인해 도구별로 정리하고 밝은/어두운 테마 원본을 묶겠다고 설명했습니다. 기능 자동 매핑은 빈 프로젝트, 입력값 검사는 실행 전, 서버·경로 탐색은 후보 검증 전이라는 상태를 표시했습니다.

## 04. 결과 · 요약

현재 1.4.4 JAR와 캡처 보고서의 SHA-256 일치를 확인한 PNG를 그대로 복사했습니다. 8개 도구와 재현·증거 도구의 추가 재현 탭 1개를 1280×800 해상도의 밝은/어두운 테마 18장으로 정리하고 갤러리·ZIP·파일 해시 목록을 작성했습니다. 합성 예시의 계정·세션 값은 사용자 인증정보가 아닙니다. 앱 코드와 기존 배포 JAR·소스 ZIP은 변경하지 않았습니다.
