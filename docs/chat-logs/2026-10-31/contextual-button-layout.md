## 이전 답변 요약

13개 화면의 버튼 배치를 시안4장으로 제안했고, 내부 작업 공간 링크가 열리지 않는 문제를 공개 저장소 이미지 링크로 고쳤다. 사용자는 변경한 시안을 소스에 적용하라고 요청했다.

## 구현·진행 안내 요약

기존 기능과 입력·선택을 유지하면서 버튼을 해당 작업 영역으로 옮기고 작은 창에서도 실행·중지를 보이게 하겠다고 안내했다. 통합 설정 메뉴, 단계별 payload 결과 버튼, 입력/출력별 변환 도구, 선택 상세의 증거·Repeater·출처 작업을13개 화면에 적용했다. 계정 카드와 반복 제목도 압축했다. 번호 가이드16개와96개 위치를 새 배치에 맞췄다.

실제 창에서 기존 버전에도 있던 Workbench/Mapper 테마 재적용 반복을 확인하고 감시 경계와 UI 교체를 수정했다. 작은 CVE 화면의 메타데이터 배치를 보완하고 실제 창으로 두 테마의 필터 표시를 확인했다. 분리된 헤드리스 트리의 레이아웃 캐시 처리도 보완해 실제 창과 캡처를 교차 검증했다.

최종 전체7073개, Swing194화면, 실제 창112개, Katana102개가 통과했다. 이미지93장·가이드·이전/시안 비교를 갤러리와 ZIP으로 정리해 Simple1.4.12 설치 JAR/소스와 함께 전달한다. 실제 Linux 창과 합성 Burp 어댑터 검증이며 Windows Burp는 직접 검증하지 않았다. 기존 main 병합 승인 범위에서 작업 브랜치와 일반 병합으로 전달하며 이전 아티팩트는 보존한다.

## 패키징·업로드 안내

JAR·소스·이미지 ZIP의 패키징과 무결성 검증을 완료했다고 안내했다. 기존 main 반영 요청에 따라 병합 후 공개 파일을 재다운로드 확인하고 내부 작업 경로 대신 공개 링크를 전달한다. GitHub CLI 토큰이 유효하지 않아 PR 생성은 사용할 수 없으므로 기존 승인 범위에서 일반 Git 병합을 진행한다. 강제 push는 사용하지 않는다.

## 최종 병합·전달 안내

main 병합과 공개 다운로드 확인을 완료했다고 안내했다. JAR·소스 ZIP·이미지 ZIP을 실제 재다운로드해 체크섬을 확인했고 실제 화면 링크도 HTTP200으로 열렸다. Simple1.4.12 설치 파일과 소스,13개 도구별 적용 화면·이전/시안 비교·Guide를 포함한 이미지93장 자료를 공개 링크로 전달한다. 회귀7073개·화면194개·실제 창112개 통과와 Windows Burp 직접 검증 미실시를 구분해 안내한다. [시안·이전 링크 수정 대화](button-layout-proposal.md)도 보존했다.
