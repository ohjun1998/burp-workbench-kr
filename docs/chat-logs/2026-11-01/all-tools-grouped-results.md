# 전체 URL 결과 목록 A 그룹형 소스 적용 · Simple 1.4.22

- 날짜: 2026-11-01 (Asia/Seoul)
- 작업: all-tools-grouped-results

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

A 그룹형으로 소스코드 수정해줘

## 02. 도우미 · 원문

A 그룹형을 실제 확장의 기능 자동 매핑 화면에 적용하겠습니다. 기능명·요청 건수와 접이식 그룹을 표시하고, 선택 상세에서 원본 URL을 확인할 수 있도록 수정한 뒤 검증하겠습니다.

## 03. 사용자 · 원문

기능 자동 매핑뿐만 아니라 다른 확장자에도 저런식으로 보여주는 곳이 있는데 다 확인해서 A 그룹형 소스코드로 수정해줘(첨부한 이미지 외 다른데에도 있음)

## 04. 사용자 · 요약

대시보드의 API·명세 183행과 환경·DB 단서 53행에서 긴 URL 및 반복 내용이 보이는 화면 두 장을 첨부했다.

## 05. 도우미 · 원문

범위를 전체 도구로 넓혀 확인하겠습니다. 첨부하신 대시보드의 API·명세, 환경·DB 목록뿐 아니라 다른 화면의 긴 경로·중복 목록도 점검해 A 그룹형으로 정리하겠습니다. 개별 관측 건수와 판정은 유지하고, 원본 URL과 증거는 선택 상세에서 확인할 수 있게 하겠습니다.

## 06. 도우미 · 요약

13개 도구와 보조 창을 조사해 URL 중심 결과 목록에 유형 그룹·짧은 기능명·원본 건수·원본 정보 펼치기를 연결했다. API 후보는 업무/인증/문서/정적 자산 등으로 나누고 환경·DB의 같은 관측은 합산 건수를 표시한다. 입력값·JSONPath·Raw는 본래 값을 유지했다. 기존 표 모델·정렬·ID·바이트·원본 연결과 명시적 실행을 보존했다. 좁은 카드의 배치와 열 가독성, JS 호출 위치별 선택, 폴더 접기와 명시적 선택 해제의 차이를 검증하고 보완했다.

## 07. 도우미 · 원문

전체 자동 검사 **8,289개가 통과**했고, Simple **1.4.22** JAR와 소스 ZIP 생성도 완료했습니다. 배포 파일의 무결성과 최종 JAR의 화면 검사를 확인한 뒤 다운로드 링크를 정리하겠습니다.

## 08. 도우미 · 요약

최종 Simple1.4.22/Mapper0.3.22/helper0.4.1 패키지를 검증했다. 자동 8289개와 공식 JAR의 실제 Linux Swing 1632개 검사·156캡처를 통과했다. 합성 API 어댑터이며 Windows Burp 본체 검증이 아니다. 이전1.4.21 배포 파일과 은행 결과 HTML은 원래 SHA를 보존했다. 관련 소스·설치 JAR·소스 ZIP·검증 보고서를 작업 브랜치에서 제공한다.
