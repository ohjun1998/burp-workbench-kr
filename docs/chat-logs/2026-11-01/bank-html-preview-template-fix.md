# 도구 결과 HTML 미리보기 · 생성 템플릿 오인 수정

- 날짜: 2026-11-01 (Asia/Seoul)
- 작업: bank-html-preview-template-fix

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 요약

layout-results-template.html이 열린화면에 “시각화 내부에서 오류가 발생했습니다” 메시지가표시된스크린샷을첨부했다.

## 02. 도우미 · 원문

화면에 열린 파일이 데이터가 채워지기 전 템플릿으로 보입니다. 완성된 HTML과 미리보기 방식을 확인해서, 결과가 정상 표시되는 파일로 바로잡겠습니다.

## 03. 도우미 · 원문

원인을 확인했습니다. 생성용 템플릿에 남아 있는 데이터 자리표시자 때문에 미리보기에서 오류가 납니다. 템플릿은 미리보기 대상으로 잡히지 않도록 파일 형식을 바꾸고, 데이터가 포함된 완성 HTML을 열도록 요청했습니다.

## 04. 도우미 · 요약

생성용파일을.html.in으로구분하고generator참조를수정했다. 템플릿바이트와기존완성HTML/ZIP SHA는그대로이다. 완성본에89개실제트래픽·525개Scope행데이터가내장됨을확인했다. Codex패널에정확한완성파일을열도록요청했고UI도구는queued를반환했다. 실제Codex화면표시가완료됐다고추측하지않는다.
