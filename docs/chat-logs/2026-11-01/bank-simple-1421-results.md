# Simple1.4.21 · 실제 로컬 은행 진단과 도구별 결과

- 날짜: 2026-11-01 (Asia/Seoul)
- 작업: bank-simple-1421-results

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 도우미 · 요약

앞선 작업에서 Simple1.4.21의 통합 점검·대시보드 컴팩트 메뉴를 적용하고 JAR를 작업 브랜치에 올렸다. 이번 작업은 그 배포 JAR를 그대로 사용하며 제품 소스나 과거 배포물을 바꾸지 않는다.

## 02. 사용자 · 원문

취약점 진단 테스트 용 사이트(은행 웹 사이트)를 로컬에 생성하고  Workbench SImple 1.4.21 내 확장자들을 사용해서, 확장자 별로 얻을 수 있는 결과 값을 보여줄래?

## 03. 도우미 · 원문

로컬 은행 실습 사이트를 준비하고, Workbench Simple 1.4.21의 각 도구로 얻은 결과와 원본 요청·응답을 묶어 보여드리겠습니다. 먼저 저장소의 은행 실습 환경과 검증 도구를 확인해 재사용하겠습니다.

## 04. 도우미 · 원문

로그인·계좌 조회·이체·관리자 기능이 있는 기존 VulnBank를 이 환경의 로컬 주소에 준비하고 있습니다. “확장자별” 결과는 Simple 안의 8개 주요 도구와 통합 점검·대시보드를 기준으로 정리하겠습니다. 도구가 표시한 후보와 실제 재현으로 확인한 취약점은 구분해서 보여드리겠습니다.

## 05. 도우미 · 원문

은행 사이트가 로컬에서 기동했고, 관리자·Alice·Bob 계정의 로그인과 계좌 조회를 확인했습니다. 이제 같은 요청을 계정별로 비교하고, SQL 입력값 검사·음수 이체 재현·JS/API 추출·환경 탐색을 실행하겠습니다. 결과 화면과 요청·응답 근거도 함께 저장합니다.

## 06. 도우미 · 원문

독립적인 요청 대조에서 SQL 로그인 우회, 비로그인 타인 잔액 조회, JWT 변조 후 관리자 접근을 재현했습니다. 반대로 일반 계정의 관리자 접근과 음수 대출 요청은 정상 차단됐습니다. 이 확인 결과를 각 도구의 분석 후보·출력값과 나란히 비교할 수 있게 정리하고 있습니다.

## 07. 도우미 · 원문

Simple 1.4.21의 주요 도구 실행은 모두 확인했습니다. 계정 비교에서는 타인 계좌 조회를 ‘우회 의심’으로, 입력값 검사에서는 참 조건 200·거짓 조건 404를 ‘SQL 조건 차이 후보’로 표시했습니다. 지금은 해당 결과 행과 요청·응답 상세가 보이도록 실제 화면 캡처를 보완하고 있습니다.

## 08. 도우미 · 원문

은행의 준비·재시작 명령도 클라우드 설정 초안에 저장했습니다. 다음 클라우드 작업에서도 유지하려면 환경 설정에서 변경 사항을 검토·저장한 뒤 Publish하면 됩니다. 현재 실행 중인 은행과 결과 검증은 계속 진행하고 있습니다.

## 09. 도우미 · 요약

실제 은행 페이지와 두 테마의 제품 화면, 별도 증거 ZIP을 완성했다고 안내했다. 실제 음수 이체 -5에서 Alice1000→1005/Bob1000→995를 확인했고, 제품의 HTTP 기대 조건 일치와 독립적인 숫자 변화 대조를 분리한다고 설명했다. 중간 안내의 일부 문장과 원 단위 표기는 뒤의 달러($) 기준으로 바로잡았다. 사이트의 통화는 달러이고 모든 잔액은 가짜 실습 값이다.

## 10. 도우미 · 원문

도구별 실제 값과 화면을 볼 수 있는 HTML·CSV 보고서를 만들었고, 원본 요청·응답 지문과 공개 파일의 인증값 노출 검사도 통과했습니다. 금액 표기는 사이트의 표시 단위인 달러($)로 바로잡았습니다. 진단 중 발견한 기준 계정 이름 표시 문제와 증거 자동 연결 문제도 보고서에 기록했습니다.

## 11. 도우미 · 원문

은행 사이트 ZIP과 전체 결과 ZIP을 완성했습니다. 실제 화면 35장과 도구별 JSON·CSV를 포함했고, 인증 원문은 제외했습니다. 기존 1.4.21 JAR도 변경 없이 유지했습니다. 저장소에 올린 뒤 다운로드 링크를 확인하겠습니다.

## 12. 도우미 · 원문

두 ZIP과 주요 실제 화면을 저장소에 올렸습니다. 공개 링크에서 12개 파일을 다시 내려받아 체크섬과 ZIP 무결성을 확인했습니다. 은행은 클라우드 로컬에서 계속 실행 중이며, PC에서는 사이트 ZIP의 실행 명령으로 재현할 수 있습니다.
