# Simple1.4.19 상단 테마 전환과 빈 도구 메뉴 수정

- 날짜: 2026-11-01 (Asia/Seoul)
- 작업: header-tools-theme-fix

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

저렇게 뜨는데 수정 좀 해줘

## 02. 사용자 · 요약

첨부 화면에는 상단 달 모양 버튼 아래에 큰 빈 메뉴와 맨 아래 Guide만 표시되어 있다.

## 03. 도우미 · 요약

아이콘 전용 원본 버튼의 빈 제목을 메뉴로 복사해 행들이 비어 있음을 확인했고, 이름과 아이콘을 유지하도록 수정한다고 안내했다.

## 04. 사용자 · 원문

달 모양이 원래 다크 / 라이트 모드 변경되는 기능 아닌가?

## 05. 도우미 · 원문

맞습니다. 달 모양은 라이트·다크 전환으로 동작하는 게 맞습니다. 제가 그 버튼에 설정·창 도구 메뉴를 연결한 것이 잘못됐습니다.

클릭하면 테마가 바로 바뀌도록 수정하겠습니다. 기존 설정·창 도구는 이름이 분명한 별도 메뉴로 옮기겠습니다.

## 06. 도우미 · 요약

달 버튼은 테마 전환으로, 설정·전체 화면·오류 기록은 별도 톱니 메뉴로 분리한다. 수정 전 빈 메뉴를 재현하고 실제 창의 테마 변경과 입력·선택 보존을 검증한다.

## 07. 도우미 · 요약

달/해 직접 전환과 별도 톱니 메뉴, 계정 편집기 교체 충돌, Workbench/Mapper 선택 목록·스크롤·검색 강조의 테마 캐시를 수정했다. 실제 창296개, 전체 도구600개 시나리오, 버튼/창/가이드180개 검증을 통과했다. 전체 실행에서 이전 Mapper 버전을 기대하던 검사 한 그룹을 현재0.3.20으로 정정해 재실행했으며 배포 코드는 변경하지 않았다. 전체7,634개 검사와 독립 소스 ZIP 재빌드의 JAR 바이트 일치를 확인했고, 설치 파일과 실제 캡처를 업로드해 다운로드 링크를 확인한다고 안내했다.
