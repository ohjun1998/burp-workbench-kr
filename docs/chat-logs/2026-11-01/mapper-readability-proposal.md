# 기능 자동 매핑 목록 가독성 · URL 대신 기능명 표시 시안

- 날짜: 2026-11-01 (Asia/Seoul)
- 작업: mapper-readability-proposal

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

이거 URL은 굳이 안 보여줘도 되는데 다른 방법으로 가독성 있게 표시할 수 있도록 제시해줄래?

## 02. 도우미 · 원문

지금 목록은 기능명에 경로가 반복해서 붙어 한눈에 훑기 어렵네요. URL 대신 기능명과 유형을 표시하고, 자동 생성된 탐색 항목은 묶어서 보여주는 안을 만들어 보겠습니다.

## 03. 도우미 · 원문

추천은 **업무별 그룹 + 짧은 기능명 + 요청 건수** 방식입니다. 예를 들어 `Check account balance`는 `잔액 조회 · 13건`으로 표시하고, 긴 임의 경로와 입력 변형은 접어서 보여주면 좋겠습니다. 그룹형·한 줄형·카드형을 비교할 수 있는 HTML 시안을 만들고 있습니다.

## 04. 도우미 · 원문

세 가지 시안을 만들었습니다. 추천하는 그룹형은 핵심 업무와 계정 기능을 먼저 보여주고, 문서 탐색·입력 변형·대조 경로는 접어 둘 수 있습니다. 원본 URL은 선택 상세에서 펼쳐 볼 수 있게 했으며, 43개 관측 그룹과 135건의 데이터는 그대로 유지했습니다.

## 05. 도우미 · 요약

기존 완성 HTML·JAR은 보존하고 별도 비교 시안을 만들었다. 세 표시 방식, 한글 표시명 검색, 실제 관측 수·ID 보존, URL 선택 펼치기, 테마와 반응형 표시를 현재 브라우저로 확인했다. JavaScript 오류 및 추가 HTTP 요청은 0건이다. 표시명과 상위 그룹은 제안이며 기능 또는 취약점의 확정을 의미하지 않는다.
