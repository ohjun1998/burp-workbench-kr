# 13개 도구 A 그룹형 출력 HTML · 저장 결과와 실제 확장 캡처

- 날짜: 2026-11-02 (Asia/Seoul)
- 작업: grouped-output-html

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

확장자 별로 출력되는 형태를 .html로 보여줘

## 02. 도우미 · 원문

각 도구의 실제 결과가 A 그룹형으로 보이는 HTML을 만들겠습니다. 기존 은행 테스트 결과를 넣고, 도구별 메뉴·그룹 접기·원본 정보 보기를 직접 살펴볼 수 있게 구성하겠습니다.

## 03. 도우미 · 원문

13개 도구를 메뉴로 전환하는 단일 HTML로 구성하고 있습니다. 기존 은행 테스트 결과를 탐색하는 화면과 1.4.22 실제 확장 캡처를 함께 넣고, 각 화면의 데이터 출처도 표시하겠습니다.

## 04. 도우미 · 원문

14개 HTML 검사가 모두 통과했습니다. 결과 데이터와 실제 확장 캡처가 한 파일에 들어 있으며, 저장용 ZIP도 함께 준비했습니다. 다운로드 링크를 확인하고 있습니다.

## 05. 도우미 · 요약

공식 1.4.22 JAR의 표시명과 기능 그룹을 읽기 전용으로 가져와 13개 도구를 전환하는 단일 HTML을 생성했다. 은행 1.4.21의 원본 JSON 1,321,014바이트와 트래픽 89건, Mapper 관측 135건, Scope 525행을 그대로 보존했다. 결과 탐색과 실제 1.4.22 Swing 합성 검증 캡처 26개를 별도 모드로 표시한다. 그룹·행·원본·검색·테마·실제 결과값·캡처·JSON 저장·모바일 선택을 검증해 14개 검사와 80개 배치 측정이 통과했고, JavaScript 오류와 추가 HTTP 요청은 0건이다. ZIP CRC와 내부 HTML 동일성, 내장된 26개 PNG의 원본 동일성도 확인했다. Simple 소스와 설치 패키지는 변경하지 않았다.
