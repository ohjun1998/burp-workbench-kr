# Next 0.55.0 범위 제한 자동 점검

사용자 원문:
> 범위 제한 자동: 지정한 SCOPE·테스트 계정·요청 예산 안에서 재현 검사까지 자동, 다만 시스템의 가용성을 해칠만한 검사는 사용자 한테 확인 필수

사용자에게 전달한 설명 요약:
- SCOPE·테스트 계정·요청 예산 안에서 자동 재현하고 가용성 우려 검사는 사용자 확인 전까지 실행하지 않는다고 설명했습니다.
- 기존 수집·계정 기능과 연결하며 이번 자동 실행 유형은 조회 요청의 계정 간 접근 비교라고 안내했습니다.
- 상태 변경·고비용 요청은 자동 전송하지 않고 개별 검사안 검토 대상으로 남깁니다. 가용성 우려 GET 비교의 승인은 한 항목 한 번만 적용합니다.
- 자동 결과는 후보/관측으로 표시하고 원본과 재현 요청·응답을 보관합니다. 응답 일치만으로 취약점을 확정하지 않습니다.

구현·검증 진행 요약:
별도 로컬 개발 사본 ~/workbench-next-auto 및 0.55.0 버전으로 작업합니다. 0.54.0과 기존 배포 파일은 보존합니다. 엔진 집중 검증과 운영 패널의 합성 Montoya 검증, 전체 회귀/HTTP CI를 실행합니다. 최초 컴파일의 record origin 이름 충돌은 수정했습니다. 실제 사용자 Burp와 0.55.0 실모델 계획 출력은 아직 검증하지 않았습니다. 원시 도구 출력이나 인증값은 이 기록에 포함하지 않습니다.

후속 검증 요약: 엔진 37개와 운영 패널 합성 호스트 12개 초기 검사가 통과했습니다. 승인 만료·모델 예산·잘못된 계획 검사를 추가했고 구조화 계획의 실제 loopback HTTP 경로도 전체 CI에 포함했습니다. 관측 응답부터 429/5xx이면 재전송 전에 중지하도록 보강했습니다.

화면 검증 요약: 850×700 운영 패널을 합성 데이터로 렌더링해 입력·시작/중지·개별 승인·결과/근거가 보이는지 확인했습니다. 대기 상태가 모델 분석 중으로 남던 표시를 바로잡았습니다. 현재 집중 검사: 엔진 41개, 합성 Montoya 패널 12개, 증거 가림 7개 통과입니다.

사용자 원문: "실행했어"

전달한 설명 요약: 사용자 터미널의 실제 Halogen 검사안 요청이 2.9초에 성공했습니다. JSON action은 REVIEW였고 대상 요청은 0건입니다. 모델이 공개 정보라고 해석한 근거는 부족하므로 이를 검증된 사실로 취급하지 않는다고 알렸습니다. 이 실모델 검사는 c94ab745200a1d64afc1f8e15bcf2a181e842702f3fac6caf15160589a2259d7 JAR를 대상으로 했으며, 이후 보강은 전송 서버/Host 일치와 인증 쿼리 제외 및 그 회귀 검사입니다. 모델 클라이언트는 동일합니다.

배포 검증 결과 요약: 최종 소스 be80cb754e61c9903a819fab38f6d5e41c9e0d32가 전체 4,886개 검사 및 Mapper Java134/Node15와 패키징 검증을 통과했습니다. CI 생성 0.55.0 JAR·소스 ZIP을 로컬에 가져와 SHA-256/ZIP CRC/393개 소스 지문을 확인했습니다. 임시 분할 전송본을 정리합니다. 확대 검사의 인증 단계 실패는 배포 파일 생성 전 커밋에 manifest가 없어 발생했으며, 배포 파일 포함 상태에서 재실행합니다. 실모델 진단 도구와 합성 패널 이미지, 검증 기록을 함께 업로드합니다.

최종 전달 설명 요약: 확대 CI의 인증 조합, 50개 업무 권한 비교, 전체/집중 화면 배치, 패키징 검증과 Windows/Linux 내구성 검사가 모두 통과했다고 알렸습니다. 검증 기록을 PR #108에 반영하고 검토 가능 상태로 전환합니다. 자동 점검은 초기 OFF이며 사용자가 범위·테스트 계정·예산을 설정하고 시작해야 합니다. 자동 실행 유형은 GET 계정 비교이며 가용성 우려 계획은 개별 승인 전 대상 요청을 보내지 않습니다. 실제 사용자 Burp GUI와 실제 대상 자동 검사는 아직 미수행입니다.
