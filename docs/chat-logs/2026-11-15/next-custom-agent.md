답변 요약: 공개 저장소의 스타와 공식 문서를 비교하고 Custom AI Agent를 추천했다. Next에 내부 화면으로 연결하며 원본 Agent 1.1.0을 고정하고 Halogen 기본값을 제공한다고 설명했다. 새로운 능동 검사 연결부는 개별 요청 승인을 요구하며 CLI·외부 MCP 등 전송 제한 밖 경로는 이번 통합에서 제외한다고 설명했다. 기존 Next 0.55.0의 제한 자동 비교는 보존한다. 최초 로컬 전송 경계 검사 37개 통과를 안내했다. 실제 원본 JAR 부팅·회귀·산출물 검증은 후속 CI에서 수행한다.

작업 기준: main 222aef191a34f7d6cd1014e941ecc7152341f640에 이어 기존 미병합 Next 0.55.0 PR #108의 0516bfc8eaebae28a158472bfd2b060252692542를 승계하는 별도 작업 브랜치다. Simple·Strix·기존 Burp 프로필은 변경하지 않는다.

이 파일에는 사용자에게 보이는 대화만 요약하며 인증값·숨겨진 추론·원시 도구 출력을 포함하지 않는다. CI가 추가하는 검증 JAR·소스·합성 화면도 이 작업의 산출물이다. main 병합 또는 native Burp 검증을 의미하지 않는다.
