# Next 0.54.0 로컬 LLM 연동 작업

한국 시간 2026-11-15. 이 작업과 관련해 제공된 사용자 메시지와 사용자에게 전달한 설명만 기록합니다. 아래 원문/요약 구분을 따르며 자격증명·비공개 추론·원시 도구 출력은 포함하지 않습니다.

## 사용자 원문

> workbench Next 확장자에 로컬 LLM을 연동시켜서 효율적으로 버그바운티 할 수 있게 고도화 해줄래?

> 0.53.4 버전 이후로 업데이트 해줘

> github에 위치한 것, 여기 로컬로 복사하고 실행 및 테스트 할 수 있도록 설정하고, 완성된 파일은 github에 업로드 해줘

## 전달한 설명 요약

- main에서 확인한 Next 0.53.4를 출발점으로 선택한 요청·응답의 가설·재현 절차와 기존 SCOPE·Repeater·증거 정리를 연결하기로 했다.
- 사용자 확인에 따라 신규 기능 버전은 0.54.0으로 올리고 기존 배포본은 보존한다고 설명했다.
- 기본 모델 서버는 Halogen `/v1` 로컬 8731, 모델 ID는 `halogen-qwen3.8-flash-next`로 준비했다.
- 미리보기 확인·편집 후 수동 분석, 동시 분석 1개, 미검증 가설 표시, 자동 대상 요청 없음과 가용성 조건을 설명했다.
- `~/workbench-next-local-llm`에 소스를 준비했다. 직접 Git 네트워크 접속은 차단되어 GitHub 연결 도구로 소스를 가져왔다. Burp 동봉 JDK 26을 발견해 로컬 컴파일에 사용했다.
- 관리 환경은 socket 생성/loopback bind도 차단한다. 따라서 로컬에서는 Java 컴파일 및 네트워크 없는 검사 34개만 실행했으며, 전체 빌드·HTTP 검사는 CI로 추가 검증하기로 했다. 실제 Halogen·native Burp 검증을 했다고 주장하지 않았다.

## 현재 제출 범위

새 로컬 LLM 클라이언트·Swing 화면, 두 메뉴 진입점, 프로젝트/종료 수명 처리, 기존 증거 가림·원본 연결, 회귀 검사, 로컬 실행 스크립트, 사용 안내, 작업 브랜치에만 검증 산출물을 추가하는 CI. 전체 검증 결과와 잔여 제한은 PR 및 이후 작업 기록에 추가한다. main 자동 병합은 포함하지 않는다.
