## 공개 답변과 진행 요약
Simple에서 기존 Strix를 실행하고 중지·로그·보고서를 연결하는 범위를 설명한 뒤 사용자의 명시 확인을 받았다. 기존 Strix 설치·모니터를 변경하지 않고 Simple 쪽의 실행 연동부를 추가한다. 제공자 선택은 공식 Strix 구독 인증 지원을 확인한 뒤 구현하며 일반 API 키를 구독 인증으로 표시하지 않는다. 기반은 main 1f3534e55d4dd99536b8e5e9a80b4e88e3863ab9, Simple 1.4.12이며 새 후보는 1.4.13이다. 실제 사용자 Burp·모델 진단과 합성 API/가짜 CLI 검증을 구분한다.

공개 저장소의 Simple 빌드 입력을 로컬 검증용으로 임시 전송했다. 비공개 설정과 진단 자료는 포함하지 않았다.

## 구현·로컬 검증 요약
- Strix 자체 ChatGPT 구독 인증과 Halogen/Qwen3.8 선택, 실행별 설정과 고정 제공자, 실행 전 기본 취소 확인, 중지·로그·소유 보고서 미리보기를 Simple1.4.13에 추가했다. 기존 Strix 설치·설정과 Next는 변경하지 않았다.
- 사용자가 추가로 “적용 다 끝나고, 사용 단계별로 이미지 캡쳐해서 가이드 해줘(.html로)”라고 요청해 HTML 가이드와 실제 운영 UI 합성 캡처를 준비했다.
- 작은 창에서 본문 높이가 부족한 실패를 보존하고 실제 패널 배치를 수정했다. 검사 기준은 완화하지 않았다.
- 집중 회귀 6그룹271개와 지정JAR의 합성UI28화면/배치위반0을 통과했다. 실제 Strix·모델·대상은 실행하지 않은 검증이다. 전체 검사·패키징은 CI에서 이어간다.

最終default-run-root 검토에서 stable Workbench와 분리해 ~/.burp-workbench-simple/strix-runs에 저장하도록 수정하고, 기본 경로를 사용하는 fake 실행 회귀를 추가했다. 해당 코어63개가 통과했으며 실제 Strix는 실행하지 않았다. 배포 파일 생성 전에 전체 후보 검증을 다시 시작한다.
