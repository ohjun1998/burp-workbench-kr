## 공개 답변과 진행 요약
Simple에서 기존 Strix를 실행하고 중지·로그·보고서를 연결하는 범위를 설명한 뒤 사용자의 명시 확인을 받았다. 기존 Strix 설치·모니터를 변경하지 않고 Simple 쪽의 실행 연동부를 추가한다. 제공자 선택은 Strix 자체 구독 인증 지원을 확인한 뒤 구현하며 일반 API 키를 구독 인증으로 표시하지 않는다. 기반은 main 1f3534e55d4dd99536b8e5e9a80b4e88e3863ab9, Simple 1.4.12이며 새 후보는 1.4.13이다. 실제 사용자 Burp·모델 진단과 합성 API/가짜 CLI 검증을 구분한다.

공개 저장소의 Simple 빌드 입력을 로컬 검증용으로 임시 전송했다. 비공개 설정과 진단 자료는 포함하지 않았다.

## 구현·로컬 검증 요약
- Strix 자체 ChatGPT 구독 인증과 Halogen/Qwen3.8 선택, 실행별 설정과 고정 제공자, 실행 전 기본 취소 확인, 중지·로그·소유 보고서 미리보기를 Simple1.4.13에 추가했다. 기존 Strix 설치·설정과 Next는 변경하지 않았다.
- 사용자가 추가로 “적용 다 끝나고, 사용 단계별로 이미지 캡쳐해서 가이드 해줘(.html로)”라고 요청해 HTML 가이드와 실제 운영 UI 합성 캡처를 준비했다.
- 작은 창에서 본문 높이가 부족한 실패를 보존하고 실제 패널 배치를 수정했다. 검사 기준은 완화하지 않았다.
- 집중 회귀 6그룹271개와 지정JAR의 합성UI28화면/배치위반0을 통과했다. 실제 Strix·모델·대상은 실행하지 않은 검증이다. 전체 검사·패키징은 CI에서 이어간다.

기본 실행 폴더를 최종 검토하면서 기존 Workbench와 분리해 ~/.burp-workbench-simple/strix-runs에 저장하도록 수정하고, 기본 경로를 사용하는 fake 실행 회귀를 추가했다. 해당 코어63개가 통과했으며 실제 Strix는 실행하지 않았다. 배포 파일 생성 전에 전체 후보 검증을 다시 시작한다.

CI에서 전체 Simple 검사와 UI·Katana를 통과한 경우에만 1.4.13 배포 파일을 생성한다. Strix 실제 진단·모델 추론은 수행하지 않는다.

## 최종 배포·가이드 검증 요약
- 소스 609c252a9543f0e5ef8db800f28e09f147efe62d가 Actions 43874202784 전체 검증을 통과했다. 전체 Simple 7,162개, 별도 Katana 102개, 기존 Simple/Scope 84/68화면, Strix 28화면 배치 위반 0이다.
- CI가 작업 브랜치에 1.4.13 JAR·소스 ZIP·체크섬·manifest를 게시했다. 공개 JAR 9,038,952바이트를 받아 SHA-256 a61e81a4f4131f4226a8057d3b7974678c4941856370fdf1b79dbe470d374fd2를 확인하고 같은 JAR로 새 회귀 89개와 UI 28화면을 다시 통과했다.
- 읽기 전용 실제 환경 검사에서 Halogen 로컬 설정은 정상이며 Strix 자체 ChatGPT 구독 인증은 검사 시점 미로그인이었다. 실제 모델 추론·대상 진단·Docker 호출은 하지 않았다.

- 단일 HTML과 설치 JAR·가이드 묶음, 이미지 ZIP, 체크섬을 생성·검증하고 사용자 문서 폴더에 HTML을 복사했다. 기존 Strix 래퍼/모니터/전역 설정은 수정하지 않았다. 최대 에이전트 턴은 HTTP 요청 예산이 아니며 실제 Burp 로드·로그인·추론은 별도 확인 항목으로 남긴다.
