# Workbench Strix1.0.1 · Simple1.4.21 디자인 기준 업데이트

- 날짜: 2026-11-17 (Asia/Seoul)
- 작업: strix-simple-1421

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

기존에 simple 1.4.21 버전에 Strix 진단 에이전트 기능만 넣어서 strix 버전에 다시 업데이트 해줄래?
기존 버전의 디자인 및 레이아웃 등을 꼭 유지해서 디자인 해주고 실제 화면 캡쳐해줘

## 02. 도우미 · 원문

Simple 1.4.21을 기준으로 Strix 진단 기능을 추가하겠습니다. 1.4.21의 디자인과 레이아웃을 유지하고, 새 Workbench Strix 버전으로 빌드한 뒤 실행 창을 캡처하겠습니다.

## 03. 도우미 · 원문

새 버전은 **Workbench Strix 1.0.1**로 구분하겠습니다. 화면 기준은 Simple 1.4.21의 배포 소스로 고정하고, Strix 진단은 별도 창으로 연결해 기존 메인 화면의 배치와 버튼 구성을 보존하겠습니다.

## 04. 도우미 · 요약

Strix연결부와 기존1.4.21 강조 메뉴·설정·작업 흐름 집중377개를 통과했다. 기존 런타임·디자인·리소스280파일이 Simple1.4.21과 바이트단위 동일하고 변경은 이름/Strix연결부7파일 및 신규Strix2파일임을 확인했다. StrixUI28개를 통과했고 전체검사를 진행했다.

## 05. 도우미 · 원문

실제 Linux 창에서 두 버전을 비교했습니다. 라이트·다크 테마와 두 창 크기의 메인·대시보드 배치 비교 464항목에서 위치·크기 차이가 없었고, 통합 점검·대시보드 강조 메뉴도 모두 기존 42px 높이를 유지했습니다.

## 06. 도우미 · 요약

실제 우클릭에서 선택 원본으로 Strix창 진입을 확인했고, 원본1.4.21과 새판의 메인/대시보드464배치 비교가 모두 일치했다. 기존 검색 준비시험에서 1회 실패해 gate설치만 같은EDT의 텍스트변경 이후/begin직전으로 보정했다. 제품검색소스와18개assertion은 유지했다. 원본/새JAR각18개 집중검사를 통과했고 최종전체검사를 다시 실행했다.

## 07. 도우미 · 원문

전체 자동 검사 **8,191개**를 모두 통과했습니다. Simple 1.4.21 기반 화면, Strix 기능 연결, 배포 파일·소스 빌드와 가이드 검증까지 끝났습니다. 새 설치 파일과 실제 창 캡처를 업로드하겠습니다.
