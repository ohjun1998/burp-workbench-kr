# Workbench에서 Strix 연동 제거

- 날짜: 2026-11-18 (Asia/Seoul)
- 작업: simple-remove-strix

이 작업에서 확인 가능한 사용자 요청과 사용자에게 표시한 응답을 기록합니다. 과거 대화 전체나 내부 추론·도구의 원본 출력은 포함하지 않습니다. 요약한 항목은 별도로 표시합니다.

## 01. 사용자 · 원문

burp suite에 확장자로 Strix를 연동하지말고, Strix 그 자체를 연동해서 Strix가 burp suite 내 정보들을 참고해서 답변할 수 있도록 할 수 있나?

## 02. 도우미 · 요약

독립 Strix가 참고할 선택 기록과 Burp 실시간 기록 조회의 차이를 설명했습니다. 답변 전용 운용에서 대상 요청 권한을 조회 권한과 분리해야 한다고 안내했습니다.

## 03. 사용자 · 원문

Burp 기록을 실시간 조회

상기 방식으로 진행해주고, 기존 workbench 내 strix 기능은 제거해줘

## 04. 도우미 · 원문

Workbench에서 Strix 실행과 채팅 기능을 제거하겠습니다. 독립 Strix 연동은 Burp 기록을 읽는 경로와 대상에 요청을 보내는 경로를 분리할 수 있는지 확인하면서 진행하겠습니다.

## 05. 도우미 · 원문

Burp 기록을 읽는 인터페이스는 확인했습니다. 다만 현재 Strix에서는 가져온 기록으로 답변하면서 자체 대상 요청 도구를 차단하는 모드를 확인하지 못했습니다. 실시간 연결은 적용하지 않고, Workbench에서 Strix 메뉴·채팅·실행 코드를 제거한 새 JAR를 검증하겠습니다.

## 06. 도우미 · 원문

새 JAR에서 Strix 클래스와 실행 도우미가 빠진 것을 확인했습니다. 이제 설정과 우클릭 메뉴에서 Strix 항목이 사라졌는지, 기존 화면 이동과 저장 동작이 정상인지 회귀 검사로 확인하고 있습니다.

## 07. 도우미 · 원문

이전 설치 파일과 비교했더니 JAR에서 빠진 28개 항목이 모두 Strix 관련 파일이었습니다. 새 버전도 기존 Simple 프로젝트 저장 경로와 설정 키를 사용합니다. 전체 회귀 검사는 아직 진행 중입니다.

## 08. 사용자 · 원문

추가로 workbench strix 확장자에서 strix 버튼 실행하면 독립된 Strix 채팅 화면이 뜨게해줘

## 09. 도우미 · 원문

추가 요청은 일반 Simple에서 Strix를 제거하고, 별도 Workbench Strix 판의 버튼으로 독립 Strix 채팅 화면을 여는 것으로 이해했습니다. Simple 배포 검사를 계속하면서 Strix에 바로 열 수 있는 채팅 화면이 있는지 확인하겠습니다.

## 10. 도우미 · 요약

검토한 Strix의 채팅은 실행 중인 진단 세션에 연결됩니다. 이미 사용자가 열어 둔 독립 Strix 웹 화면으로 이동하는 바로가기 방식이 괜찮은지 물었습니다.

## 11. 도우미 · 원문

설정과 요청·응답 우클릭 메뉴에서 Strix 항목이 제거된 것을 회귀 검사로 확인했습니다. 독립 Strix의 메시지 입력 화면은 진단 세션 안에서 열리는 구조여서, 버튼으로 새 답변 전용 채팅을 바로 띄우는 경로는 확인되지 않았습니다.

## 12. 도우미 · 요약

Workbench Simple 1.4.23 설치 JAR와 소스 ZIP을 만들고 자동 검사 8,105개, 패키지 검증, 체크섬 비교를 통과했습니다.
