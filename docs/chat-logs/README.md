# 날짜별 작업 대화 기록

GitHub에 소스·문서·배포 파일 등을 새로 올리거나 갱신할 때 관련 대화를 같은 변경에 기록합니다. 한국 시간의 `YYYY-MM-DD/작업명.md` 구조를 사용하고, 한 대화의 후속 작업은 같은 파일에 이어서 정리합니다.

사용자 요청과 사용자에게 표시한 응답을 포함합니다. 확인 가능한 원문과 요약을 구분하며, 확인하지 못한 과거 메시지를 복원했다고 표현하지 않습니다. 인증정보·토큰·민감한 개인정보는 가리고, 내부 추론이나 도구의 원본 출력을 붙이지 않습니다.

```sh
python tools/record_chat.py --date 2026-10-15 --topic workbench-remaining --input /path/to/task-chat.json
```

입력은 `title`과 `messages`를 가진 JSON 객체입니다. 메시지마다 `role`은 `user` 또는 `assistant`, `content`는 표시한 내용, `kind`는 `verbatim` 또는 `summary`로 지정합니다. 같은 입력을 다시 실행해도 중복 메시지를 추가하지 않습니다. 이 명령은 해당 작업의 기록 도구이며 계정의 다른 채팅을 자동으로 내보내는 기능은 아닙니다.
