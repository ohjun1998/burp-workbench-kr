# Workbench · 새로운 화면 디자인 제안

[18페이지 PDF 다운로드](workbench-alternative-design-proposal.pdf) · [표지 미리보기](cover.png)

현재 기능 구성을 바탕으로 밝은 회색·흰 작업 면·네이비 본문·청록색 강조를 적용한 시안입니다. 제품 소스코드는 변경하지 않았습니다.

PDF는 표지, 공통 디자인 기준, 도구별16개 시안으로 구성한 총18페이지입니다. 한 페이지에 한 화면을 배치하고 각 화면의 배치 개선점 두 가지를 적었습니다. 모든 페이지에 디자인 제안임을 표시하고 한글 제목·책갈피를 제공합니다.

이미지는 image_gen으로 생성한 디자인 검토용 시안입니다. 실제 실행 화면·기능 검증 결과가 아니며, 화면 속 데이터·CVE·날짜·판정과 일부 문구는 설명용 예시입니다. 표시된 기능과 표현은 승인된 구현 변경을 뜻하지 않습니다. 제품의 기존 실행/조회/원본·증거 계약은 구현 시 별도 유지해야 합니다.

방향: 큰 본문 제목 없이 압축한 상단, 얇은 구분선, 작은 상태 배지, 한 개의 주요 실행 강조, 선택 데이터 옆 보조 작업, 넓은 표·패킷·편집 영역. 36px상단·30px기본행 등 수치는 설계 목표이며 생성 이미지의 픽셀 측정값이 아닙니다.

PDF검증:18페이지·18책갈피·한글 제목과설명 추출·이미지 경계와원본비율·삽입이미지 전체RGB픽셀 일치. 상세는 verification.json을 참고하세요.
