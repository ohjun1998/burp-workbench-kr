# Workbench 버튼 배치 개선안 · 2026-10-31

Simple 1.4.11의 현재 화면과 실제 버튼을 검토한 디자인 제안입니다. 코드·JAR·main은 변경하지 않습니다. 이미지의 치수와 시각 효과는 시안이며, 공간 절약 수치를 실측한 것은 아닙니다.

## 공통 배치

- 공통 상단: 메뉴·경로 왼쪽, 창·설정·로그·Guide 오른쪽. 큰 도구 제목은 추가하지 않습니다.
- 문맥 줄: 대상·계정·수집 상태. 작업 줄: 검색·필터 왼쪽, 현재 단계의 주 실행 오른쪽.
- 선택한 데이터에 쓰는 Repeater·증거·복사는 해당 목록 또는 상세 제목줄에 배치합니다.
- 실행 버튼 옆에 중지/취소를 두고 실행 중에도 고정 표시합니다. 선택 없이 실행할 수 없는 버튼은 같은 위치에서 비활성화합니다.
- 주황색은 현재 영역의 핵심 동작에만 사용합니다. 보조 작업은 윤곽 버튼, 전체 비우기·초기화는 더보기의 별도 구역에 배치합니다.
- 제안 치수: 버튼 높이 32px, 그룹 내부 간격 6–8px, 그룹 간격 16px. 작은 창에서는 검색 입력 너비부터 줄이고 작업 버튼 문구와 중지 버튼을 보존합니다.
- 화면 이동·선택만으로 요청을 보내지 않습니다. 준비와 실행의 구분을 유지합니다.

## 도구별 배치

| 화면 | 상단/실행 | 해당 영역 작업 |
|---|---|---|
| 요청·응답 목록 | 대상·계정·수집, 하나의 설정 진입점. 검색 줄 오른쪽 계정 비교 준비 | 같은 목록 줄에 Repeater·증거 추가. 수집 설정과 검색·목록 설정은 한 메뉴에서 별도 항목 유지 |
| 기능 자동 매핑 | 프로젝트 열기·저장 / 수집·매핑 설정 | 표 제목줄에 분류 수정·Repeater, 선택 기능 옆 편집·점검 업무 연결 |
| JS에서 API 찾기 | 분석 ON·대상·소스·검색 | 선택 API 상세 옆 원본 위치·Repeater 준비 |
| 서버·경로 탐색 | 대상·계정. 검색 옆 선택 경로 GET 확인 및 일괄 실행 드롭다운 | 일시정지·중지는 인접 표시. 후보 설정은 후보 목록 옆 |
| 검색 노출 조사 | 검색식 옆 복사·Google에서 열기 | URL 목록 옆 가져오기, 선택 URL 상세 옆 Repeater 준비·근거 복사 |
| CVE 후보 | 관측 제품·조회·취소 한 줄, 표 바로 위 필터 | 선택 CVE 상세 옆 출처 열기·근거 복사. 최신성/미확인 상태 유지 |
| 계정 권한 비교 | 인증 탐지·도메인, 계정 요약 옆 인증 후보·계정 설정 | 표 위 선택 요청 비교·중지. 비교 계정 선택은 응답 비교 영역 옆 |
| 응답 보안 분석 | 탭·검색. 없는 전역 검사 시작 버튼은 추가하지 않음 | 선택 관찰 상세 옆 증거. API 탭의 Repeater 초안은 해당 탭에만 표시 |
| 입력값 보안 검사 | 단계 표시 옆 검사 설정·검사 시작·중지 | 요청 헤더에 삽입 위치·정렬. 결과 단계에만 결과를 증거로·Repeater 열기 |
| 데이터 변환·비교 | 입력 헤더에 변환 방식·변환. 비교 탭은 비교·중지 | 출력 헤더에 출력→입력·복사. 비교 결과 옆 이전·다음·증거 |
| 점검 진행 현황 | 추적·Scope·기록 | URL 표 옆 URL 완료, 입력 표 옆 입력 완료. 선택 상세 옆 발견 근거·Repeater 초안 |
| 재현·증거 정리 | 문서 제목 옆 가림 미리보기·증거 ZIP 저장 | 증거 목록 옆 증거 추가. 이동·삭제·실행 취소·메모는 목록 안쪽 |
| 점검 대시보드 | 현재 실행·계정·조건 해제, 오른쪽 통합 점검 열기 | 선택 결과 상세 옆 원본·Repeater 준비·증거 추가. 열기는 실행 시작이 아님 |

## 이미지 구성

1. 요청·응답 목록 전체 화면: 공통 버튼 체계와 데이터 읽기 영역.
2. 실행형 화면 4종: 계정 권한 비교·입력값 검사·서버/경로 탐색·CVE 조회.
3. 분석 도구 4종: 기능 매핑·JS API·응답 보안 분석·데이터 변환.
4. 관리·조사 4종: 점검 현황·증거 정리·대시보드·검색 노출.

합성 예시를 사용하는 디자인 시안입니다. 실제 제품 화면이나 사용자 수용성 검증 결과가 아닙니다.
