# Simple 1.4.12 · 승인한 버튼 배치 적용

13개 화면에 실행·중지 고정, 선택한 데이터 옆 작업, 입력/출력별 도구, 단계별 결과 작업을 적용했습니다. 설정·검색·문서 저장은 전역 위치를 유지하고, 상세/목록 작업을 각 영역으로 옮겼습니다. 버튼 이름·핸들러·원문·선택 ID·작성 중인 입력과 명시적 전송 흐름은 유지합니다. [화면별 비교](README.md)와 [대화형 갤러리](index.html)에서 확인할 수 있습니다.

실제 창 검증에서 발견한 기존 테마 재적용 반복도 수정했습니다. 외부 Workbench 감시가 내장 Mapper의 감시와 충돌하지 않게 경계를 두고, Mapper가 같은 버튼 UI를 반복 교체하지 않게 했습니다. 호스트의 실제 UI 교체 복원은 별도 회귀 검사로 유지합니다. [측정](paint-comparison.json)은 격리 Linux에서 각 경로의 단일 3초 구간을 관측한 EDT 스레드 CPU/그리기 통계입니다. 전체 프로세스·Windows·일반 성능 향상률로 확대 해석하지 않습니다. 수정본과 최종 JAR의 동일 클래스는 [별도 기록](class-equivalence.json)으로 확인합니다.

좁은 CVE 화면에서는 필터 전체 너비를 먼저 확보하고 최신성 메타데이터를 아래로 보냅니다. 실제1024×720 창에서 두 테마·최초 표시/크기 복귀를 검증했습니다. 캡처 도구도 분리된 헤드리스 트리의 BoxLayout 캐시를 무효화하도록 고쳤습니다. [실제 창 증거](cve-native-narrow.json)의 부모 영역 교집합과 getVisibleRect 검사로 가려짐을 교차 확인했습니다.

전체 **7,073개**(Java 157개 그룹 6,761 · payload HTTP 136 · Mapper 147 · Node 29)를 통과했습니다. 최종 JAR의 Swing **194개 화면**, 실제 창 **112개**, Katana **102개**도 통과했습니다. 두 테마 가이드16화면·96번호를 갱신하고192개 위치를 확인했습니다. 비교·실제 화면·가이드를 포함한 공개 PNG는93장입니다. [전체 검증](VERIFICATION.json)
