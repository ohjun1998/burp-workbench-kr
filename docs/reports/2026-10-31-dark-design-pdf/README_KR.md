# Workbench · 다크모드 디자인 제안

[18페이지 PDF 다운로드](workbench-dark-design-proposal.pdf) · [표지 미리보기](cover.png)

직전 밝은 테마 시안의 정보 구조를 유지하면서 짙은 네이비 바탕, 한 단계 밝은 작업 면, 밝은 본문 글자와 절제된 청록색 포인트로 다시 구성하는 디자인 제안입니다. 제품 소스코드는 변경하지 않았습니다.

PDF는 표지, 다크모드 공통 디자인 기준, 도구별 16개 시안으로 구성한 총 18페이지입니다. 한 페이지에 한 화면과 두 줄의 설명을 배치하고 한글 제목·책갈피를 제공합니다. 문서 자체도 다크 색상으로 구성합니다.

주요 방향은 표와 편집기의 밝기 차이, 패킷·코드·줄 번호의 구분, 작은 상태 배지, 차분한 선택 면과 주요 실행 강조입니다. 큰 본문 제목 없이 상단을 압축하고, 선택 데이터의 복사·증거·Repeater 작업은 해당 영역 가까이에 둡니다. 약 36px 상단·30px 기본 행 높이는 구현 단계의 목표이며 생성 시안의 픽셀 측정값이 아닙니다.

문서 색상 기준: 바탕 `#0B1220`, 작업 면 `#151F2E`, 본문 `#E7EEF7`, 보조 글자 `#A9B8CC`, 구분선 `#273447`, 강조 `#2DD4BF`.

이미지는 image_gen으로 생성한 디자인 검토용 시안입니다. 실제 실행 화면·기능 검증 결과가 아니며, 데이터·CVE·날짜·판정과 일부 문구는 설명용 예시입니다. 표시된 표현은 구현 변경을 뜻하지 않습니다. 제품의 실행·조회·원본·증거 계약은 실제 구현에서 별도로 유지해야 합니다.
