# Simple 1.4.11 · 번호 가이드와 화면 정리

각 도구 화면의 오른쪽 위 `Guide` 또는 F1로 별도 가이드 창을 엽니다. 현재 도구를 선택한 상태로 열리며, 화면 위 빨간 1–6 번호와 오른쪽 사용 설명을 서로 클릭해 확인합니다. 총16개 화면·96개 단계, 화면 맞춤/100% 확대, 창 최대화/F11과 Esc 숨김을 제공합니다. 가이드 이미지는 합성 예시이며 사용자의 실제 패킷이나 인증값을 캡처하지 않습니다.

사용자의 마지막 선택인 ‘사용 빈도가 낮은 기능 자체도 삭제’에 따라 중복과 보조 기능을 실제로 제거했습니다. 사용 빈도 통계는 없으므로, 고유한 점검 기능을 임의로 삭제하지 않고 다음5종부터 정리했습니다.

1. 구형 텍스트 도움말 창과 중복 진입점을 새 Guide/F1로 통합했습니다.
2. 기능 자동 매핑의 하단 중복 분류 수정 버튼을 제거했습니다. 상단 분류 수정은 유지합니다.
3. 입력값 보안 검사의 중복 요청 준비 버튼을 제거했습니다. 단계1 요청 준비로 돌아갈 수 있습니다.
4. 증거 작성의 빠른 Markdown 서식 버튼과 전용 글자 수 줄을 제거했습니다. 직접 작성·수정·저장·내보내기는 유지합니다.
5. 점검 진행 현황에서 반복되는 카드 제목 줄을 제거했습니다.

정리 검토13개 화면은 적용 전 화면에 빨간 박스로 표시했습니다. **실선은 이번 삭제 반영, 점선은 추가 검토 후보**입니다. 빨간 숫자로 표시한 사용 단계와 구분합니다. 점선 기능까지 모두 삭제한 것은 아닙니다. 실제 삭제 후 화면도 두 테마로 제공합니다.

## 검증 범위

전체 검사6964개를 통과한 뒤 실제 가이드 창에서 발견한 창 제목 동기화와 어두운 설명 글자색을 수정했습니다. 최종 수정은 집중 검사1057개로 재확인했습니다. 전체 검사와 후속 집중 검사 시점은 [별도 기록](VALIDATION_SCOPE_KR.md)에 구분합니다.

최종 JAR 기준으로 두 테마 실제 Linux 가이드 창50개 검사, Swing194개 화면, Katana102개 검사를 통과했습니다. 가이드 창에서는 대상 HTTP 요청이0개이며, 원본·선택·입력과 창 닫기·재열기·로드 해제를 확인했습니다. [검증 자료](VERIFICATION.json)에 최종 JAR 해시가 연결되어 있습니다.

실제 창 검증은 격리한 Linux Xorg/xfwm4와 합성 Burp API/패킷을 사용했습니다. Windows Burp 본체·DPI/IME는 직접 검증하지 않았습니다. 원본 Next와 이전 배포 파일은 변경하지 않았습니다. Simple 패키지 입력을 동결한 뒤 불변 패키지·소스 fingerprint·CRC 검증을 통과했습니다.
