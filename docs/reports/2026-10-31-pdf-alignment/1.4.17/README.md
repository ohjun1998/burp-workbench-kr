# Simple 1.4.17 · PDF 시안과 실제 화면 대조

[나란히 비교 PDF](workbench-simple-1.4.17-pdf-alignment.pdf) · [오프라인 갤러리](gallery.html) · [원본 PNG 포함 ZIP](workbench-simple-1.4.17-pdf-alignment-images.zip)

이번 자료는 중단되었던 PDF 맞춤 작업을 1.4.16 원격 소스에서 복구한 1.4.17 결과입니다. 이전 1.4.16의 완료 기록과 이번 작업의 결과를 구분합니다.

[화면별 구현 대조와 남은 차이](ALIGNMENT_KR.md)도 함께 확인하세요.

실제 운영 Swing 컴포넌트에 합성 패킷·계정 데이터를 넣은 캡처입니다. 실제 Windows Burp 본체·DPI/IME·외부 서비스 검증은 별도입니다.

시안과 실제 캡처의 합성 데이터·선택 상태·결과 건수는 서로 다릅니다. 각 원본 PNG를 제공하므로 배치와 표시 내용을 함께 대조할 수 있습니다. PDF 원본 삽입 검사는 이미지 보존 검사이며 화면 배치의 픽셀 일치 판정이 아닙니다.

인증 후보 연결 시안은 연결 영역만 보여 줍니다. 이 비교와 별도로 부록에 실제 준비 창의 세 탭 전체를 테마별로 수록했습니다. 연결 영역만의 비교를 준비 창 전체의 검증 결과로 사용하지 않습니다.

16개 화면 × 두 테마의 비교 32페이지와 인증 준비 창 전체 세 탭 × 두 테마의 부록 6페이지를 수록했습니다. 원본 이미지에 UI 내용을 덧그리거나 시안의 예시 값을 주입하지 않았습니다.
