## 수정과 검증 범위

공통190/174px 메뉴·46px 헤더·카드/탭, 입력값 검사 결과의 실제 필터/응답 시간/상단 주 작업, 단일 보고서 작성 카드, 원문 대조와 실제 선택된 재현 결과, 인증 준비 창의 전체3탭을 확인했습니다. JS 호출 위치·서버/경로의 실제 응답 상태 필터·검색/CVE 사실표·변환/완료/대시보드 작업 영역도 대조했습니다. 작은 CVE 창은 실제 세로 스크롤로 출처 작업까지 도달하며 수평 오프셋을 방지합니다. 인증 준비 창은 탭 줄을 고정하고 각 탭 내부에서 스크롤합니다.

첫 전체 검사에서는 옛 글자 크기·팔레트, 숨겨진 CSV 메뉴, 중복 shortcut, 재현 탭 수, 대시보드 tree 선택, Mapper 버전 기대가 실패했습니다. 기능·원본 바이트·실제 Action 연결·배율·Scope·전송·수명주기 검사는 유지하며 새 PDF 기준을 반영했고, 각 실패 그룹의 독립 검증 후 **전체 명령을 다시 실행하여 종료 코드0**을 확인했습니다. 첫 실패 결과는 [보존한 요약](first-full-test-summary.json)과 별도 로그에 구분했습니다. 최종 전체 명령은 Mapper와 Node 단계까지 실행했습니다.

캡처의 계정·패킷·CVE·개수는 합성 fixture이며 생산 확장에 예시 데이터를 넣지 않았습니다. 실제 데이터와 추가 기능 때문에 남긴 차이를 숨기거나 PDF와 픽셀이 같다고 주장하지 않습니다. 원본 Next와 모든 이전 버전의 배포 파일은 변경하지 않았습니다.

실제 Windows Burp 본체·DPI/IME, 수동 브라우저/MV3, Docker 전체 실습 스택, 외부 CVE/OAST/BApp/AI 서비스는 이번 검증에 포함하지 않습니다. 현재 실제 실행 결과는 [VERIFICATION.json](VERIFICATION.json), 게시 결과는 별도 `PUBLISH_KR.md`를 기준으로 확인합니다.
