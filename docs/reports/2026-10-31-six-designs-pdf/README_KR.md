# Workbench · 라이트3안 / 다크3안 디자인 비교

[9페이지 PDF 다운로드](workbench-light-dark-six-designs.pdf) · [라이트3안](light-overview.png) · [다크3안](dark-overview.png)

같은 요청·응답 화면을 기준으로 서로 다른 세 계열의 디자인을 라이트·다크 한 쌍씩 비교합니다. 총6개 시안이며 제품 소스코드는 변경하지 않았습니다.

- A: 미니멀 화이트·블루 / 차콜·블루. 폴더 메뉴와 위쪽 요청 표·아래쪽 좌우 패킷의 익숙한 배치입니다.
- B: 소프트 아이보리 / 웜그레이·앰버. 왼쪽 요청 목록과 오른쪽 위아래 요청·응답으로 작업 흐름을 바꿉니다.
- C: 쿨그레이·청록 / 네이비·청록. 아이콘·짧은 이름의 간결한 메뉴와 넓은 읽기 영역에 집중합니다.

PDF구성: 표지와비교설명1페이지, 라이트3안비교1페이지, 다크3안비교1페이지, 개별대화면6페이지로 총9페이지입니다. 한글제목·설명·책갈피를 포함합니다.

image_gen으로 생성한 디자인 검토용 이미지입니다. 실제 실행 화면이나 기능 검증 결과가 아니며, 문구·수치·간격·예시값에는 생성 이미지의 차이가 있습니다. 메뉴 폭이나 분할 비율은 설계 목표이며 실제 측정값으로 주장하지 않습니다. 이전PDF와배포파일은변경하지 않았습니다.
