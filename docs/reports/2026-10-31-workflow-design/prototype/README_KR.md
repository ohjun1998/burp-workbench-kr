# 작업 흐름 설계 시안

기존 확장 엔진을 연결하지 않은 HTML 검토 시안입니다. 메뉴·접힘·역할 연결·단계 이동·화면 설명과 일부 로컬 변환 예시를 확인할 수 있습니다. 실제 전송·외부조회·증거저장은 수행하지 않습니다.

압축을 푼 폴더에서 `python -m http.server 8000`을 실행하고 `http://127.0.0.1:8000/prototype/index.html`을 엽니다. 서버는 정적 파일만 제공합니다. `screen`과`theme` 쿼리로 각 화면을 직접 엽니다. 예: `?screen=auth&theme=dark`.

관리형 검증 브라우저는 file:// 열기를 차단하므로 직접 파일 열기는 검증하지 않았습니다. 로컬 HTTP 방식으로 확인했습니다. 한글 폰트와 모든 스크립트는 포함되어 있고 외부 CDN이 필요하지 않습니다.
