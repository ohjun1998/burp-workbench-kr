# 도구 배치에 맞춘 실행 결과 HTML

[저장용 ZIP](Workbench_Simple_1.4.21_Results_Layout_KR.zip)을 내려받아 압축을 풀고 안의 HTML을 더블클릭합니다. [.html 원본](Workbench_Simple_1.4.21_Results_Layout_KR.html)도 제공합니다.

실제 Workbench Simple1.4.21의 왼쪽 메뉴·결과 표·계정 비교·요청/응답 패널·대시보드 배치를 참고해 **저장된 실행값 중심의 HTML**로 재구성했습니다. 기존 설명 보고서와 별도의 결과 열람 화면입니다.

- 왼쪽 메뉴에서13개 도구 선택
- 실제 결과 행 선택, 현재 도구 검색, 계정·분류·기능·원본 변경
- 계정 비교의 실제 Alice 기준/Bob 응답, SQL 후보의 실제 GET·404 응답 표시
- JWT·응답 비교, 이체5단계와 실제 잔액, 원래 대시보드 집계 표시
- 라이트·다크 전환, 작은 창에서 메뉴 숨김·세로 배치, 현재 도구 JSON 저장

새 전송·점검 기능은 없으며 폰트와 데이터가 파일에 들어 있습니다. 원래 후보·미확인·미실행 상태를 유지하고, 민감 헤더·비밀값은 가립니다. 관리자 HTML·바이너리 본문은 생략하며 일반 HTML/JS 발췌는4000자로 제한했습니다. 표시본과 원본의 SHA는 구분했습니다.
