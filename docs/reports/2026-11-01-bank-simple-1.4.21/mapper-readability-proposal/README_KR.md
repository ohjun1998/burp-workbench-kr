# 기능 목록 가독성 시안

[비교 HTML 열기](Mapper_Readability_Proposal_KR.html)

URL이 반복되는 기능 목록을 짧은 한국어 표시명과 관측 요청 수로 바꾼 별도 시안이다. 기존 결과 HTML과 Simple 1.4.21 JAR에는 반영하지 않았다.

- **A 그룹형 · 추천**: 핵심 업무와 계정 기능을 먼저 보여준다. 문서·환경 탐색, 입력 변형과 대조 경로는 접어서 표시한다.
- **B 한 줄형**: 전체 항목을 한 줄씩 표시한다. 현재 목록의 구조를 가장 적게 바꾸는 안이다.
- **C 카드형**: 기능명·유형·요청 수를 작은 카드에 표시한다. 좁은 목록에는 그룹형이 더 적합하다.

예를 들어 잔액 조회는 13건, 관리자 화면은 6건, 로그인은 2건으로 표시한다. 원본 URL·관측 ID·기능 ID·원래 기능명은 선택 상세의 **원본 정보 보기**를 펼쳐 확인한다. 한글 표시명으로 검색할 수 있고 라이트·다크 전환도 가능하다.

43개는 자동 분류된 관측 그룹이다. 표시명과 상위 그룹은 가독성을 위한 제안이며 정상 기능 또는 취약점 확정을 의미하지 않는다. 미점검 상태와 HTTP 응답은 원래 값으로 유지한다. 문서·경로의 404 후보는 후보로 구분하고 입력 변형 및 대조 경로의 개별 ID도 그대로 유지했다. 배지의 건수는 원래 기능의 primary 연결에 해당하는 관측 수다.

`build_proposal.py`는 SHA-256으로 확인한 기존 완성 HTML에서 별도 시안을 만든다. 내장된 전체 JSON 데이터는 기존 완성본과 바이트가 같다. 재생성은 저장소 루트에서 다음 명령으로 실행한다.

```sh
python3 docs/reports/2026-11-01-bank-simple-1.4.21/mapper-readability-proposal/build_proposal.py
```

현재 브라우저 검증은 `browser-verification.json`에 기록했다. 43개 기능 ID와 전체 135건, 기능별 선택, 한글 표시명 검색, URL 펼치기, 세 가지 표시 방식과 두 테마, 1480·1024·390px의 가로 넘침을 확인했다. JavaScript 오류와 추가 HTTP 요청은 0건이다. 이 검증은 HTML 시안에 대한 것이며 실제 Burp 확장 화면 검증은 아니다.
