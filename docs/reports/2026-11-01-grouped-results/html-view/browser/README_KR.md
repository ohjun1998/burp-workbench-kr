이 폴더에는 대표 PNG13개를 원본 바이트대로 복사했다. 전체43개 브라우저 캡처는 JSON의 `qaScreenshotsOutsideRepository` 경로에 있으며, 복사한 파일 목록은 `copiedRepresentativeScreenshots`로 구분한다. `SHA256SUMS`는 최종 보고서·실행 출력·대표 PNG의 지문이다. 별도 이미지·폰트 서버 없이 HTML 한 번만 제공하는 loopback 서버로 검증했다. 관리형 Chromium의 파일 URL 정책 때문에 `file://` 직접 실행을 검증한 것은 아니다.

첫 시도는 그룹 선택 버튼의 일반 문구에서 유형명을 찾던 검사 가정을 고쳤다. 실제 유형은 폴더 제목과 그룹 키에 있었다. 두 번째 시도는 기존 기능 검사에 통과했으나 직접 캡처 검토에서 모바일 JS 분석 원본 카드의 축소·잘림을 발견했다. CSS를 보완하고 원본 선택 필드의 높이와 카드·페이지 안 실제 노출 영역을 검사하도록 추가한 뒤 세 번째 최종 시도로 통과했다. 이전 시도는 `prior-attempts/`에 구분했고 최종 검증 수치와 합산하지 않는다.
