현재 클라우드의 GitHub REST API는 Forbidden으로 차단되어 PR 생성/원격 Actions 조회를 확인하지 못합니다. Git HTTPS 브랜치 게시와 공개 raw 다운로드는 별도로 검증합니다. main 병합이나 PR 생성 완료를 뜻하지 않습니다.
