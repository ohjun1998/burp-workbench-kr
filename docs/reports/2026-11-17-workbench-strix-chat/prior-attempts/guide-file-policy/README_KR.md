# 가이드 로컬 파일 열기 정책 제한

Chromium에서 최종 단일 HTML을 `file://`로 여는 시도는 문서 로드 전에 관리 정책의 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단됐습니다. DOM 검사0개 상태이며 이 시도를 가이드 통과 결과로 세지 않습니다. 브라우저 정책·사용자 프로필은 변경하지 않았습니다.

후속 검사는 동일한 최종 HTML 바이트만 전용 loopback HTTP 서버로 제공하고, 처음 문서를 읽은 뒤 네트워크를 오프라인으로 전환해 내장 이미지·100% 확대·내부 링크·뷰포트를 실제 Chromium에서 확인합니다. 이 방식의 성공은 사용자의 OS 저장창이나 `file://` 열기를 직접 검증한 결과와 구분합니다.
