# Workbench 한국어 사용 안내서

처음 사용한다면 **0.25.0 쉬운 한국어 개정판**을 받으세요. 하고 싶은 일을 고르고, 화면의 버튼을 따라 누른 다음 어떤 결과를 확인해야 하는지 설명합니다.

| 사용할 확장 | 안내서 | 내용 |
|---|---|---|
| 0.25.0 | [쉬운 한국어 개정판](0.25.0-easy-ko/Burp_Workbench_KR_0.25.0_easy_guide.pdf) | 24쪽 전체 문장을 다시 썼습니다. 어려운 용어는 예시로 설명하고 계정 등록 등 빠진 순서도 보완했습니다. |
| 0.25.0 | [개정 전 안내서](0.25.0/Burp_Workbench_KR_0.25.0_guide.pdf) | 이전 설명을 확인할 때 사용하는 보존본입니다. |
| 0.24.0 | [이전 안내서](0.24.0/Burp_Workbench_KR_0.24.0_guide.pdf) | 0.24.0 화면과 사용 방법입니다. |
| 0.23.0 | [이전 안내서](0.23.0/Burp_Workbench_KR_0.23.0_guide.pdf) | 0.23.0 화면과 실습 방법입니다. |

개정판도 **0.25.0 JAR**로 사용합니다. 문서만 수정했으므로 확장을 다시 설치할 필요는 없습니다. 처음에는 3~5쪽에서 용어·설치·첫 요청을 확인하고, 이후에는 2쪽의 목차에서 필요한 기능을 찾으세요.

그림은 예제 데이터를 넣어 만든 확장 화면입니다. 실제 Burp에서 점검을 마친 결과를 캡처한 그림은 아닙니다.

원고는 [쉬운 한국어 원고](../../docs/GUIDE_0.25.0_EASY_KR.md), 변경 내역은 [문서 개정 기록](../../docs/HANDOFF_GUIDE_EASY_KR.md)에서 확인할 수 있습니다. 생성 명령은 `python tools/build_guide.py --edition easy-ko`입니다. 기존 PDF는 그대로 보존합니다.
