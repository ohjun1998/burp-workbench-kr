# 한국어 PDF 가이드

처음 사용한다면 **현재 JAR와 같은 버전의 가이드**를 받으세요. 설치 → 첫 요청 선택 → 공통 SCOPE 지정 → 목적에 맞는 점검 → 원본·증거 저장 순서로 읽을 수 있습니다.

| 버전 | 파일 | 범위 |
|---|---|---|
| 0.25.0 | [최신 그림 가이드북](0.25.0/Burp_Workbench_KR_0.25.0_guide.pdf) | 쉬운 기능 이름, 화면 안 기능 안내, 첫 사용 순서와 각 도구의 입력·결과·다음 동작 |
| 0.24.0 | [이전 가이드북](0.24.0/Burp_Workbench_KR_0.24.0_guide.pdf) | 버튼·작은 화면 개선, 전체 도구, 계정·업무, 모의 진단과 원본 증거 |
| 0.23.0 | [이전 가이드북](0.23.0/Burp_Workbench_KR_0.23.0_guide.pdf) | UI 최적화 이전 도구 및 커뮤니티 모의 진단 |

0.25.0은 **요청·응답 목록**, **계정 권한 비교**, **입력값 보안 검사**처럼 작업을 드러내는 이름을 사용합니다. [이전 이름 대응표](../../docs/RELEASE_0.25.0_KR.md)로 과거 문서를 함께 읽을 수 있습니다.

그림은 운영 Swing 컴포넌트를 API 어댑터로 렌더링한 미리보기입니다. 실제 Burp GUI 클릭이나 브라우저 실행을 완료했다는 증거가 아닙니다. 현재 실행 검증은 [검증 JSON](../../docs/VERIFICATION_0.25.0.json)을 확인하세요.

텍스트 원본은 [가이드 원고](../../docs/GUIDE_0.25.0_KR.md), 재생성 코드는 `tools/build_guide.py`와 `tools/GuidePreview.java`에 있습니다. 과거 PDF는 각 버전 폴더와 `release/`, `history/`에 보존합니다.
