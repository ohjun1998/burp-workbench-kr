그림은 최신 운영 Swing 컴포넌트를 API 어댑터로 렌더링한 미리보기입니다. 실제 Burp GUI 클릭이나 브라우저 실행을 완료했다는 증거가 아닙니다. 현재 실행 검증은 [검증 JSON](../../docs/VERIFICATION_0.24.0.json)을 확인하세요.

텍스트 원본은 [가이드 원고](../../docs/GUIDE_0.24.0_KR.md), 재생성 코드는 `tools/build_guide.py`와 `tools/GuidePreview.java`에 있습니다. 과거 PDF는 `release/`와 `history/`에 보존합니다.
