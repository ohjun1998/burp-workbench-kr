# 0.19.0 배포 검증

확장 API 어댑터·headless Swing 799개, 페이로드 HTTP fixture 127개, 커뮤니티 실제 HTTP 검사 100개(199회 요청), 실제 Burp 런타임 13개가 통과했습니다. 검사군 합계이며 독립 취약점 개수가 아닙니다.

실제 Burp Community에 배포 JAR를 로드하고 CSRF GET 갱신, 신원 불일치 거부, 생성→조회와 취소를 확인했습니다. GUI 창과 프록시 리스너 없이 임시 프로필로 실행했고 서버를 종료했습니다. 단계 구분 줄바꿈이 본문에 붙는 문제를 발견해 수정하고 실제 Burp 및 회귀 검사로 확인했습니다. 별도의 클라우드 VM은 사용하지 않았습니다.

PDF: 45쪽, 실제 배포 UI 이미지 34개, 번호 설명 129개. 41~44쪽은 서비스 전체 점검 흐름입니다. 전체 페이지를 PNG로 렌더링해 확인했습니다. 화면은 창 없는 실제 Swing 컴포넌트 렌더링이며 Burp 데스크톱 캡처가 아닙니다.

Pro Collaborator 외부 서비스와 브라우저 실제 스크립트 실행, TLS/HTTP2, 전체 Docker/Oracle/Nginx는 이번 검증 범위에서 제외했습니다. Native Burp headless 시작 과정에 Swing 테마 경고가 있었으며 확장 오류 출력은 0바이트였습니다.
