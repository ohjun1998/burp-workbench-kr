# Workbench KR 0.16.0

기존 확장을 언로드한 뒤 `burp-workbench-kr-0.16.0.jar`를 Java 확장으로 불러옵니다.

## 데이터 도구 → 비교

1. 왼쪽과 오른쪽에 비교할 JSON, XML, HTTP 요청/응답 또는 일반 텍스트를 붙여넣습니다.
2. **비교**를 누릅니다. 기본으로 JSON·XML 본문을 정렬해 나란히 표시합니다.
3. 왼쪽 차이는 붉은색, 오른쪽 차이는 초록색으로 표시됩니다. **← / →**로 차이 위치를 이동합니다.
4. **입력으로**를 눌러 원문을 수정하거나 **데이터 정렬**을 해제해 원문 기준으로 비교합니다.

추가·삭제된 줄은 빈 줄을 넣어 위치를 맞춥니다. 붙여넣은 원문은 유지합니다. 숫자 값과 JSON 키 순서는 유지하며 키 순서를 자동으로 재배열하지 않습니다. 입력당 64 KiB, 정렬 후 1,500줄까지 비교합니다. 제한 적용 시 상태 표시가 나타납니다. 비교 작업은 HTTP 요청을 보내지 않습니다.

## 설정 창

최상위 **설정** 탭을 선택하거나 **설정 창 열기**를 누르면 공통 배치 설정 창이 열립니다. 창을 띄운 상태에서 다른 도구 탭도 사용할 수 있습니다. 환경 탐색 후보 설정과 페이로드 검사 설정도 별도 창으로 표시합니다. 데이터 비교는 좌우 배치를 사용합니다.

## JS 추출

URL/API는 파란색, 시크릿은 붉은색, 도메인·의존성은 초록색, 소스맵 지시문은 보라색으로 원문에 표시합니다. 유형 필터와 **← / →**로 감지 위치를 순환하며 해당 결과 행을 함께 선택합니다. 수동 입력을 분석하면 바로 색을 표시합니다. 수집된 JS는 결과 선택이나 화살표 이동 시 원문을 표시합니다. 원문을 직접 수정하면 기존 표시를 해제하며 화살표 이동 시 분석 당시 원문을 복원합니다. 외부 소스맵에서 복원한 내용처럼 현재 원문 위치가 없는 항목은 화살표 탐색 대상에 포함하지 않습니다.

## 환경 탐색 추천 개선

환경별 선별 경로에 더해 실제 robots.txt·sitemap·OpenAPI GET 경로·Actuator 링크·Swagger 문서 위치를 반영합니다. OpenAPI 서버와 기본 경로를 고려하고 다른 출처 및 변수 포함 경로는 제외합니다. 환경 분류를 선택하면 해당 근거에 연결된 후보를 표시합니다. 경로의 참고 출처는 툴팁에서 확인할 수 있습니다. 사용자 워드리스트는 후보 설정에서 가져옵니다.

검증 결과를 다음 정렬에 반영합니다. 404/410과 없는 경로와 동일한 응답은 낮추고, 401/403 및 검토할 응답은 우선합니다. 2xx 응답만으로 취약점을 확정하지 않습니다. 기본 설정에서 검증한 후보는 일괄 실행 시 제외합니다.

없는 경로 비교가 켜져 있으면 경로 루트마다 임의 경로에 **추가 GET 요청 1회**를 보내 기준 응답을 수집합니다. 본문과 콘텐츠 유형이 같은 응답을 구별해 SPA 등에서 발생하는 오탐을 줄입니다. 완전히 같은 본문 기준이므로 동적 응답을 모두 잡아내지는 않습니다. 429가 발생하면 남은 요청을 중단합니다. 대용량 덤프·재시작 등 후보는 일괄 실행에서 제외하며 단일 실행 대상으로 유지합니다. 실행은 기존 범위 설정과 선택 작업을 따릅니다.

추천 근거: SecLists, Assetnote의 기술별 목록 구성, 공식 Spring/OpenAPI/FastAPI/Symfony/Rails 문서와 Wiz의 공개 Actuator 연구. 전체 원본 워드리스트는 포함하지 않았습니다. 세부 링크는 소스의 `ENVIRONMENT_SOURCES_KR.md`에 있습니다.

## 한글 및 패킷 표시

응답 바이트의 UTF-8·EUC-KR·MS949 등 선언된 인코딩을 반영합니다. UTF-8을 다른 인코딩으로 읽은 흔적은 표시 영역에서 복원을 시도합니다. 한글 글꼴을 선택하고 필요한 경우 포함된 NanumGothic 글꼴을 사용합니다. 문자 복원과 정렬은 화면 표시용이며 저장된 원본과 전송 데이터는 변경하지 않습니다.

## 검증 범위

가짜 Burp 호스트, 로컬 HTTP 서버 및 Swing 컴포넌트로 기능을 검증했습니다. 실제 Burp의 창 표시와 운영 대상에서의 최종 확인은 별도입니다.

자동 기능 검사 564개, 전체 화면 배치 검사 828개가 통과했습니다.
