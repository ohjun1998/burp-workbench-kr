버그바운티 흐름 실습

사이트 3.5.0 · 요청 수집 → 정책별 권한 비교 → 저장·조회 연결 → 증거 정리 → 데이터 정리

로컬 학습용 가상 데이터입니다. 응답에 마커가 보이는 것과 브라우저에서 실행되는 것은 다릅니다. 이 페이지는 응답을 문자열로 표시하며 취약 HTML을 자동 실행하지 않습니다.

1. 계정과 비교 모드

로그인이 필요합니다. 실습 비밀번호: LabOnly!2026

브라우저 로그인은 현재 실습 사이트 세션만 전환합니다. Burp 권한 비교에는 각각의 세션을 별도 슬롯으로 수집하세요.

2. 같은 경로, 서로 다른 정책

GET /api/bounty/{mode}/objects/{id}의 성공 응답은 모두 200입니다. 대표 URL 한 개만 검사하면 다른 조직·공유 정책을 놓칠 수 있습니다.

ID정책fixed 허용 계정실행
201PUBLIC비회원 포함 전체
202OWNER_ONLY · Bobbob, admin
203TENANT · Aalice, moderator, admin
204SHAREDalice, bob, admin
205TENANT · Bbob, admin
206OWNER_ONLY · Alicealice, admin

차단 응답은 404입니다. 소유자 원본 → 다른 계정 → 동일 소유자 재조회 순서로 존재 여부를 검증하세요. 조직 접근은 수동 정책 매트릭스로 ALLOW/DENY를 지정합니다.

3. 저장과 조회를 하나의 발견 건으로

fixed 업로드는 파일명을 probe.txt로 바꾸세요. 다운로드는 text/plain + attachment로 반환합니다.

생성 주소 직접 열기 ↗

마지막 생성 주소는 로그인 계정을 바꿔도 유지됩니다. 다른 계정의 조회와 소유자 재조회를 비교한 후 직접 삭제하거나 초기화하세요. fixed에서는 소유자에게만 조회를 허용합니다.

4. 실습 데이터 정리

이 화면에서 생성한 현재 계정 데이터만 삭제합니다. 커뮤니티 게시글과 다른 계정 데이터는 유지됩니다. 계정당 64개, 전체 256개, 파일당 64KiB 제한이며 서버 재시작 시 사라집니다.
