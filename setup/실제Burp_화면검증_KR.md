# 실제 Burp 화면 및 네이티브 검증

실제 Burp Suite Community 2026.7.3-52685에 재빌드한 Workbench KR 0.21.0 JAR를 로드했습니다. 사용자 PC 화면을 사용하지 않고 격리된 Xvfb 화면과 임시 프로필을 사용했습니다.

- 주요 기능 10개 화면과 계정별·업무별 화면 2개, 총 12개 화면을 실제 선택·캡처했습니다. 한국어 표시와 기본 배치를 확인했습니다. 모든 UI 동작을 검사했다는 의미는 아닙니다.
- 실제 Burp Montoya API로 기존 상세 흐름 71개, 전체 흐름 87개, 계정·업무 흐름 22개, 총 180개 검사 통과. 이 수는 GUI 클릭 수가 아닙니다.
- 확장 오류 로그 0바이트. Burp·실습 서버·가상 화면·콜백 프로세스 종료 및 테스트 포트 종료 확인.
- 이전에 이번 환경에서 통과한 1,132개와 합쳐 현재 검증 합계 1,312개입니다. 이전 첨부 기록을 재사용해 통과 수를 채운 것이 아닙니다.

Java 21.0.3 조합에 대해 Burp가 미검증 JRE 경고를 표시했습니다. 첫 실행의 네이티브 하네스 클래스 로더 오류를 수정하고 재실행했으며 확장 구현은 변경하지 않았습니다. 상세 결과는 `gui-native-verification.json`, 실제 화면과 각 하네스 JSON·로그는 `gui/`에 있습니다.

Docker는 실행하지 못했습니다. 실행기/데몬/소켓이 없고 컨테이너 생성 권한 및 rootless 사용자 네임스페이스 생성도 제한되어 있습니다. 원격 작업공간을 제공하는 DigitalOcean 경로를 찾았으나 설치·연결되지 않아 서버를 만들지 않았습니다. Docker 실행 가능한 환경이 연결된 뒤 Oracle/Nginx/Tomcat 전체 스택 검증을 진행해야 합니다.

브라우저 DOM/JS, Pro Collaborator, 외부 BApp, TLS/HTTP2는 미검증입니다.
