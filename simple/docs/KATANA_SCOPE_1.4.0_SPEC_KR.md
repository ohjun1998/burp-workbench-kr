## 실행 경계

- 수집은 지정한 Scope와 고정한 실행 프로필·예산을 따릅니다. 발견 경로나 환경 단서 때문에 범위를 자동으로 확장하지 않습니다.
- 자동 탐색은 조회 메서드와 변경 경로 제외 정책을 유지합니다. 폼 제출·자동 로그인·결제·삭제·비밀번호 변경을 수행하지 않습니다.
- 동적 API 템플릿은 원문과 실제 관측 통신을 구분합니다. 변수·필수값을 추측하거나 JavaScript 식을 평가해 새로운 대상 요청을 만들지 않습니다.
- 발견한 자격증명으로 외부 공급자·DB·메일 서버에 인증하거나 유효성을 검사하지 않습니다.
- 브라우저의 요청/응답 연결은 메타데이터 관측입니다. 브라우저 세션의 본문·쿠키·쿼리 원문을 HTTP 계정으로 복사하지 않습니다.
- 중단·제외·부분·미방문은 정상 완료와 구분합니다. 대기열 종료는 서비스 전체 기능·취약점 점검 완료가 아닙니다.
- 중지 시 수신 원본은 `RESPONSE_PENDING_ANALYSIS`·`complete=false`로 보존하며 추가 HTTP 없이 원본 열기·내보내기를 유지하고 원문 추출을 제품 분석 완료로 집계하지 않습니다.

## 효과를 읽는 기준

고정 fixture의 알려진 정보와 실제 경로를 기준으로 탐지·오탐·방문·미확인 상태를 각각 확인합니다. 원본 앱의 관측 행수는 중복 위치·계정·응답·예시·미확인을 포함할 수 있으므로 취약점 수나 서비스 전체 탐지율로 사용하지 않습니다. 실제 사이트 재시험과 fixture 성공의 범위도 분리합니다.
