# Workbench Simple 1.3.2 변경 안내

Katana의 SCOPE 수집과 선택적 브라우저 helper를 연결하는 흐름에서 **지연 메뉴 발견·동작 전 링크 보존·부분 탐색 표시·경로별401 신원 재확인**를 보완했습니다. 원문 값 보고서에는 JS 백틱 문자열과 동적 API 템플릿을 근거 위치와 함께 보존합니다. 기존 8개 도구와 원본 Next, Simple 1.0.0–1.3.1 배포·가이드·검증 기록은 유지합니다. Katana는1.8.0이며 새 helper는0.4.1입니다.

## 메뉴·기능 탐색

Katana는 HTML·JS·폼 메타데이터에서 경로와 API 후보를 발견하고 실제 응답을 기존 환경·민감정보 분석에 연결합니다. 브라우저 helper를 선택하면 별도 탐색 탭의 DOM 메뉴와 동적 라우트도 관측합니다. 두 실행의 로그인 세션과 예산은 구분합니다.

- 늦게 나타나는 SPA 메뉴를 즉시 탐색 종료로 처리하지 않도록 제한된 대기를 적용합니다.
- 탭·메뉴 동작으로 DOM이 바뀌기 전에 관측한 링크를 먼저 보존합니다.
- 메뉴 동작·경로·페이지·후보 큐 등의 한도에 닿으면 남은 범위를 부분 탐색으로 표시합니다. helper 팝업은 부분·중지·실패·완료를 구분합니다. 발견 대기열의 종료를 사이트 전체 메뉴 완료로 해석하지 않습니다.

최초 DOM 확인은 최소1.5초, 후속 메뉴 동작 뒤에는 최소350ms를 관찰합니다. 관측 경로나 남은 메뉴 동작이 있고 DOM이350ms 안정되면 진행합니다. 경로·동작이 없는 빈 화면은3초 전체를 기다리고, 빈 화면·계속된 `aria-busy`·DOM 변화로 끝나면 부분 상태로 남깁니다. 문서 후보200개·문서별 동작12회·스크롤2회·실행 후보500개·대기열100개와 전체 페이지/동작 한도를 적용합니다. 한도 뒤 나타나는 메뉴까지 모두 관측했다는 의미는 아닙니다.

브라우저 helper0.4.1 ZIP을 새 폴더에 풀고 압축해제된 확장을 다시 불러옵니다. 연결 주소·토큰과 사이트 활성화, **SPA 통합 탐색 허용**을 확인한 뒤 Workbench 통합 점검에서 브라우저 모드를 선택합니다. 기존 브라우저 로그인 계정과 HTTP 점검 계정은 별개이며 쿠키를 복사하지 않습니다.

## 경로별401과 실제 세션 실패

정상 계정의 신원이 확인됐어도 별도 역할·인증 영역의 경로는401을 반환할 수 있습니다. 기존에 구성한 신원 URL·동일 계정의 신원 확인 근거가 있고 로그인 화면·리디렉션·보안 확인·쿠키 변경이 없을 때만, 동일 인증 스냅샷의 신원 GET과 비로그인 대조 GET을 새로 전송합니다. 인증된 새 응답의 완전한2xx JSON에서 신원·조건이 다시 일치하고 비로그인 대조가 그 신원을 증명하지 못해야, 해당401을 경로별 접근 거부·권한 의도 미확인으로 남기고 나머지 큐를 이어갑니다.401 경로는 재시도하지 않으며 새 신원·비로그인 대조의 원본 ID와 거부 원본을 구분합니다.

새 제어 요청2회도 SCOPE·GET·공통 요청 예산을 지킵니다. 신원 URL 자체의401, 구성/근거 누락, 남은 예산 없음, 실제 신원 만료·불일치, challenge·리디렉션·쿠키 변경·잘못된 응답이면 정상 신원 유지로 예외 처리하지 않고 기존 세션·예산 중단 정책을 적용합니다. 자동 로그인이나403 정책의 일반 완화는 추가하지 않았으며, 신원 유지가 해당 경로의 접근 권한을 증명하지는 않습니다.

## 원문 값 보고서

점검 완료 또는 중지 후 **분류 보고서 저장**에서 새 ZIP을 저장합니다. `report.json`의 `value`는 파싱값, `rawText`는 원문 표기이며 실제 원본 ID·응답 SHA·UTF-16 위치를 함께 확인합니다. 백틱 안의 정적 문자열과 `${...}`를 포함한 동적 템플릿을 구분합니다. 동적 값은 식을 평가하거나 실제 URL·키로 만들어내지 않고 미확정 상태로 남깁니다.

정적 백틱은 `valueType=STRING`이며 `value`에는 이스케이프를 해석한 문자열, `rawText`에는 백틱을 포함한 원문이 들어갑니다. 동적 API는 `valueType=RAW_TEMPLATE_INTERPOLATED`·`classification=DYNAMIC_UNRESOLVED`로 표시합니다. 이때 `value`는 `${...}`가 남아 있는 백틱 내부 원문이며 `rawText`는 전체 백틱 원문입니다. `resolvedEndpoint`를 만들지 않으므로 실제 API 도달이나 동적 값 복원 완료로 읽지 않습니다. 동적 시크릿·태그 함수·연결식의 앞부분을 실제 시크릿으로 추출하지 않습니다.

`report.html`은 읽기용 분류표, `values.csv`는 스프레드시트용 목록, `manifest.json`은 범위·분석 제한 기록입니다. CSV의 보호 문자가 붙은 셀을 포함해 정확한 기계 값은 JSON에서 확인합니다. 보고서 추가 파싱과 제품의 자동 탐지, 공개·예제·미검증 분류를 구분합니다. 저장은 추가 대상 요청이나 발견 키의 유효성 검사를 하지 않으며 기존 파일을 덮어쓰지 않습니다. 정상 화면·이력·기존 증거의 가림은 유지합니다.
