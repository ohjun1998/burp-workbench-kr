# Workbench Simple 1.4.0 변경 안내

기존 8개 도구와 Katana 1.8.0 수집을 유지하면서 **응답 분석·원문 보고서의 공통 파서, 탐색 처리 흐름, 선택 재점검, 브라우저 요청·응답 연결**을 보강합니다. 새 helper는 0.5.0입니다. 기존 Next와 Simple 1.0.0–1.3.2 배포·가이드·검증 기록은 보존합니다.

## 주요정보 수집과 분류

원터치 통합 점검이 이미 확보한 응답을 공통 규칙으로 분석하고, 같은 규칙의 원문 값과 근거를 명시적 분류 보고서로 저장합니다. API 경로·템플릿, 개인정보, 환경 설정, 키·토큰·연결문자열 후보를 함께 확인합니다. 주소·생년월일·계좌 관련 필드처럼 이전에 보고서 보충 파싱에서만 확인하던 정보를 운영 탐지와 연결합니다.

응답에서 명시적으로 참조한 소스맵은 같은 Scope·조회·예산 안에서 수집 후보로 다루며 환경 추정 경로의 제한과 분리해 우선 확인합니다. 소스맵 이름을 추측해 탐색하지 않으며 복원 코드의 가상 위치와 실제 응답 원문 좌표를 구분합니다. 용량·구조 한도와 미검사 범위는 부분 상태로 남습니다.

CSS 아이콘, 빈값·null, DOMTokenList, 일반 Swagger 코드 조각을 실제 DB·토큰·비밀값으로 해석하지 않도록 문맥과 값 상태를 확인합니다. DB 연결문자열·URI 인증정보의 `password@host` 부분을 별도 이메일로 중복 분류하지 않으며 정상 이메일과 `mailto`는 유지합니다. 공개 식별자·예시·데모·동적 미해결 상태는 비밀값 후보와 구분합니다. 일반 쿠키 값과 인증 형식은 주요정보에서 제외하고 **쿠키·인증 형식** 보기에서 따로 확인하며 실제 인증 토큰으로 확정하지 않습니다. 탐지 개수는 취약점 개수가 아니며, 인증된 본인 계정의 응답에서 수집한 개인정보는 비인가 공개 여부와 별도로 읽습니다.

화면과 실행 이력에는 마스킹된 값·분류·지문을 사용합니다. **분류 보고서 저장**으로 명시적으로 만드는 로컬 ZIP은 원문 값을 포함하며, `report.json`의 `value`·`rawText`·원본 ID·응답 SHA·UTF-16 위치를 함께 확인합니다. 보고서 추가 추출·제품 탐지 연결·부분 분석 범위를 구분하며, 동적 식을 실행하거나 없는 원문 값을 복원하지 않습니다.

## 발견한 경로와 실제 응답 구분

경로 문자열이나 메뉴를 발견한 상태와 실제 요청·응답·본문 분석 상태를 탐색 처리 흐름에서 구분합니다. 대기, 실패, 깊이·예산 한도, Scope 제외, 인증 필요, 변수 미해결과 처리 불가 사유를 읽고 후속 확인 대상을 고릅니다.

**형태 일치 후보**는 미해결 API 템플릿과 이미 관측한 응답 주소의 정적 경로 형태를 대조합니다. `PATH_SHAPE_ONLY` 상세에서 선언·관측 각각의 계정·인증 revision·HTTP·원본을 분리해 확인합니다. 쿼리·fragment 항목은 제외하며 변수·호스트 식 복원, 계정·권한·메뉴 인과 확인이나 실행 가능성 승격은 하지 않습니다. 이 대조는 추가 대상 요청 없이 현재 보유한 근거에서 제한된 후보만 표시합니다.

선택 재점검은 대기열 처리 완료 또는 중지 뒤 현재 실행의 조건과 남은 예산 안에서 허용한 조회 항목만 다시 처리합니다. 선택하지 않은 기존 대기열은 재점검 동안 보관했다가 되돌립니다. Scope·프로젝트·인증이 달라졌거나 기존 예산이 소진된 경우에는 이유를 확인하고 새 실행을 준비합니다. 거부 응답을 성공으로 바꾸거나 미해결 입력·쓰기 요청을 추측해 실행하지 않습니다. 중지 후 이어가기와 선택 재점검은 각각의 실행 조건·대기 항목을 확인합니다.

중지 시 이미 수신한 원본은 `RESPONSE_PENDING_ANALYSIS`·`complete=false`로 보존하며, 추가 HTTP 없이 원본 보기·분류 보고서로 확인할 수 있고 원문 값 추출을 제품 분석 완료로 처리하지 않습니다.

기존 계정별 비교와 변경 이력은 같은 계정·범위·조건·분석 규칙의 응답을 비교합니다. 1.4.0의 공통 파서 확대는 새 분석 기준으로 구분하므로 첫 실행은 새 baseline이며, 이전 버전에서 추출하지 못했던 값을 사이트의 새 변경으로 오인하지 않습니다. 이전 이력은 보존해 읽을 수 있습니다. 불완전한 실행에서 재관측하지 못한 항목을 해결로 확정하지 않습니다. 상태 코드 차이와 신원 유지도 해당 경로의 권한 획득·우회 성공을 뜻하지 않습니다.

## 브라우저 helper 0.5.0

같은 Scope의 iframe 주소를 메뉴 후보로 수집하고, 브라우저에서 관측한 API 요청과 응답·오류를 해시 연결 ID로 연결합니다. HTTP 상태, 자원 유형, frame, 캐시, 경과 시간과 대기 상태는 브라우저 관측 문맥으로 표시합니다. 종료 시 제한된 응답 대기 뒤에도 요청이 남으면 부분 탐색으로 유지합니다.

helper ZIP을 새 폴더에 풀고 압축해제된 확장을 갱신한 뒤, 연결 주소·토큰, 현재 사이트 활성화와 SPA 통합 탐색 허용을 확인합니다. 별도 탐색 탭과 GET/HEAD·Scope·변경 경로 제외 조건은 유지합니다. 브라우저 로그인 계정과 Workbench HTTP 프로필은 별개이며 쿠키·응답 본문·쿼리 원문을 연결 메타데이터로 복사하지 않습니다.

브라우저의 응답 상태 관측은 해당 본문을 제품이 분석했거나 선택한 HTTP 계정의 접근을 검증했다는 의미가 아닙니다. 메뉴·iframe·라우트와 실제 통신의 연결은 관측한 문맥의 근거로 읽습니다.
