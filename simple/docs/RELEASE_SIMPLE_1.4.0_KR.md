# Workbench Simple 1.4.0 · 점검 대시보드

Workbench 안에서 현재 SCOPE 통합 점검의 수치를 보고, 숫자·막대를 눌러 해당 결과와 원본을 확인합니다. 기존 8개 도구와 통합 점검, Mapper 0.3.6·브라우저 helper 0.4.1·Katana 1.8.0은 유지합니다. 기존 Next 및 Simple 1.0.0–1.3.2 배포 파일은 수정하지 않습니다.

## 사용 흐름

1. Workbench Simple 상단의 **대시보드**를 누릅니다. 아직 실행이 없으면 빈 상태와 시작 안내를 표시합니다.
2. **통합 점검 열기**에서 SCOPE·HTTP 계정·실행 조건을 확인하고 점검을 직접 시작합니다. 대시보드는 같은 현재 실행의 결과를 받아 갱신하며 별도로 수집하지 않습니다.
3. 관측 경로·API와 명세·환경과 DB 단서·민감정보 후보·계정별 차이·미확인 카드를 누릅니다. 분류별 막대도 같은 목록을 엽니다.
4. 계정 또는 민감정보 중요도로 좁힙니다. 목록 위에서 전체 수와 현재 조건의 수를 함께 확인하고 **조건 해제**로 해당 분류의 전체 목록으로 돌아갑니다.
5. 목록의 항목을 선택하면 상태·확실성·중요도·탐지 근거·원본 위치를 확인합니다. 현재 원본이 연결된 경우 **원본 보기**, **Repeater 준비**, **증거 추가**로 이어갑니다.

기존 8개 도구의 진입점과 입력은 유지합니다. 대시보드는 기존 페이지 뒤에 추가하며, 작은 창에서는 카드를 두 줄로 배치하고 세로 스크롤로 차트·상세를 확인합니다. 밝은/어두운 테마와 키보드 버튼 선택을 지원합니다.

대량 결과를 집계하는 동안에는 숫자 대신 **—**와 집계 중 안내를 표시합니다. 같은 실행·계정의 새 결과를 집계할 때는 기존 카드·목록을 **이전 집계 표시 · 새 결과 집계 중**으로 구분합니다. 상단의 최신 실행 상태와 요청 현황, 카드·목록의 반영 시점이 다를 수 있습니다. 새 실행·계정으로 바꾸거나 초기화하면 이전 조건의 결과를 표시하지 않습니다.

## 숫자를 읽는 기준

| 지표 | 집계 기준 |
|---|---|
| 관측 경로 | 선택한 계정 범위에서 메서드와 쿼리를 포함한 정확한 URL로 중복 제거합니다. 여러 계정에서 관측하면 상세에 계정 목록과 대표 원본 계정을 명시합니다. |
| API·명세 항목 | API 후보, 문서 선언, 관측 여부, 명세 대조 결과입니다. API 호출 성공 수가 아닙니다. |
| 환경·DB 단서 | 환경과 DB의 탐지 근거 항목 수입니다. 고유 기술 종류나 확정된 서버 구성 수가 아닙니다. |
| 키·민감정보 후보 | 후보 결과를 중요도·상태와 함께 집계합니다. 높음/중간/낮음/정보를 한글·영문 표기와 관계없이 같은 기준으로 계산합니다. |
| 계정·권한 검토 | 계정 비교·응답 차이와 계정 관련 검토 결과입니다. 확정된 권한 취약점 수가 아닙니다. |
| 미확인·제한 항목 | 점검 범위의 미확인·제외·한도 사유와 자동 실행하지 않은 후보입니다. 실패 수와 단순 합산하지 않습니다. |

동일한 결과의 중복만 제거하며, 계정·원본·탐지 위치가 다른 결과를 같은 시크릿 지문이라는 이유로 합치지 않습니다. 카드 수와 필터를 적용하지 않은 해당 목록 수는 같은 집계 규칙을 사용합니다. 계정 정보가 없는 전역 후보는 전체 결과 계정에서 확인합니다.

전송/요청 한도는 요청 예산 사용량이며 사이트 전체 점검률이 아닙니다. 처리 수에는 실패가 포함될 수 있습니다. 중요도와 확실성·유효성은 서로 다른 정보입니다. 결과 0건이나 대기열 종료가 전체 사이트의 안전함을 의미하지 않습니다.

## 현재 실행과 원본

대시보드는 현재 통합 점검 실행만 표시합니다. 새 실행에서는 계정·중요도·선택을 초기화하고, 같은 실행의 갱신에서는 동일한 결과의 선택을 유지합니다. 프로젝트 변경과 확장 종료 시 이전 결과를 정리합니다. 원본 동작은 실행 시점에 현재 실행의 불변 원본 ID를 다시 확인합니다.

조회·필터·원본 보기·Repeater 준비·증거 추가는 대상 요청을 보내지 않습니다. Repeater의 실제 Send와 통합 점검 시작은 별도 사용자 동작입니다. 대시보드가 발견한 키를 사용하거나 유효성을 자동 검증하지 않습니다.
