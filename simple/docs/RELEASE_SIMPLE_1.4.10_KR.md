# Simple 1.4.10 · 독립 창과 압축 메뉴

Burp 자체의 상단 메뉴·탭과 하단 상태 표시줄이 Workbench의 세로 공간을 차지하던 문제를 바꿉니다. **Workbench 탭을 선택하면 독립 창**이 열리고, 그 안에서 기존 도구를 선택합니다. 처음 열 때 최대화하며, 일반 크기 조정과 F11 전체화면을 지원합니다.

[설치 JAR](../downloads/1.4.10/burp-workbench-simple-1.4.10.jar) · [소스·체크섬](../downloads/1.4.10/) · [실제 창 화면](images/1.4.10/README.md)

## 사용하는 방법

- Burp의 Workbench 탭을 선택합니다. 창을 닫은 뒤에는 같은 탭을 다시 누르거나 `Workbench 열기`를 누르면 됩니다. 열린 창이 있으면 그 창을 앞으로 가져오며 창을 중복 생성하지 않습니다.
- 일반 창에서는 운영체제의 최대화/복원 버튼과 모서리 크기 조정을 사용합니다.
- F11 또는 상단 전체화면 아이콘으로 전체화면을 전환합니다. Esc는 전체화면을 해제합니다. 기존 도구의 입력과 선택, 원본 ID를 그대로 유지합니다.
- X로 닫으면 창만 숨깁니다. 확장이 로드된 동안 수집·작업은 계속되며 다시 열면 같은 화면과 입력을 사용합니다. **창 닫기는 검사 중지가 아닙니다.** 중지가 필요하면 해당 도구의 중지 버튼을 사용합니다.
- Burp에서 요청 우클릭 등으로 Workbench 기능을 준비하면 해당 도구가 있는 별도 창을 앞으로 가져옵니다. 준비만으로 대상 요청을 추가 전송하지 않습니다.
- 확장을 로드 해제하거나 Burp를 종료하면 창과 작업 자원을 정리합니다. 창 닫기 후 유지되는 메모리 상태를 앱 재시작 후 영구 복원한다고 의미하지 않습니다.

## 상단과 메뉴

공통 상단은 **36px 한 줄**입니다. 반복되는 큰 Workbench 이름을 제거하고 현재 도구 이름만 작게 표시합니다. 전체 폴더 경로는 툴팁으로 제공합니다. 대시보드·SCOPE 점검·전체화면·도움말·설정·로그 버튼은 아이콘과 툴팁·접근성 이름으로 유지합니다. 전체화면 해제 상태에서도 줄이 늘어나지 않습니다.

왼쪽 메뉴는 폴더와 도구별 색상 아이콘, 둥근 마우스 오버 반응, 주황 선택 표시를 사용합니다. 그룹·도구 간 여백을 줄여 작은 창에서도 더 많은 메뉴를 보여줍니다. 폴더 접기, 메뉴 숨기기, Ctrl+K 찾기, 기존 Alt+1–8 도구 이동과 원래 도구 인스턴스를 유지합니다. 5개 폴더와 11개 메뉴 항목 안에 CVE 조사와 기존 도구가 모두 있습니다.

## 창 상태와 검증

전체화면은 같은 JFrame과 기존 도구 컴포넌트를 유지하는 Java의 화면 전환 기능을 사용합니다. 전체화면 전환을 위해 창을 dispose하지 않으므로 이미 열린 설정·원본·Scope 대화상자의 편집 상태와 소유 관계도 유지합니다. 창 숨김 시 함께 숨기고 다시 열 때 복원합니다.

실제 창 테스트는 Linux의 격리한 Xorg dummy/xfwm4 디스플레이에서 실제 JFrame, 운영체제 창 관리자, 키보드 입력과 픽셀 캡처를 사용합니다. Burp API와 HTTP 데이터는 합성 어댑터입니다. 사용자의 Windows Burp Community 2026.9.2 본체·DPI/IME 검증과 구분합니다. 기존 원본 Next와 모든 이전 Simple 파일을 보존하며, 내장 Mapper 0.3.11 / helper 0.4.1은 유지합니다.

검증 결과: 전체 **6,029개**, 실제 Swing **194개 화면**, 실제 창 검사 **50개**(두 테마), Katana **102개** 통과. 잘린 컨트롤과 최소 높이 미달 영역은0개입니다. [검증 JSON](VERIFICATION_SIMPLE_1.4.10.json).
