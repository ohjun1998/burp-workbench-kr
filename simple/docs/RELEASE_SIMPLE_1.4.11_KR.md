# Simple 1.4.11 · 화면 번호 가이드와 기능 정리

각 도구 화면의 오른쪽 위에 **Guide** 버튼을 추가했습니다. 클릭하거나 F1을 누르면 별도 가이드 창이 열립니다. 현재 도구·검색/CVE 탭·요청 준비/결과·재현 화면에 맞는 예시를 선택하고 **빨간 번호와 사용 단계 설명**을 함께 보여줍니다.

[설치 JAR](../downloads/1.4.11/burp-workbench-simple-1.4.11.jar) · [소스·체크섬](../downloads/1.4.11/) · [가이드·정리 검토 이미지](images/1.4.11/README.md)

## Guide 사용

1. 오른쪽 위 Guide 또는 F1을 누릅니다. 현재 작업 화면·선택 요청·편집 내용은 유지됩니다.
2. 가이드 왼쪽의 빨간 번호 또는 오른쪽 설명 카드를 누르면 대응하는 단계가 강조됩니다. 키보드 Enter/Space로도 설명을 선택할 수 있습니다.
3. 화면 맞춤/100% 보기로 확대하고, 최대화 버튼이나 F11로 가이드 창을 크게 봅니다. 원본 크기에서는 가로·세로로 스크롤합니다.
4. 상단 목록으로 다른 도구/화면의 사용 방법을 볼 수 있습니다. 목록 변경은 현재 점검 도구를 이동하거나 실행하지 않습니다.
5. Esc 또는 X로 가이드를 닫습니다. 같은 창을 다시 사용하며, Workbench가 전체화면일 때도 가이드가 그 위에 표시됩니다.

16개 화면·96개 단계에 예시 이미지를 제공합니다. 기존11개 메뉴와 대시보드/CVE 두 탭, 입력값 결과·요청 재현·계정 연결 예시를 포함합니다. 예시 화면에는 합성 데이터만 들어 있습니다. 실제 사용자 패킷·인증값을 캡처하지 않고, 가이드 열기/이미지 변경/설명 선택은 대상 요청을 전송하지 않습니다.

이미지는 JAR에 포함하며 인터넷 없이 읽습니다. 비동기 로딩, 최대3장 이미지 캐시, 이전 선택의 늦은 결과 차단과 확장 종료 정리를 적용했습니다. 공통 상단36px는 유지하고 구형 텍스트 도움말/별도 선택 창은 새 가이드로 교체했습니다.

## 이번에 실제 제거한 항목

- 구형 텍스트 도움말 아이콘·창·중복 기능 선택 화면: 새 Guide와 F1으로 교체합니다.
- Mapper 하단의 `선택 패킷 분류 수정`: 같은 동작의 상단 `분류 수정`을 사용합니다.
- 입력값 검사의 `요청 준비로 돌아가기`: 같은 동작의 번호 `1 요청 준비`를 사용합니다.
- 증거 영향·재현 절차의 빠른 서식 삽입 버튼과 전용 글자 수 줄: 일반 텍스트/Markdown 직접 편집을 사용해 입력 공간을 넓혔습니다. 초안/패킷/증거 ID와 저장 형식은 유지됩니다.
- 점검 진행 현황의 반복 카드 제목줄: 현재 도구·탭 제목을 사용하고 실제 URL 목록은 유지합니다.

## 빨간 박스 정리 검토 이미지

사용 순서 가이드의 빨간 숫자와 별도 자료입니다. 적용 전1.4.10 합성 화면에 빨간 박스/영문 표식을 넣어 도구별 정리 대상을 보여줍니다. **실선은 이번 버전 실제 삭제 반영**, **점선은 추가 검토 후보**입니다. 후보의 기능을 모두 삭제했다고 의미하지 않습니다. 각 이미지에 이유와 상태를 표시합니다.

사용 빈도를 측정한 자료는 없으므로 고유한 검사 엔진이나 암호/변환 기능을 임의로 제거하지 않았습니다. 이 버전은 중복 및 보조 기능을 우선 삭제합니다. 원본 Next와 이전 배포는 보존합니다. 내장 Mapper는 중복 버튼 수정으로0.3.12, helper는0.4.1입니다.

## 검증 범위

실제 Linux Xorg/xfwm4의 가이드 창·키보드·숫자 클릭·현재 화면 연결·최대화·Workbench 전체화면 위 표시·Esc·로드 해제 동작을 확인합니다. 합성 Burp API/HTTP 데이터를 사용하며, 실제 Windows Burp 본체·DPI/IME 검증과 구분합니다.

검증: 전체 기능6,964개(155개 그룹6,652 +payload136 +Mapper147 +Node29) 통과 후 표시 개선을 집중1,057개로 추가 확인했습니다. 최종 JAR의 실제 가이드 창50개, Swing194개 화면, Katana102개가 통과했습니다. Windows Burp GUI는 미검증입니다. [검증 범위·기록](../../../docs/reports/2026-10-31-numbered-guides/VALIDATION_SCOPE_KR.md).
