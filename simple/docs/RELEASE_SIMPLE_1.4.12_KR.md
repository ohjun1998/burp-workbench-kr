# Simple 1.4.12 · 작업 영역에 맞춘 버튼 배치

승인한 버튼 배치 시안을 13개 화면에 적용했습니다. 넓은 창에서는 대상·설정과 검색·작업을 조밀하게 배치하고, 작은 창에서는 작업 줄을 재배치합니다. 실행·중지는 함께 두고, 선택 항목의 작업은 해당 목록이나 상세 제목줄로 옮겼습니다. 이전 버전의 원본 데이터·저장 형식·명시적 실행 흐름과 Guide는 유지합니다.

[설치 JAR](../downloads/1.4.12/burp-workbench-simple-1.4.12.jar) · [소스·체크섬](../downloads/1.4.12/) · [실제 화면·검증](https://github.com/ohjun1998/burp-workbench-kr/blob/main/docs/reports/2026-10-31-contextual-button-layout/README.md)

## 화면별 변경

| 화면 | 배치 |
|---|---|
| 요청·응답 목록 | 설정 메뉴 하나에서 수집 설정과 검색·목록 설정을 엽니다. 검색 옆에는 선택 건수·Repeater·증거 추가·계정 비교 준비를 모았습니다. |
| 기능 자동 매핑 | 프로젝트·수집 설정은 상단, 기능 편집·업무 연결은 트리 위, 분류 수정·Repeater는 패킷 목록 옆에 둡니다. |
| JS에서 API 찾기 | 소스·검색은 상단, 원본 위치·Repeater 준비·선택 API 도구는 경로 상세 제목줄로 옮겼습니다. |
| 서버·경로 탐색 | 대상·계정과 후보 작업을 구분합니다. 단일·일괄 GET 확인과 일시정지·중지를 함께 표시합니다. |
| 검색 노출 조사 | 검색식 옆에 복사·Google 열기, URL 목록 위에 가져오기, 선택 URL 상세 위에 근거 복사·Repeater 준비를 둡니다. |
| CVE 후보 | 관측 제품·조회·취소는 한 작업 줄, 필터는 표 위, 출처·근거 복사는 선택 CVE 상세 위에 둡니다. 캐시는 더보기에서 엽니다. |
| 계정 권한 비교 | 계정 설정은 요약 옆, 비교·중지는 기록 목록 위에 둡니다. 계정 카드는 이름·이메일·역할을 유지하면서 높이를 줄였습니다. |
| 응답 보안 분석 | 관찰을 증거로 추가하는 버튼을 선택 관찰 상세 옆으로 옮겼습니다. API·저장 흐름 작업은 해당 탭과 상세에 둡니다. |
| 입력값 보안 검사 | 설정·검사 시작·중지는 상단에 고정합니다. 입력 위치·정렬은 요청 편집기 위, 증거·Repeater는 실행·결과 단계에만 표시합니다. |
| 데이터 변환·비교 | 변환 방식·변환은 입력 위, 출력→입력·복사는 출력 위에 둡니다. 데이터 비교의 가져오기는 입력별로, 편집·차이 이동·증거는 결과 영역에 둡니다. |
| 점검 진행 현황 | URL 완료는 URL 목록, 입력 완료는 선택 URL 입력 목록에 둡니다. 근거·Repeater는 선택 URL 상세에 모았습니다. |
| 재현·증거 정리 | 문서 미리보기·ZIP 저장은 상단, 증거 추가는 목록 위, 이동·삭제·되돌리기·메모는 목록 안에 둡니다. |
| 점검 대시보드 | 반복 대제목·정보 줄을 압축했습니다. 원본·Repeater·증거 버튼을 선택 결과 상세 위로 옮겼고, 통합 점검 열기는 화면 이동으로 유지합니다. |

## 유지한 동작

- 버튼 이동이나 선택·탭 변경만으로 대상 요청이나 CVE 조회를 시작하지 않습니다.
- 실행·중지/취소를 인접 배치하고, 선택이 없는 작업은 같은 위치에서 비활성화합니다.
- Repeater 준비는 실제 전송과 구분하며, Scope·계정·예산·취소·프로젝트 종료 검사를 유지합니다.
- 요청 원문·선택 원본 ID·작성 중인 증거·변환 입력과 도구 인스턴스를 유지합니다.
- 계정 카드의 전체 설명은 접근성 이름과 툴팁에서도 확인할 수 있습니다.

실제 창 검증에서 발견한 기존 테마 재적용 반복도 수정했습니다. Workbench는 내장 도구의 내부 스타일 감시를 해당 도구에 맡기고, Mapper는 같은 버튼 UI를 반복 교체하지 않습니다. 호스트가 UI를 바꿨을 때의 복원은 유지합니다. 이 경계와 반복 적용의 종료를 별도 회귀 검사로 확인합니다.

## Guide와 배포

오른쪽 위 Guide/F1은 유지합니다. 16개 화면의 밝음·어두움 예시 32장과 빨간 번호 96개의 위치·설명을 새 배치에 맞춰 갱신했습니다. 예시는 합성 데이터이며 사용자 패킷을 캡처하지 않습니다. 두 테마에서 번호 중심이 해당 화면 영역에 있는지 192건 확인했습니다.

내장 Mapper는 0.3.13, 브라우저 helper는 0.4.1입니다. 원본 Next와 이전 버전 JAR·소스 ZIP은 보존합니다. 상세 검증과 실제 캡처 범위는 위 보고서에 기록합니다. 실제 Linux Swing/격리 창 관리자와 합성 Burp API 검증을 Windows Burp 본체·DPI/IME 검증과 구분합니다.
