# Simple 1.4.13 · Apple 디자인 언어를 참고한 라이트·다크

승인한 독립 디자인 시안의 실버·화이트, 중립 그래파이트, 파란 선택 강조를 실제 Workbench 공통 컴포넌트에 적용합니다. macOS의 정돈된 화면 구성을 참고한 Swing 구현이며 Apple 공식 테마나 운영체제의 투명·블러 효과를 사용하는 제품은 아닙니다.

- 메뉴: 은은한 배경 변화, 파란 그룹 아이콘, 중립 도구 아이콘, 선택·마우스 반응과 키보드 포커스.
- 작업 영역: 중립 바탕과 선명한 본문, 얇은 구분선, 둥근 입력·버튼 테두리, 작은 버튼·제목줄 여백.
- 표: 가로 구분선 중심으로 정리하고 파란 선택 행과 상태·메서드 구분을 유지.
- 주요 실행: 평평한 파란 버튼. 어두운 모드에서도 흰색 버튼 글자 대비를 확보.
- 기능 자동 매핑, 계정 카드, 단계 탭, 데이터 도구, 검색 노출·CVE 조사, 점검 현황·증거·Scope 창에서도 같은 색상 체계 사용.
- Guide: 16개 화면의 라이트·다크 예시 32장을 새 디자인으로 갱신하고 빨간 번호 96개의 위치를 확인.

36px 상단, Guide/F1, 독립 창·최대화·전체화면, 기존 버튼 기능과 배치를 유지합니다. 사용자 요청 원문·입력·선택 ID·계정·SCOPE·취소·저장 방식은 바꾸지 않습니다. 화면 선택·테마 적용만으로 요청을 보내거나 CVE를 조회하지 않습니다. Burp 전체 UI 기본값을 변경하지 않는 로컬 테마입니다.

내장 Mapper는 0.3.14, 브라우저 helper는 0.4.1입니다. 기존 버전과 원본 Next 소스는 보존합니다.
