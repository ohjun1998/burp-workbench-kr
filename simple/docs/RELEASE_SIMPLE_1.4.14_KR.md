# Simple 1.4.14 · 작업 공간과 버튼 배치 정리

16개 화면을 검토하고 Apple 스타일의 라이트·다크 테마를 유지하면서 사용 공간과 버튼 위치를 개선했습니다.

- 계정 연결: 왼쪽 고정 라벨과 넓은 입력란으로 정렬해 오른쪽 쏠림을 없앴습니다.
- 대시보드: 상단 요약·차트 높이를 유지하고 남는 높이를 결과 목록·상세에 배분합니다. 작은 창에서는 세로 스크롤을 유지합니다.
- 점검 현황: 검색란을 넓히고 URL·출처 열에 실제 너비를 적용했습니다. 긴 표는 가로 스크롤로 읽습니다.
- 요청 재현: 요청 추가는 요청 편집기 위, 실행·중지는 오른쪽 실행줄, 결과→증거는 결과 목록 위에 놓았습니다.
- 증거 정리: 순서·삭제·되돌리기·메모 작업을 목록 바로 위에 모았습니다.
- 트래픽: 화면 고정·새 트래픽 버튼을 상단 설정 옆에 모으고 하단 상태줄을 줄였습니다.
- 권한 비교: 검색 안내를 추가하고 검색란을 남는 너비만큼 확장했습니다.
- 입력값 검사: 단계줄을54px에서40px로, 문맥 요약 여백을10px에서4px로 줄였습니다.
- 빈 표 안내: 가로 스크롤 여부와 관계없이 실제 보이는 영역의 가운데에 표시합니다.
- 공통 도구막대: 중첩 여백과 불필요한 세로 확장을 줄이고 좁은 창의 줄바꿈을 유지합니다.
- Guide: 실제 배치로 16개 화면/32장과 96개 빨간 번호의 위치·설명을 갱신했습니다.

기능 자동 매핑·JS·서버 탐색·외부 노출/CVE·응답 분석·데이터 변환을 포함한 전체16개 화면을 다시 캡처했습니다. Mapper는 빈 표 안내의 보이는 영역 정렬을 함께 수정하여0.3.15, helper0.4.1을 유지합니다. 기존 패키지와 원본 Next 소스는 보존합니다.
