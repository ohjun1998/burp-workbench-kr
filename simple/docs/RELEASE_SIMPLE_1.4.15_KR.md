# Simple 1.4.15 · 주요 버튼 실제 재배치

1.4.14는 작업 영역 간 버튼 이동이3개 화면에 그쳐 전반적인 재배치 요청에 부족했습니다. 설치된1.4.14에서 주요 버튼이 그대로라는 지적을 확인하고, 이번 버전은 실제 버튼 부모 영역을 변경합니다.

검색·필터는 목록 위에, 선택 항목 작업은 해당 목록/상세 아래에 고정합니다. 실행·중지를 함께 유지하고 입력·결과 단계에서도 보존합니다. 화면 이동·리사이즈·선택은 자동 요청을 보내지 않습니다. 버튼 핸들러·원본 ID·입력·선택·실행 조건은 유지합니다.

트래픽의Repeater/증거/계정비교, Mapper 분류수정/Repeater, JS 선택결과, 서버탐색 실행, 검색노출 선택작업, CVE 조회/출처, 계정비교 실행, 응답분석 선택작업, 페이로드 준비/실행/결과, 데이터변환, 점검완료, 증거문서 저장, 대시보드 근거 작업을 옮깁니다. 요청재현과 인증후보 연결은 이전에 정리한 배치를 유지합니다. 실제 변경 범위는 전후 캡처와좌표로 확인합니다.

Simple1.4.15/Mapper0.3.16/helper0.4.1. Apple 라이트·다크와36px 공통상단/Guide/독립창/전체화면을 유지합니다. 이전 버전 패키지와 원본Next는 보존합니다.
