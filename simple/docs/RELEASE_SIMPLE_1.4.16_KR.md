# Simple 1.4.16 · 승인한 작업 흐름 적용

승인한 [16개 화면 설계](../../docs/reports/2026-10-31-workflow-design/README.md)를 실제 Swing 확장에 적용했습니다. 각 도구의 진행 순서에 따라 주 작업·보조 메뉴·접힌 설정·원문 영역을 구성합니다.

- **트래픽·Mapper:** 선택 요청 확인과 Repeater 준비, 기능 분류 수정을 중심에 둡니다. 수집·프로젝트·기능·선택 요청 작업은 범위별 메뉴로 묶었습니다.
- **JS·응답 분석·서버 탐색:** 결과 목록과 선택 원문을 나란히 배치했습니다. 반복 사실 정보는 접고, 선택 GET·일시정지·중지는 원문 옆에 유지합니다.
- **계정 비교:** 큰 신원 카드를 42px 역할 요약으로 줄이고 응답 비교 영역을 넓혔습니다. 전체 신원은 툴팁과 계정 설정에서 확인할 수 있습니다. 추가 계정은 접고 후보 선택의 즉시 연결 동작은 유지합니다.
- **입력값 검사:** 중첩된 준비 탭을 요청 편집기와 실제 조건 사이드바로 바꿨습니다. 검사 위치·한도·SCOPE를 표시하고 후보와 고급 조건을 접었습니다. 시작·중지는 두 단계에서 함께 표시하며 결과에서는 증거 연결을 강조합니다.
- **검색 노출·CVE:** 목록 옆에서 선택 근거를 읽습니다. 관측 제품은 한 번 표시하고 필터는 접었습니다. CVE 상세는 적용 조건과 관측 근거 탭으로 정리했습니다.
- **데이터·현황:** 변환 작업은 입출력 공통 줄에, 출력 재사용은 출력 메뉴에 배치했습니다. 현황은 핵심 URL 목록과 선택 상세·입력 점검으로 구성했습니다.
- **증거·재현·대시보드:** 증거 목록·영향 및 재현 작성·원문을 3열로 구성하고 문서 작업과 항목 편집을 구분했습니다. 재현 변수와 대시보드의 중복 분포는 접었습니다.
- **공통 패킷·Guide:** Pretty·Raw를 카드 헤더에 합쳤습니다. Hex·Render·복사·검색·기본 편집기는 원문 도구에서 열며 Ctrl+F도 지원합니다. Guide 16개 화면·96단계의 설명과 이미지를 새 배치로 갱신했습니다.

기존 원본 ID·바이트·작성 내용·정렬 및 선택·계정·SCOPE·취소·저장·종료 동작을 유지합니다. 메뉴는 원래 컨트롤의 처리와 활성 상태를 연결합니다. 화면 이동이나 접힘을 여는 동작으로 대상 요청이나 외부 조회를 시작하지 않습니다.

배포 구성은 Simple **1.4.16**, Mapper **0.3.17**, browser helper **0.4.1**입니다. 기존 패키지와 원본 Next 소스는 보존합니다.

캡처는 합성 데이터를 넣은 실제 Swing 컴포넌트입니다. 사용자의 Windows Burp 본체·DPI·IME 검증은 포함하지 않습니다. 구현의 배치와 흐름을 적용한 결과이며 HTML 시안과의 픽셀 일치를 뜻하지 않습니다. 완료한 검사와 남은 한계는 검증 보고서에 기록합니다.
