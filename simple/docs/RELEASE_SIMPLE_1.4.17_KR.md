# Simple 1.4.17 · 승인 PDF 배치 적용 보완

Simple1.4.16에서 승인된16개 화면 시안과 달랐던 공통 화면·결과·작성 영역을 다시 적용했습니다. 중단 당시1.4.17 소스가 원격에 없어 보존된1.4.16 작업 브랜치와 원본 `workbench-ux-flow-design.pdf`를 기준으로 이어서 구현했습니다. 기존 배포 파일은 변경하지 않습니다.

[설치 JAR](../downloads/1.4.17/burp-workbench-simple-1.4.17.jar) · [독립 소스 ZIP](../downloads/1.4.17/burp-workbench-simple-1.4.17-source.zip) · [시안과 실제 화면 대조](../../docs/reports/2026-10-31-pdf-alignment/1.4.17/ALIGNMENT_KR.md) · [이번 검증 기록](../../docs/reports/2026-10-31-pdf-alignment/1.4.17/VERIFICATION.json)

## 바뀐 화면

- 공통 화면: 기본190px 메뉴(작은 창174px),46px Workbench 브랜드·경로 헤더, 카드 표면과 선택 탭을 시안 기준으로 정리했습니다. 대시보드를 실제 메뉴 항목으로 추가했습니다. 사용자가 따로 저장한 메뉴 폭과 기존 설정·Guide·전체화면·로그 동작은 유지합니다.
- 입력값 검사 결과: 결과를 증거로·Repeater·검사 관리·중지를 상단에 두고, 전체/관찰/기준·대조 필터와 응답 시간 열을 표시합니다. 초기 기준 요청이401/403/429/503으로 끝난 경우와 출력 대조의 일치·미완료도 기준·대조로 구분합니다. 필터·정렬 후 원본과 전체 증거 묶음은 유지합니다.
- 증거 정리·재현: 목록/보고서 작성/원문 대조의3열과 보고서 카드 안의 실제 영향·재현 절차를 정리했습니다. 요청·응답 탭과 접힌 원본 정보를 보존합니다. 재현은 요청 준비와 실제 선택 결과를 구분합니다.
- 인증: 역할별 후보·연결 상태를 같은 행에 표시하고 Origin 반복을 줄였습니다. 실제 준비 창의 적용 상태/계정·쓰기 조회/세션·권한표3탭을 모두 유지하며, 첫 탭과 탭 재진입의 실제 내용·스타일도 확인합니다.
- 탐색·분석: JS 경로의 메서드·경로·호출 상태·호출 위치를 함께 보여주고 변경 정보는 상세에 보존합니다. 서버·경로에는 실제 계정의 응답 상태를 사용하는 빠른 필터를 추가했습니다. 검색·CVE의 사실표·근거·출처, 응답의 원문 대조 영역을 정리했습니다.
- 변환·진행·대시보드: 입력/출력 카드와 변환 방식, 검색·필터·완료 동작, 선택 결과의 사실·근거·원본 정보를 각 작업 영역에 배치했습니다. 작은 창에서는 읽기 영역을 줄여 숨기지 않고 스크롤로 접근합니다.

화면을 열거나 필터·역할·설정을 바꾸는 동작은 대상 요청이나 외부 조회를 자동 실행하지 않습니다. 요청·응답 원문 바이트와 불변 원본ID, 작성 중인 내용, 취소·Scope·계정·수명주기 경계를 유지합니다. 내장 Mapper는0.3.18, 브라우저 helper는0.4.1입니다.

## 설치와 확인

기존 JAR와 프로젝트를 보관하고 이전 Simple의 로드를 해제한 뒤 Burp의 Extensions → Add → Java에서1.4.17 JAR를 선택합니다. 기존 Simple 저장 공간을 이어서 사용하며 새 비교를 자동 시작하지 않습니다. 먼저 입력값 검사 결과의 필터/응답 시간, 증거의 보고서 작성 카드, 인증 준비 창 전체3탭을 확인할 수 있습니다.

비교 자료에는 합성 원본을 넣은 운영 Swing 화면과 시안을 나란히 제공합니다. 인증 후보 연결 부분만 잘라 전체 준비 창과 같다고 설명하지 않으며, 실제 데이터·추가 기능 때문에 유지한 차이를 구분합니다. 실제 Windows Burp GUI·DPI/IME 검증은 자동 Swing·Linux 창 검사와 별도입니다.

## 개발 검사

Python3.10+, 완전한 JDK17+, Node22+에서 저장소 루트의 `python simple/dev.py check`와 `python simple/dev.py verify`를 사용합니다. 기본 `--release 17`을 유지합니다. 화면 검사는 `simple/tools/render_simple.py`, `simple/tools/render_scope_inspection.py`에 별도 `--out`을 지정하고, Linux 실제 창 검사는 Xorg dummy/xfwm4가 있는 격리 환경에서 `bash simple/tools/run_pdf_alignment_native.sh all`로 실행합니다. 이전 버전의 이미지·배포 파일을 덮어쓰지 않습니다.
