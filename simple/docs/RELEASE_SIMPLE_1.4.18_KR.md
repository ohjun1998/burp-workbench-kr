# Workbench Simple 1.4.18 변경 안내

요청·응답 목록의 승인 시안 적용 예시를 나머지 도구로 확장했습니다. 승인 원본은 `docs/reports/2026-10-31-workflow-design/`의 16개 화면입니다. Mapper는 0.3.19, 브라우저 도우미는 0.4.1입니다.

- 공통 46px 헤더·190px 메뉴와 화면별 버튼, 탭, 카드, 목록 열을 맞췄습니다.
- 매핑 원문에도 실제 Pretty/Raw·검색·복사 도구를 연결했습니다. 원본 패킷은 포맷된 표시와 별도로 보존합니다.
- 계정 카드는 승인 시안의 간단한 연결창을 엽니다. 인증 후보 관리에서 적용 상태·계정/쓰기 조회·세션/권한표의 기존 3탭을 계속 사용합니다. 추가 계정을 펼치면 창 높이도 늘어납니다.
- JS 목록 필터와 원문 위치 탐색, 환경의 원문 표시 방식, CVE의 상세 조건은 화면의 실제 메뉴에서 열 수 있습니다.
- 입력값 검사 결과의 응답 시간과 필터, 증거 작성의 영향·재현 절차와 원문 대조, 대시보드의 실제 집계·선택 근거를 유지합니다.
- 계정 연결창을 연속 재호출하거나 닫을 때 배경 클릭 차단을 즉시 복원합니다. 일반 닫기·Esc·추가 계정 펼침과 기존 창 숨김 동작도 유지합니다.
- 표 열을 조절한 뒤 재실행하거나 프로젝트를 바꿔도 해당 프로젝트의 열 순서·너비를 복원합니다. 메모 표시 여부는 원래 검색 설정이 결정합니다.

설치할 때 기존 Simple을 언로드한 후 1.4.18 JAR을 등록합니다. 이전 버전 배포 파일은 덮어쓰지 않습니다. 이번 변경은 점검·비교·외부 조회를 자동 실행하지 않습니다.

검증과 원본 해상도 화면은 [실행 보고서](../../docs/reports/2026-10-31-all-tools-approved/1.4.18/REPORT_KR.md)에 제공합니다. 실제 운영 Swing 컴포넌트에 합성 Burp 어댑터를 연결하고 Linux 창에서 캡처합니다. 승인 이미지와 합성 데이터·결과 건수는 다르며, Java와 브라우저의 글자 렌더링까지 픽셀 차이 0으로 검증했다는 의미는 아닙니다. Windows Burp 본체에서의 확인은 별도입니다.

개발 환경에서는 JDK 17과 Python, Node를 준비하고 `python simple/dev.py check`를 실행합니다. 실제 창 캡처는 `simple/tools/run_approved_all_native.sh`, 독립 소스 검증과 패키징은 `python simple/dev.py release`를 사용합니다.
