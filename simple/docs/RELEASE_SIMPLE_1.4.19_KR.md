# Workbench Simple 1.4.19 변경 안내

1.4.18에서는 상단 달 모양 버튼이 설정·창 도구 메뉴를 열었고, 아이콘 전용 원본 버튼의 빈 제목이 복사되어 `Guide` 위에 빈 메뉴 행들이 나타났습니다.

Simple1.4.19에는 공통 테마 전환을 지원하는 Mapper0.3.20과 기존 브라우저 도우미0.4.1이 포함됩니다.

- 달 모양 버튼은 Workbench의 라이트·다크 테마를 즉시 전환합니다. Burp 전체의 테마 설정을 변경하지 않습니다.
- 설정·전체 화면·오류 기록 등 기존 도구는 별도 톱니 메뉴에서 선택합니다. 각 항목의 이름과 아이콘, 선택·활성 상태, 전체 화면 상태에 따른 이름 변경을 유지합니다.
- 오른쪽 `화면 설명`과 메뉴의 `Guide`는 기존 화면별 설명 창을 엽니다.
- 테마 변경과 메뉴 조회는 대상 HTTP 요청을 보내지 않습니다. 기존 입력·선택·원본·검사 엔진을 계속 사용합니다.

기존 Simple을 언로드한 뒤 [1.4.19 JAR](../downloads/1.4.19/burp-workbench-simple-1.4.19.jar)을 등록합니다. 이전 버전의 JAR과 소스 ZIP은 보존합니다.

실제 실행 화면, 회귀 검사, 패키지 검증 결과와 검증 범위는 [실행 보고서](../../docs/reports/2026-11-01-header-tools/REPORT_KR.md)에 기록합니다. Linux의 실제 Swing 창에 합성 Burp API 어댑터를 연결하여 확인하며, Windows Burp 본체에서의 검증과 구분합니다.

독립 소스 ZIP은 JDK17에서 `python dev.py check`로 검사하고 `python dev.py build`로 빌드합니다.
