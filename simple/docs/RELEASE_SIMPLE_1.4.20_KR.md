# Workbench Simple 1.4.20 변경 안내

1.4.19의 전체 화면을 승인한 16개 시안과 다시 비교했습니다. 큰 카드의 위치 외에 입력 컨트롤·카드 내부 구성에도 남아 있던 차이를 수정합니다. Mapper는0.3.21, 브라우저 도우미는0.4.1입니다.

- 검사 조건의 선택 상자·숫자 입력을 31px 단일 둥근 테두리와 왼쪽 정렬로 표시합니다. 시안에 없는 숫자 증감 화살표는 숨기고, 기존 숫자 모델·범위·직접 입력·키보드 증감을 유지합니다.
- 검사 위치·단위·현재 조건 요약, 중립 결과 안내, 카드 제목의 여백과 구분선, 접힌 설정의 높이·표시를 보완합니다. 실제 요청 한도·간격·검사 종류 등 사용자의 값을 시안 예제로 덮어쓰지 않습니다.
- 인증 연결창의 역할 배지·비로그인 선택·추가 계정·배경과 인증·환경 화면의 제목·상태·필터 표현을 맞춥니다. 연결·해제와 관리의 기존3탭을 유지합니다.
- 매핑·JS·응답 분석·데이터 변환·외부 노출·CVE·점검 현황·증거·재현·대시보드의 내부 간격, 잘린 필터, 안내·상태·원문 도구를 보완합니다. 표시를 줄인 기존 작업은 실제 메뉴에서 원래 컨트롤러를 호출합니다.
- 기존 일반 입력칸의 글자 크기와 150% 배율을 유지하고, 카드·검색 헤더를 다시 구성해도 이전 프로젝트의 사용자 열 너비·순서를 복원합니다. 재현 결과의 증거 작업 버튼이 좁은 작업 줄에서 1px 잘리던 문제도 수정했습니다.
- 라이트·다크 전환과 설정·창 도구 메뉴는1.4.19의 수정 동작을 유지합니다. Burp 전체의 UI 기본값을 바꾸지 않습니다.

기존 Simple을 언로드한 뒤 새1.4.20 JAR을 등록합니다. 이전 배포 파일은 보존합니다. 원본 요청 ID·바이트, 작성 문서·실행 조건·필터·프로젝트별 수동 열 너비와 명시적 실행·SCOPE·중지·종료 처리를 유지합니다.

[실행 보고서](../../docs/reports/2026-11-01-approved-review/REPORT_KR.md)에 승인 원본,1.4.19 원본, 수정 후 실제 화면과 검증을 제공합니다. Linux의 실제 Swing 창과 합성 Burp API 어댑터를 사용하며, Metal·Nimbus의 기본 UI 간섭도 확인합니다. 실제 Windows Burp·DPI/IME 검증 또는 글자 렌더링을 포함한 화면 전체의 픽셀 차이0 검증을 뜻하지 않습니다. 화면의 대상·데이터·건수·시간·연결·실행 상태는 실제 모델을 따릅니다.

독립 소스 ZIP은 JDK17에서 `python dev.py check`, `python dev.py build`로 검사·빌드합니다.
