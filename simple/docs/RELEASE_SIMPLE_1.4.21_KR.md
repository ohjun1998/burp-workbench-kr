# Workbench Simple 1.4.21 · 통합 점검과 대시보드 빠른 메뉴

승인한 C안의 컴팩트 강조형을 왼쪽 최상단에 적용했습니다. 통합 점검과 대시보드를 각각 한 줄로 배치하고, 얇은 테두리·왼쪽 포인트·아이콘과 화살표로 일반 도구 목록과 구별합니다. 라이트·다크에서 같은 구조를 사용합니다.

- **통합 점검**은 기존 SCOPE·계정·실행 조건을 준비하는 창을 엽니다. 이미 열려 있으면 해당 창을 앞으로 가져오고, 작성 중인 조건을 유지합니다. 실제 점검은 준비 화면의 시작 동작으로 실행합니다.
- **대시보드**는 현재 통합 점검의 결과·목록·근거를 확인하는 기존 화면으로 이동합니다. 하단 그룹의 중복 항목은 위로 옮겼으며 원래 도구 메뉴와 단축 탐색도 유지합니다.
- 두 항목은 아래 도구 목록을 스크롤해도 상단에 고정됩니다. 메뉴 숨김·다시 보기, 기존 사이드바 너비, 뒤로·앞으로와 현재 대시보드 선택 상태를 유지합니다.
- 입력 문서·원본 ID/바이트·실행 중인 점검·현재 결과와 계정·SCOPE 조건을 다시 만들거나 예제 값으로 덮어쓰지 않습니다. 두 메뉴를 누르는 동작만으로 요청을 전송하지 않습니다.

기존 Simple 1.4.20을 언로드한 뒤 [1.4.21 JAR](../downloads/1.4.21/burp-workbench-simple-1.4.21.jar)을 등록합니다. 이전 배포물은 보존하며, Mapper0.3.21과 브라우저 도우미0.4.1은 유지합니다.

전체 기본 프로필은 Java 178개 그룹 7,789개, payload HTTP 136개, Mapper Java 147개, Node 29개로 **8,101개 통과**했습니다. 상단 메뉴는 두 테마 × 네 창 크기에서 실제 마우스·Tab·Space·Enter·뒤로/앞으로·숨김/복원·스크롤을 **808개 검사**하고 원본 PNG 48장을 보존했습니다. 두 축의 검사는 겹치므로 합산하지 않습니다.

실제 창·좁은 창·테마·키보드 동작과 전체 검사 결과는 [실행 보고서](../../docs/reports/2026-11-01-compact-primary-navigation/REPORT_KR.md)에서 확인합니다. 실제 Linux Swing 창과 합성 Burp API 어댑터를 사용하며 Windows Burp 본체·DPI/IME 검증과 구분합니다.
