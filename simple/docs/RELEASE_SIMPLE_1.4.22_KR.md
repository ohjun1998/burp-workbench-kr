# Workbench Simple 1.4.22 · URL 결과 목록 A 그룹형

승인한 A 그룹형을 Simple의 URL·경로 중심 결과 목록에 적용했습니다. 반복되는 긴 경로 대신 짧은 표시명과 건수를 보여주고, 업무·계정·문서 탐색·환경·입력 변형 등을 접이식 그룹으로 살펴볼 수 있습니다. URL의 정확한 값과 원본 연결은 선택 상세에서 확인합니다.

| 도구 | 표시가 바뀌는 목록 |
|---|---|
| 통합 점검·대시보드 | 경로·응답과 API·명세·환경·DB 등의 결과 목록 |
| 요청·응답 | 기존 그룹 탐색을 이용한 업무별 요청 목록 |
| 기능 자동 매핑 | 짧은 기능명·연결된 요청 수와 업무별 그룹 |
| JS에서 API 찾기 | 발견 경로·분석 이력·관련 URL 목록 |
| 서버·경로 탐색 | 후보 경로와 검사 이력 |
| 외부 노출·CVE 조사 | 외부 노출 URL 결과 목록 |
| 계정 권한 비교 | 요청별 비교 이력 |
| 응답 보안 분석 | 관찰 결과·API 문서·저장/조회 연결 |
| 점검 진행 현황 | URL 점검 현황과 미확정 경로 |
| 재현·증거 정리 | 재현 단계·증거와 관련 URL 목록 |

요청·응답 목록은 **수집 설정 → A 그룹형으로 보기**에서 전환합니다. 대량 트래픽을 처리하는 기존 백그라운드 인덱스와 그룹 접기 기능을 사용하며, 저장한 그룹 선택도 유지합니다. 다른 URL 결과 목록은 그룹을 선택해 기존 표의 해당 결과를 보고, 선택 상세의 원본 정보에서 정확한 URL을 확인합니다. 보조 URL 후보 수집 목록에도 같은 표시를 적용했습니다.

입력값 보안 검사의 실제 검사값과 데이터 변환·비교의 JSON 필드 경로는 결과 자체의 의미를 전달하는 값입니다. 이 값들과 URL 입력란, 편집 중인 내용, 요청·응답 Raw는 원래 값을 표시합니다. CVE ID·계정 식별 정보·입력 이름 등의 비 URL 목록도 각 도구의 의미를 유지합니다.

표시를 바꾸기 위해 원래 TableModel 값이나 원본 기능·패킷 ID, URL, 요청/응답 바이트를 바꾸지 않습니다. 검색·계정·중요도 필터, 선택 상세와 명시적인 Repeater·검사·증거·업무 연결 동작은 기존 데이터에 연결됩니다. 그룹 탐색과 접기·펼치기만으로 요청을 전송하지 않습니다. Mapper에서 사용자가 편집한 기능명과 점검 상태도 보존합니다.

짧은 표시명과 상위 그룹은 탐색을 돕는 표시입니다. 정상 기능이나 취약점이 확인됐다는 뜻이 아니며, 미확정 경로·입력 변형·대조 경로의 개별 관측도 원본과 연결된 채로 구분됩니다.

구성은 **Simple 1.4.22 · Mapper 0.3.22 · 브라우저 도우미 0.4.1**입니다. 기존 확장을 언로드한 뒤 [1.4.22 JAR](../downloads/1.4.22/burp-workbench-simple-1.4.22.jar)을 등록합니다. 이전 배포 파일과 은행 테스트의 원래 결과 HTML은 보존합니다.

현재 소스로 실행한 검사와 실제 창 캡처는 [실행 보고서](../../docs/reports/2026-11-01-grouped-results/REPORT_KR.md)에 기록합니다. Linux Swing 창의 합성 Burp API 어댑터 검증은 Windows Burp 본체·DPI/IME 검증과 구분합니다.
