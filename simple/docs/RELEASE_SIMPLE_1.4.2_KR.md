# Workbench Simple 1.4.2 · 반복 작업과 복구 개선

대상·계정을 바꾸고 원본을 읽고 오류를 고치는 실제 작업을 기준으로 다듬습니다. 기존 8개 도구와 통합 점검·대시보드, Mapper0.3.6·helper0.4.1·Katana1.8.0을 유지합니다.

서버·경로의 **대상과 계정은 기본 화면에서 선택**합니다. 이미 관찰한 다른 대상과 준비한 비교 계정으로 경로를 확인할 때 대상 설정·후보 설정 창을 각각 열 필요가 없습니다. 요청 간격·타임아웃·예산·기준 응답 비교·동적 필드 제외·후속 탐색은 기존 후보 설정에서, 저장·불러오기·이력·초기화는 더보기에서 관리합니다. 대상·계정 선택만으로 요청을 전송하지 않으며 GET 확인은 직접 실행합니다. 실행 중에는 두 선택기를 잠급니다. 로그인 계정의 Origin·세션 확인과 요청 예산은 기존대로 적용합니다.

서버·경로에서 **다른 응답을 수신해도 같은 원본의 읽기·복사 위치를 유지**합니다. 같은 관측은 표를 다시 만들거나 패킷을 반복 정렬하지 않습니다. 바뀐 표만 한 번에 반영하고 정렬·열 배치·선택 URL을 유지합니다. 계정·원본·표시 모드·저장 판정이 바뀌면 올바른 내용을 새로 표시합니다. EDT 할당량은 해당 작업에서 새로 할당한 바이트이며 전체 힙·RSS 측정값은 아닙니다.

URL 후보 수집의 대상 준비에서 **오류를 입력 창 안에 표시**합니다. 잘못된 도메인이나 8개 대상 상한을 확인하고 같은 창에서 고쳐 다시 시도합니다. 입력 뒤 Enter는 기존 대상 열기 버튼과 같은 준비 동작이며 수집이나 GET을 자동 실행하지 않습니다. 아직 적용하지 않은 입력은 현재 대상·원본을 바꾸지 않습니다. 종료 뒤 남아 있던 버튼·Enter·메뉴 동작이 대상 탭을 다시 만들지 않도록 처리합니다.

트래픽 검색은 **조건 준비 중인 상태도 진행 중으로 판단**합니다. 이전 결과를 완료된 새 결과처럼 사용하는 경합을 줄입니다. 검색 조건·원본 선택 기준을 완화하지 않으며 입력 오류·취소·프로젝트 전환·종료 뒤에는 기존 복구 절차를 유지합니다.

사용자가 선택한 저장소의 로컬 실습 환경을 사용합니다. 운영 Swing·Montoya 어댑터와 실제 loopback HTTP를 구분해 기록하며 실제 Burp GUI·OS 클릭·파일 선택기·브라우저 DOM·Windows DPI/IME 검증으로 표현하지 않습니다. 조작 수는 하네스가 호출한 필수 컨트롤 동작이며 선택적인 창 닫기나 사람의 작업 시간을 추정해 더하지 않습니다. 시간과 할당량은 동일 fixture의 로컬 합성 부하 진단값입니다. 최종 전체 회귀·패키지 검증과 PR 결과는 보고서의 실제 완료 근거를 따릅니다.
