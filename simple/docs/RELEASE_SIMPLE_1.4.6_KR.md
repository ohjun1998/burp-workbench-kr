# Workbench Simple 1.4.6 · 승인 시안 기준 재배치

1.4.5는 큰 본문 제목 제거와 일부 패널 분할을 적용했지만, 사용자가 승인한 이미지의 상단 바·아이콘·정보 배치와 달랐습니다. 1.4.6은 해당 8개 시안을 기준으로 공통 화면과 도구별 작업 영역을 다시 구성합니다. 이전 1.4.5의 “시안 적용 완료” 설명을 시각적 일치의 근거로 사용하지 않습니다.

큰 도구 이름·소개 문구를 본문에 반복하지 않습니다. 생성 시안의 임의 데이터·숫자·판정 문구를 제품 데이터로 넣지 않았습니다. HTTP 본문, 표의 건수, 연결 계정은 실제 선택 모델을 사용합니다. 표와 패킷의 분할 폭·높이는 조절할 수 있고 기존 개인화 설정은 유지합니다. 이전 설정을 저장했다면 화면 설정에서 배치 초기화 후 새 기본값을 확인할 수 있습니다.

## 기존 기능 접근

8개 도구와 원본 ID·인증 계정·SCOPE·요청 한도·명시적 실행 경계는 유지합니다. 대시보드는 오른쪽 상단, SCOPE 통합 점검은 바로 옆 원형 아이콘에서 엽니다. 보조 URL 후보 수집은 Ctrl+K의 기능 찾기에서 접근합니다. 계정 후보 지정·수정은 **인증 후보**를 펼친 뒤 기존 행 메뉴로 수행합니다. 후보 인증값은 마스킹됩니다. JS의 분석 목록·상세 창은 더보기에 있습니다.

트래픽의 대상 선택은 관찰한 호스트로 URL 검색을 준비합니다. 수집 범위 자체를 바꾸려면 SCOPE 목록을 사용합니다. 오류 빠른 필터는 4xx와 5xx를 포함합니다. 일반 검색·계정 설정과 같은 검색 엔진을 사용하며 조건 복원 시 빠른 필터 표시도 동기화됩니다.

## 이미지와 구현의 차이

승인 시안과 실제 구현은 비교 페이지에 나란히 보관합니다. Swing의 네이티브 텍스트 렌더링, 기존 엔진이 제공하는 열·필드, 추가 Render/판정 근거 탭과 실제 데이터에 따른 빈 상태는 시안과 다릅니다. 계정은 최대 4개를 유지하고 세 번째 로그인 계정이 연결되면 요약 카드가 추가됩니다. 검사 시작·중지, 세부 설정 등 실제 운영에 필요한 제어는 유지합니다. 픽셀 단위의 완전 동일 구현이나 실제 사용자 PC에서의 확인을 주장하지 않습니다.

## 설치·검증

기존 Simple 확장을 해제한 뒤 1.4.6 JAR를 추가합니다. 내장 Mapper는 0.3.9, 브라우저 도우미는 0.4.1입니다. HttpServer 모듈 누락 시 전체 확장 로드를 유지하는 1.4.3 수정이 포함됩니다. 기존 Next와 이전 JAR·소스 ZIP은 변경하지 않습니다.

최종 검사 수·JAR 해시·실패 후 수정 기록은 검증 JSON에 기록합니다. 운영 Swing 컴포넌트를 합성 패킷으로 세 가지 크기·두 테마에서 렌더링하고, 기존 동작 회귀·격리 loopback HTTP·Mapper·도우미·고정 Katana를 검사합니다. 실제 Burp Community 2026.9.2 GUI, Windows DPI/IME, 수동 브라우저 확인은 미실행입니다.

최종 배포 JAR에서 전체 명령이 종료 코드 0으로 완료됐습니다. **5,897개 검사**(Java 회귀 5,587 · payload HTTP 136 · Mapper 145 · 도우미 Node 29), **164개 화면 렌더링**, **Katana 102개 검사**를 통과했습니다. 잘린 컨트롤·붕괴한 필수 영역은 0건입니다. `SimpleCompactDesignTest`의 41개 검사는 전체 수에 포함됩니다.
