# Simple 1.4.7 · 전체 화면 세부 디자인

계정 카드·결과 탭·기능 트리 예시의 시각적 세부를 8개 도구와 공통 UI에 적용했습니다. 배치만 바꾼 이전 버전에서 더 나아가 버튼·입력·경계·글자 계층·아이콘·표·패킷·빈 상태를 정리합니다.

[설치 JAR](../downloads/1.4.7/burp-workbench-simple-1.4.7.jar) · [소스·체크섬](../downloads/1.4.7/) · [8개 실제 화면](images/1.4.7/README.md) · [시안/이전/현재 비교](design/1.4.7/COMPARE.html) · [세부 디자인 기준](design/1.4.7/DETAILS_KR.md)

- 계정: 색상별 사람 아이콘, 이름·이메일/식별값·역할을 나눈 요약 카드, 슬롯 배지. 설정값만 사용하고 ‘계정 1’을 검증된 기준 계정이라고 표시하지 않습니다.
- 탭: 흰 배경과 주황 밑줄, 실제 결과 수에 연결된 개수 배지. Pretty/Raw 표시와 기존 추가 탭도 같은 스타일을 사용합니다.
- 기능 트리: 문서형 아이콘·펼침 화살표·들여쓰기·행 선택 강조와 실제 기능 수. 원래 Origin과 상태는 툴팁/노드에 남고, 접으면 본문 폭을 돌려줍니다. 작은 창에서는 필터가 줄바꿈됩니다.
- 공통 요소: 옅은 경계와 둥근 입력, 내부 검색 아이콘, 주요 버튼 그라데이션, 일반 표 32px 행, HTTP 메서드/상태 색, 체크박스·스크롤·분할 손잡이, 필터 0건과 원래 빈 목록을 구분하는 안내.
- 패킷: 읽기 편한 구문색과 줄 간격, 제목줄 복사·줄바꿈·Burp 원본 편집기 버튼, 밑줄 탭, 간결한 검색 조작. 복사는 화면에 표시한 미리보기 텍스트이며 HTML Render에서는 비활성화됩니다. 64 KiB 미리보기 제한과 원본 보존은 그대로입니다.

트래픽·매핑·계정 비교·JS·서버/경로·응답 분석·입력값 검사·증거 정리 전체에 반영합니다. 큰 도구 이름·소개를 본문에 다시 넣지 않습니다. 실제 데이터·상태·엔진 필드와 호스트 글꼴 렌더링은 시안과 다를 수 있습니다.

## 설치와 확인

기존 Simple 확장의 로드를 해제한 후 새 1.4.7 JAR를 추가합니다. 이전 개인화 배치가 저장돼 있으면 화면 설정에서 기본 배치로 초기화해 확인할 수 있습니다. Mapper 0.3.10, 브라우저 도우미 0.4.1을 사용합니다. HttpServer 모듈 누락 시 전체 로드를 유지하는 수정과 기존 기능을 포함합니다. Next 및 이전 버전 파일은 보존합니다.

화면은 실제 Java Swing 컴포넌트에 합성 패킷을 넣은 캡처입니다. Burp Community 2026.9.2 본체 GUI·Windows DPI/IME·수동 브라우저는 미실행이며 픽셀 단위 동일성을 주장하지 않습니다. 실제 검사 결과와 초기에 발견해 수정한 문제는 [검증 JSON](VERIFICATION_SIMPLE_1.4.7.json)에 기록합니다.
