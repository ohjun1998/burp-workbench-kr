# Simple 1.4.8 · 시안의 구성 요소 적용

사각 단계 버튼처럼 시안과 다른 기본 컴포넌트가 남아 있던 부분을 다시 구성했습니다. 8개 도구에 공통 색만 적용하던 방식에서 나아가 단계·요약 줄·계정 비교·상세 정보·증거 편집의 형태와 배치를 바꿉니다.

[설치 JAR](../downloads/1.4.8/burp-workbench-simple-1.4.8.jar) · [소스·체크섬](../downloads/1.4.8/) · [8개 실제 화면](images/1.4.8/README.md) · [시안/이전/현재 비교](design/1.4.8/COMPARE.html) · [세부 적용 기준](design/1.4.8/DETAILS_KR.md)

- 입력값 검사: 원형 1/2 번호와 주황 밑줄, 대상·검사 유형·인증·실제 진행률을 나눈 요약 줄, 결과 표와 사유·패킷 카드.
- 계정 비교: 역할·이메일 카드 묶음, 요청 URL 중심의 기본 6열 표와 계정 상태 배지. 계정 3을 연결하면 해당 열을 복원합니다. 선택 요청 제목과 두 실제 응답의 차이를 함께 보여줍니다.
- JS·응답 분석: 선택 항목을 이름/값 행으로 표시하며 긴 값은 줄바꿈·스크롤됩니다. 응답 분석에는 관련 요청·영향 URL 탭을 연결했습니다.
- 서버·경로: 상태/URL 열 비율, 관찰 환경 접기, 요청/응답의 Raw/JSON 표시와 판정 근거 버튼을 정리했습니다.
- 증거: 밑줄 모드 선택, 증거 목록 검색, 패킷 헤더, 영향/절차 서식 도구와 글자 수를 적용했습니다. 서식 버튼은 기존 일반 텍스트에 Markdown 표기를 넣습니다. 검색 후 삭제도 원래 증거 ID를 사용합니다.
- 트래픽·매핑과 공통 화면: 폴더 메뉴·아이콘·선택 글자, 탭 여백, 패킷 제목줄, 표 열 비율과 기능 트리의 중복 문구를 정리했습니다. 큰 도구 이름은 본문에 추가하지 않습니다.

## 설치

기존 Simple 확장의 로드를 해제하고 새 1.4.8 JAR를 추가합니다. 저장된 사용자 배치가 있으면 화면 설정에서 기본 배치로 초기화해 새 기본값을 확인할 수 있습니다. 내장 Mapper 0.3.11, 브라우저 도우미 0.4.1이며, HttpServer 모듈 누락 시 전체 확장 로드를 유지하는 수정도 포함합니다. Next와 이전 버전 파일은 보존합니다.

## 검증 범위

캡처는 배포 Java Swing 컴포넌트에 합성 패킷·결과를 넣어 만든 실제 렌더링입니다. 합성 데이터는 캡처 하네스에만 있으며 제품에 예시 행을 넣지 않습니다. 화면 변경·상세 열람은 HTTP를 전송하지 않습니다.

실제 Burp Community 2026.9.2 본체 GUI, Windows DPI/IME, 수동 브라우저 검증은 수행하지 않았습니다. 플랫폼의 글꼴 렌더링과 실제 데이터·추가 엔진 필드는 시안과 차이가 있을 수 있어 픽셀 단위 동일성을 주장하지 않습니다. 검사 수치와 초기 수정 이력은 [검증 JSON](VERIFICATION_SIMPLE_1.4.8.json)에 기록합니다.
