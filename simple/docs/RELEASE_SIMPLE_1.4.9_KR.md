# Simple 1.4.9 · 외부 노출·CVE 조사

왼쪽 **탐색·정보 수집 → 외부 노출·CVE 조사**에 `검색 노출 / CVE 후보` 두 탭을 추가했습니다. 별도 제품·버전 탭이나 큰 본문 제목 없이 기존 폴더·표·선택 강조·밑줄 탭 디자인을 사용합니다. 기존 8개 도구와 원본 Next, 이전 배포 파일은 유지합니다.

[설치 JAR](../downloads/1.4.9/burp-workbench-simple-1.4.9.jar) · [소스·체크섬](../downloads/1.4.9/) · [구현 화면](images/1.4.9/README.md)

## 검색 노출

1. 대상 도메인/URL과 하위 도메인 포함 여부를 지정합니다.
2. API 문서·공개 문서·관리 화면·디렉터리 목록 검색식을 복사하거나 Google에서 엽니다. Google 열기는 대상 도메인과 검색식을 Google에 전달합니다.
3. 검색 결과 URL을 한 줄에 하나씩 가져옵니다. 도메인 경계 검사, 중복/fragment 제거, 최대 500개 제한을 적용합니다. Google 결과를 자동 수집하지 않습니다.
4. 결과 선택 시 실제 가져오기 시각·검색식·현재 SCOPE·미확인 상태를 확인합니다. 가져오기는 실제 노출 확인이 아닙니다.
5. 현재 SCOPE에 포함된 URL만 Repeater에 준비합니다. 준비는 전송하지 않으며 인증값을 자동 첨부하지 않습니다. 근거는 복사할 수 있습니다.

## CVE 후보

- SCOPE 수집 응답의 Server/X-Powered-By에서 nginx, Apache HTTPD, IIS, PHP, Express 제품·버전을 수동 요청 없이 관측합니다. 헤더가 숨겨지거나 다른 기술이면 `수정`에서 CPE 공급사·제품 식별자를 입력합니다. 제품/버전은 헤더 주장값이며 검증된 설치 정보가 아닙니다.
- `CVE 후보 조회`를 누를 때 NVD CVE API 2.0을 호출하고 CISA KEV와 FIRST EPSS를 결합합니다. 대상 URL/쿠키/토큰/원본 패킷은 제공자에게 전달하지 않습니다. NVD에는 CPE 공급사·제품을, EPSS에는 CVE ID를 보냅니다.
- NVD 결과가 100건을 넘으면 NVD 정렬의 마지막 100건을 조회하고 제한을 알립니다. 무제한 전체 CVE 목록이 아닙니다. 요청 간격 최소 6.5초, HTTP 429/503 한 번 재시도, 응답 최대 8 MiB, 연결/읽기/전체 본문 시간 제한을 적용합니다. 60초 초과 Retry-After는 나중에 재시도하도록 안내합니다.
- CVSS 하한, 원격·인증 불필요, KEV만, 미확인 포함 필터를 적용합니다. REJECTED CVE는 제외합니다. KEV/EPSS 조회 실패는 미확인으로 유지하며 EPSS를 0으로 만들지 않습니다. EPSS는 확률 정보이며 해당 대상의 취약점 확정이 아닙니다.
- 선택한 CVE 아래에서 **대상 관측 버전 / CVE 영향 범위 / 수정 버전**을 비교합니다. 수정 버전은 공급사 공지 확인이 필요하며 영향 범위 끝값을 수정 버전으로 추정하지 않습니다.
- 숫자 버전 경계와 CPE 공급사·제품을 보수적으로 비교합니다. 배포판 접미사·백포트·알 수 없는 CPE 조건·OS/모듈/설정은 미확인입니다. AND/OR는 세 상태로 합성하고 부정 조건은 확인 필요로 남깁니다. `버전 조건 일치`는 실제 취약점 확인이나 취약 구성 확인이 아닙니다.
- 상세에는 원본 ID, 관측 헤더, 원본 URL, NVD 수정일, CVSS 출처, 조회 시각, 제공자 상태와 원문 링크를 표시합니다. 사용자 수정값은 수동 입력으로 표시하고 관측 원본도 보존합니다. 근거 복사는 선택 CVE와 출처를 함께 복사합니다.
- 조회 취소/대상·제품 변경/프로젝트 전환/확장 종료 시 늦게 도착한 결과를 차단합니다. 대상·제품별 최대 30개 **세션 메모리 캐시**를 지원합니다. 조회 실패 시 기존 캐시를 표시하며 시각을 유지합니다. 재시작 후 복원이나 디스크 영구 저장은 지원하지 않습니다.

## 설치와 검증 범위

기존 Simple 확장 로드를 해제하고 1.4.9 JAR를 추가합니다. 내장 Mapper 0.3.11, 브라우저 도우미 0.4.1은 그대로입니다. CVE 통신은 java.base의 HTTPS 연결을 사용하므로 추가 java.net.http 모듈을 요구하지 않습니다.

화면은 배포 Swing 컴포넌트를 합성 URL/가상 CVE에 연결해 캡처합니다. 가상 CVE는 테스트/캡처 하네스에만 있고 제품에는 예시 결과를 넣지 않습니다. 실제 Burp Community 2026.9.2 GUI 캡처가 아닙니다.

현재 클라우드 네트워크 정책은 NVD·CISA·FIRST API와 Google 접속을 허용하지 않습니다. 실제 외부 조회 성공이나 Google 브라우저 동작을 검증했다고 주장하지 않습니다. 제공자 파싱·오류·취소는 주입한 모의 응답으로 검증하며, 사용자 Burp 실행 환경에서 해당 HTTPS 제공자 접속이 가능해야 실시간 조회됩니다. 실제 표적 취약점 확인/공급사 공지 자동 해석/자동 Google 수집/재시작 후 캐시 복원은 이 버전 범위에 포함되지 않습니다.
