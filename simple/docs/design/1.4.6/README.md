# 승인 시안 · 구현 대조

[나란히 비교하기](COMPARE.html) · [실제 화면 모음](../../images/1.4.6/README.md)

reference/는 사용자가 승인한 큰 본문 제목 없는 8개 생성 시안입니다. 구현 증거가 아닙니다. 실제 화면은 운영 Swing 컴포넌트에 합성 패킷을 연결해 렌더링했습니다. 시안의 HTTP 결과/숫자와 실측 검증 결과를 혼동하지 마세요.

1600×1000에서 상단 Workbench 바, 220px 메뉴, 5개 그룹·10개 항목, 주황 선택선, 검색/실행 버튼 정렬, 표와 상세의 분할, 제목 제거를 직접 대조했습니다. 계정 카드 빈칸, 너무 큰 화살표, JS 상세 누락, 트리 접기 후 남던 빈 폭, 결과 단계 위치를 수정했습니다. 세부 차이와 미검증 범위는 릴리스 안내에 명시합니다.

작은 창에서는 작업 버튼이 다음 줄로 이동할 수 있습니다. 이미지 생성 시안 간에도 글꼴·메뉴 폭·아이콘 세부 형태가 서로 다르므로 픽셀 완전 일치의 수치 점수는 만들지 않았습니다. 자동 검사는 실제 컨트롤 경계, 패킷 영역, 선택 원본 연결과 명시적 실행 경계를 확인합니다.
