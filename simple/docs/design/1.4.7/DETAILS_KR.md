# 공통 세부 디자인 · 1.4.7

승인한 8개 제목 없는 시안과 추가로 첨부한 계정 카드·탭·트리 예시를 기준으로 적용했습니다.

| 요소 | 구현 |
|---|---|
| 전체 바탕 | 밝은 청회색 바탕, 흰 작업 면, 얇은 청회색 경계, 작은 모서리 곡률 |
| 제목·정보 계층 | 본문 큰 도구 제목 없이 메뉴·경로 유지; 카드 제목 15px, 일반 정보 14px, 보조 설명 12–13px |
| 계정 카드 | 파랑·초록·회색 사람 아이콘, 이름/이메일 또는 사용자 식별값/역할의 3단계, 첫 연결 슬롯 배지, 전체 내용 접근성 이름 |
| 계정 사실성 | 첫 슬롯을 무조건 서버가 검증한 기준 계정이라고 부르지 않고 ‘계정 1’로 표시; 설정된 이메일·역할만 표시 |
| 결과 탭 | 흰 배경·주황 밑줄, 실제 모델 수에서 그린 둥근 개수 배지; 0건 포함; 기존 휠·키보드 이동 유지 |
| 기능 트리 | 실제 기능 수 헤더, 문서 외곽선 아이콘, 꺾쇠 펼침, 들여쓰기, 전체 행 선택 강조; 원래 Origin/상태는 툴팁과 원래 노드에 보존 |
| 버튼·입력 | 주황 그라데이션 주요 동작, 흰 보조 버튼, 둥근 입력 경계와 내부 검색 아이콘, 포커스·비활성 상태 |
| 표 | 일반 행 32px·간결한 헤더, 옅은 가로/세로 경계, 행 선택 주황 표시; HTTP 숫자는 배지 대신 색상, 별도 판정은 배지 유지 |
| 패킷 | 제목줄 복사·줄바꿈·원본 편집기 동작, 밑줄 탭, 선명한 구문색·줄 번호·넉넉한 문단 간격, 작은 검색 화살표 |
| 빈 결과 | 0건/필터로 0건이 된 경우를 구분하는 설명; 실제 모델에 예시 행을 추가하지 않음 |
| 체크·스크롤 | 작은 주황 체크 표시와 좁은 스크롤바; 분할 경계는 가운데 손잡이로 줄임 |
| 좁은 창 | 검색란 최대 폭 제한과 Mapper 필터 줄바꿈, 카드 말줄임·접근성 전체 이름, 기존 패킷 모드/검색 옵션 반응형 동작 |
| 테마 | 같은 배치·기능의 밝은/어두운 테마, 호스트 테마 변경 후 로컬 스타일 복원 |

트래픽, 매핑, 계정 비교, JS, 서버·경로, 응답 분석, 입력값 검사, 증거 정리 전체에 적용합니다. 데이터 변환, 대시보드, SCOPE 및 설정 화면도 공통 입력·표·탭 스타일을 사용합니다. 네이티브 Burp 편집기의 내부 그림은 Burp 소유입니다.

실제 계정 수, 결과 수, 엔진 필드, 원문 길이에 따라 시안과 내용이 달라집니다. 픽셀 단위 동일성을 주장하지 않습니다. 기존 전송·원본·계정·범위·저장 동작은 회귀 검사로 확인합니다.
