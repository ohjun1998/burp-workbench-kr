# Simple 1.3.1 수정·재테스트·원문 값 보고서 기준

공유 대화 `https://chatgpt.com/share/6ae129be-c510-83e8-842b-ad54ffc5be60`에서 공개 본문으로 확인한 문제를 재현하고 수정합니다. 본문에 연결된 9개 개선안의 PDF·HTML·ZIP은 이 세션에 제공되지 않았으므로, 공개 본문에서 확인되지 않는 나머지 항목이나 다른 세션의 통과 수치를 만들어내지 않습니다.

| 확인한 문제·요청 | 변경과 확인 기준 |
|---|---|
| 일반 화면의 password 폼으로 정상 계정 점검 중단 | 폼 자체와 세션·신원 실패를 구분하고, 실제 401·신원 불일치·보안 확인 중단은 유지 |
| 공개 `.env` 발견 누락 | Scope와 공통 예산 안의 제한된 조회, 없는 경로 대조·응답 내용 판별, 가짜 200·부재·부분 상태 구분 |
| Juice Shop 대표 API 누락 | 실제 JS 번들의 `/rest/user/login`, `/rest/basket/`, `/rest/products/search`와 추출 위치 대조; 발견 후보와 실제 자동 전송은 구분 |
| 변수·표현식·소스맵 코드의 시크릿 오탐 | 코드 표현식을 리터럴 비밀값처럼 보고하지 않고 실제 문자열 키 탐지는 유지 |
| 같은 실습 토큰의 중복·다른 분류 | 같은 원문 위치·값의 일관된 예제/공개/미검증 분류, 서로 다른 출처는 보존 |
| 불필요한 추정 경로로 예산 소모 | 관측·JS·문서 참조 우선, 기술 추정 경로 선별, 기준·신원 요청까지 공통 한도 적용 |
| 원문 값 보고서 | API·민감정보·토큰·키·환경·DB·내부 경로 등의 정확한 값, 원본 ID·계정·응답 상태·헤더/본문 위치·분석 한도 포함 |
| 판정 범위 | 제품 탐지와 보고서 추가 파싱, 자동 발견과 직접 지정 대조, 계정 차이와 권한 정책 판정을 구분 |

분류 보고서는 현재 실행의 응답 원본에서 사용자의 저장 동작 때 생성합니다. 화면·이력·기존 증거의 가림은 유지합니다. 보고서 생성은 대상이나 외부 키 공급자에 요청하지 않으며, 발견한 토큰을 실행 인증값으로 재사용하지 않습니다. `report.json`은 정확한 문자열 값이고, HTML은 이스케이프해 표시하며 CSV는 수식 실행 보호를 적용합니다. 기존 보고서는 덮어쓰지 않습니다. 값의 파싱·복원 방식과 본문 문자 위치를 원시 패킷 바이트 위치와 구분합니다.

재시험 대상은 Juice Shop, BenchmarkJava, VulnerableApp, OopsSec Store, DVBank, VulnBank, LOOP Community의 별도 로컬 실행입니다. 원본 커밋·실제 실행 범위·의존성·응답·수치·미실행 항목을 새 결과로 기록합니다. 부분 servlet, 호환 DB 또는 별도 HTTP 어댑터를 쓴 경우 그대로 표시하며 전체 공식 배포 스택이나 실제 Burp GUI 검증으로 확대하지 않습니다.
