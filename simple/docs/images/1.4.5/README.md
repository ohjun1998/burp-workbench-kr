# Simple 1.4.5 도구별 실제 화면

운영 Swing 컴포넌트와 합성 패킷을 사용한 1280×800 렌더링입니다. 실제 Burp GUI 캡처가 아니며 렌더링으로 HTTP를 전송하지 않습니다. 생성 디자인 이미지와 구분합니다.
