# Simple 1.4.7 · 세부 디자인 실제 화면

계정 카드·개수 배지·기능 트리뿐 아니라 8개 도구의 버튼, 입력란, 표, 패킷, 빈 목록과 선택 상태에 같은 스타일을 적용했습니다. 아래는 생성 시안이 아닌 **운영 Java Swing 컴포넌트**입니다. 내용은 격리된 합성 예시이며 Burp 본체의 캡처는 아닙니다. 이미지를 클릭하면 원본 크기로 확인할 수 있습니다.
